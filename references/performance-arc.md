# 表演弧线（Performance Arc）

> 用途：第5站给每镜补表演时，除了「心理动机 → 外显动作」这一句，还需要一条**能按时间演出来**的弧线。
>
> 三份文件的分工，别混：
>
> | 文件 | 管什么 |
> |---|---|
> | `performance-engine.md` | 维度规则：6 维挂载矩阵、情绪生理表、动作四要素、台词声音 |
> | `microexpression-library.md` | 原子动作：A–F 六类情绪的成品动作模块 + 强度词 + 时间词 |
> | **本文件** | 编排：怎么把这些动作排成一条有因果、有节奏的弧线 |

---

## 一、开工前先建表演简报

不用展示给用户，但要先想清楚这八项：

| 项 | 问什么 |
|---|---|
| 人物目标 | 此刻想完成什么 |
| 公开面具 | 希望别人看到什么状态 |
| 真实情绪 | 内心正在涌起的是什么 |
| 触发节点 | 什么事让他变了 |
| 抵抗 | 他在压住、否认或挽回什么 |
| 最终选择 | 最后做成了、没做成、还是停在半途 |
| 证据上限 | 首帧和剧情最多能支持多强的表演 |
| 主通道 | 这一段主要由哪个可见部位承担情绪 |

> **没有「目标」和「抵抗」的情绪，会变成摆表情。** 这两项优先补清。

---

## 二、八节点弧线（核心）

一条完整的表演，按顺序是这八节。**不是每镜都要用满**，选最少但够用的那一组。

| # | 节点 | 观众看到什么 |
|---|---|---|
| 1 | **基准状态** | 人物还没被动摇时的样子 |
| 2 | **认知触发** | 听见、看清、认出了什么 |
| 3 | **情绪裂缝** | 第一处破绽：视线停顿、嘴角抽动、呼吸漏拍 |
| 4 | **相反冲动** | 想看又回避、想说又合拢、想靠近又停住 |
| 5 | **动作未完成** | 重大决定先停在中间，不一步做完 |
| 6 | **假性恢复** | 主动恢复原姿态，试图重新控制自己 |
| 7 | **无意识泄露** | 恢复之后，手抖 / 泪光 / 呼吸 / 下颌还是暴露了 |
| 8 | **最终物理落点** | 用一个可见动作结束，不用抽象结论代替 |

### 三条规则

1. **先理解，再反应。** 抽象触发后面必须紧跟可见动作。
   > 她听懂了话里的告别意味，视线停顿片刻，随后缓慢下落，嘴角原有的笑意一点点消失。
2. **每一节先承接上一节的痕迹**（泪光、呼吸、下颌张力、手势、姿态、道具位置），再用一个可见开关引发变化：看清细节、一次眨眼、一次吞咽、手指触到道具。
3. **不要每镜都从中性表情重新开始。**

### 四条常用弧线

- 温柔注视 → 听懂含义 → 笑意消失 → 垂眼消化 → 重新抬眼
- 冷静执行 → 第一处动摇 → 回避又拉回 → 动作松动 → 假性恢复 → 最终放下
- 防备倾听 → 闭眼压制 → 重新对视 → 短暂回应 → 含泪接受
- 礼貌维持 → 被看穿 → 笑容僵住 → 目光回避 → 强装平静 → 吞咽泄露

## 三、表演通道：一个主，一个漏

不要把五官同时写满。**只选一个主通道，复合情绪时只允许另一个通道泄露次级情绪。**

| 通道 | 承载什么 |
|---|---|
| 眼神 / 眼睑 | 脆弱、迟疑、依恋、警觉 |
| 嘴角 | 克制、伪装、礼貌、不愿承认 |
| 下颌 / 手部 | 意志、愤怒、决心、压制 |
| 呼吸 | 压力、放松、惊讶、即将失控 |
| 身体 / 道具 | 选择是否真的发生 |

### 复合情绪拆三层

```
主情绪：当前最强烈的真实感受
次情绪：给它增加质感的次级感受
反情绪：人物用来抵抗主情绪的力量
```

### 取舍顺序

1. 先留能说明**认知变化**的眼神或眼睑动作；
2. 再留一个**主动控制 / 抵抗**的嘴唇、下颌或呼吸动作；
3. 必要时加一个身体、手部或道具泄露；
4. 删掉观众看不出来、模型执行不稳、对剧情没用的动作。

> 连续多个镜头时**轮换主通道**，不要每镜都「垂眼—吸气—抿嘴—抬眼」。

## 四、时间轴密度

时长决定能排几节，不是越多越好。

| 时长 | 建议节点数 | 能加什么 |
|---|---:|---|
| 3–5 秒 | 2–3 | 基准 + 变化 + 落点 |
| 6–8 秒 | 3–4 | 可加一次停顿或抵抗 |
| 9–12 秒 | 4–6 | 可加假性恢复与无意识泄露 |
| 12–15 秒 | 5–7 | 保留呼吸和停顿，不持续加动作 |

**每 1.5–2.5 秒最多：**
- 一个主要面部变化；
- 一个辅助的呼吸 / 身体 / 道具反馈；
- 必要时一个短暂停留。

❌ 不要在两秒内同时要求瞳孔、双眉、鼻翼、嘴角、下巴、吞咽、手部和道具全部变化。

### ⚠️ 和 AAA 第5站的硬规则对齐（重要）

AAA 第5站 5.4 的官方规范是：**默认用阶段式，秒数只在必要时用。**

所以本文件**不允许**把「0—2 秒 / 2—4 秒」当默认写法。正确做法：

```
【阶段一】开始时：<基准状态>；主要事件：<认知触发 + 第一处裂缝>；结束时：<停留状态>
【阶段二】承接上一阶段：<发展>；主要事件：<抵抗或未完成动作>；结束时：<状态>
【阶段三】承接上一阶段：<落点>
```

- 每个阶段只安排**一个主要状态变化**，并写清结束状态。
- **只有当**用户自己写了时间段、或明确要求按秒控制节拍时，才改用连续时间码（`0—5秒` → `5—10秒`，不重叠）。
- 密度表仍然有用：它决定**你最多能排几节**，不是让你去写秒数。

## 五、关系型表演（两人以上）

多人场景不要各演各的，要建成因果链。

```
发起者：想发出什么信息 → 表达前的状态 → 对方能看见的最终信号
接收者：接收前的表面状态 → 被哪个具体动作触发 → 反应延迟 → 接收/抵抗/误解/拒绝
情绪交接点：上一镜结束时留下的信号 → 下一镜从该信号引发的首个反应
```

### 四条规则

1. **接收者必须在触发之后才反应**，不许提前进入目标情绪。
2. **每一拍只有一个主动者**，另一个人只承担注视、停顿或一个回应动作。
3. **两个人用不同的表演通道**（一个靠嘴角伪装，另一个靠呼吸泄露）。
4. **不同角色不要复用同一套动作**，尤其别让所有人都是「垂眼—吸气—抿嘴—抬眼」。

### 按角色调整

- 主动表达者：开口前先整理呼吸，重新建立对视；
- 被动接收者：反应有延迟，停顿更多；
- 强势角色：少躲闪，多用下眼睑、下颌和姿态控制；
- 内敛角色：多用眨眼延迟、呼吸、吞咽、未完成动作；
- 习惯伪装者：表面恢复得快，但保留一个无意识泄露。

> 不要把性别、年龄、身份刻板地绑到固定动作上，以性格、关系和当下目标为准。

## 六、动作余量与首帧兼容

首帧已经做过的动作，不要再往上加。

- 眼睛已经睁得很大 → 不要再"睁大"，改用视线移动；
- 眉心已经收紧 → 不要再"加深皱眉"，改用下颌或呼吸；
- 头已经侧转 → 优先用眼球动作，不要继续转头；
- 人物病弱 / 受伤 / 酒醉 / 失衡 → **先锁定椅背、墙面、桌沿、手杖、另一只脚等支撑点**，再排表情。

> 图生视频时，先按 `first-frame-preflight.md` 做风险预检；首帧不达标就先修首帧，不要用文字硬补。

## 七、强度：默认 2 级

| 强度 | 动作量 | 幅度与节奏 | 用在哪 |
|---|---|---|---|
| 1 级 极轻 | 1 主 + 1 辅 | 几乎不可察觉，短暂出现后收束 | 暗流、潜台词、初次破绽 |
| 2 级 克制 | 1–2 主 + 1 泄露 | 清晰但不过度，允许一次停顿 | **默认**，电影近景 |
| 3 级 明显但真实 | 2 主 + 1 身体或道具反馈 | 观众能明确识别，仍避免舞台化 | 强冲突、转折、高潮前 |

**升档不靠把「轻微」改成「剧烈」**：注视更稳更窄 → 呼吸压力增加 → 下颌、手部或重心参与。
**降档保留上一状态的痕迹**：眼神失去抓取 → 呼吸变长 → 肩颈下沉。

## 八、接进 AAA 流水线

| 站 | 怎么用 |
|---|---|
| 第3站 | 建角色资产时，允许带一张**表情版**（另做，不从原设定图迭代） |
| 第4站 | 单帧里**只写「起始基准 + 一处裂缝」**，不要把整条弧线塞进一帧 |
| 第5站 5.3 | 弧线按**阶段**排进时间轴，每阶段一个主变化 |
| 第5站 5.4 | 阶段式优先；秒数只在用户要求时用 |
| 第5.5站 | 诊断"表演太假/太快/没层次"时，先查是不是缺了抵抗或落点 |

## 九、禁忌

- 不用「她非常悲伤」代替可见动作。
- 不把微表情写成每块肌肉都要动的清单。
- 不让人物从中性状态瞬间切到目标表情。
- 不让多个动作无顺序同时爆发。
- 不连续叠三种以上主要情绪。
- 不用大哭、大笑、大幅摇头替代细腻表演（除非用户明确要）。
- 不在动作发生前先写出反应结果。
- 不让道具自己动——先写持有者的手部或身体变化。
- 不用「她最终释然了」代替最终物理动作。
- 不过度依赖「瞳孔收缩几毫米」「虹膜露出百分比」这类伪精确控制。
- 不把「声音很克制」当可见指令——改成口型、下颌、停顿、呼吸。

## 十、自检

- [ ] 有明确的「目标」和「抵抗」
- [ ] 节点数是按时长选的，没有硬塞
- [ ] 只有**一个**主通道，复合情绪只多一个泄露通道
- [ ] 每节都承接上一节的物理痕迹，没有从中性重新开始
- [ ] 触发在前，反应在后
- [ ] 有至少一处相反冲动 / 未完成动作 / 压制过程
- [ ] 假性恢复只在时长和冲突足够时用
- [ ] 无意识泄露晚于主动控制
- [ ] 身体或道具反馈晚于面部触发半拍
- [ ] 结尾落在可见动作上
- [ ] **用的是阶段式，不是默认时间码**
- [ ] 多人场景里接收者没有提前反应，且两人通道不同
