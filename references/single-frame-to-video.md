# 单帧图生视频 / 参考素材生视频 · 方法论

> 来源：融合 `single-frame-video-director`（2026-11-09）与 AAA 第 5 站既有规范。
> 用途：手上有**一张单帧**、**一组参考图**或**一条参考视频**，要写出可直接提交的视频提示词时使用。
> 铁律：**先读图，再编动作；可见事实与创作增补分开；单帧锁不住整段动作。**

---

## 0. 什么时候用

- 单帧图生视频（首帧，或只作外观参考）
- 参考图 + 参考视频生视频
- 上一镜尾帧续拍 / 换机位接镜
- 已有分镜单帧，要扩成 4–10 秒镜头

---

## 1. 素材核对（先做，不写正文）

- 实际打开图片/视频，不靠文件名判断画面。
- 建立「分析标签（图1 / 视频1）」到「真实附件或本机文件名」的映射。
- 每份素材只写清一件事：首帧 / 人物外形 / 服装 / 场景 / 道具 / 构图 / 风格 / 动作节奏。
- 未分配的素材 → 列入【未采用素材】。
- **参考图 ≠ 首帧**；只有明确写「作为首帧」时，动作才从它的可见状态接续。
- 不虚构已上传、平台字段、参考强度、CFG、步数。

---

## 2. 四层事实分离

| 层 | 内容 | 写法 |
|---|---|---|
| 可见事实 | 图里真的有的：主体、姿态、视线、前中后景、接触、光源、材质 | 直接写 |
| 用户要求 | 用户给的时长、动作、运镜、不可改项 | 直接沿用 |
| 创作增补 | 你补的表演、环境、镜头 | 标明「新增」 |
| 未知 | 图外信息、速度、前后动作 | 写「未知 / 待确认」，不编 |

---

## 3. 镜头卡（先填，再写正文）

| 字段 | 填什么 |
|---|---|
| 时长 | 用户给的秒数；没给时按动作量建议，标待确认 |
| 画面内容 | 主体、起始姿态、空间、道具、构图、光色、风格；事件的开始与结束 |
| 人物表演与动作 | 目的与注意对象；视线 / 表情 / 重心 / 手部；动作顺序、停顿、接触、次级反应 |
| 环境与运镜 | 前中后景动静层级；环境变化原因；光影反射联动；机位 / 轨迹 / 速度 / 结束取景 |
| 参考素材引用 | 素材名、标签、职责、采用 / 排除范围、是否实际读取 |
| 衔接（按需） | 上一镜出点、本镜入点、切点、连续性、本镜出点 |

**只填已给或有依据的值**。声音、比例、分辨率等平台设置单列，不塞进正文。

---

## 4. 表演编排（有人的镜头）

顺序：**目的与注意对象 → 预备 → 主要动作 → 反应 / 余势 → 停顿 / 结束状态**

- 先问「他想要什么、在看什么」，再写身体。
- 表情用动作写：眼睑开合、瞳孔、呼吸、嘴角、肩线、手指。
- 一个镜头只给一个主要事件；复合情绪只多一个泄露通道。
- 动作要有起点、过程、终点；力度与情绪成正比。
- 无人物镜头：写主体物的运动、受力、形变、惯性；不套眼神与呼吸。
- 细节查 `performance-arc.md`、`microexpression-library.md`。

---

## 5. 元素遍历（全画面，不等于全部运动）

| 元素 | 依据 | 动/静 | 动因与方向 | 幅度/节奏 | 联动/视差/遮挡 |
|---|---|---|---|---|---|

- 覆盖：主动作、衣料 / 发丝 / 道具连带、环境自身运动、摄影机视差、光学变化。
- **每个动的东西都要有原因；没有原因的不动。**
- 保留静止与停顿，别让全画面一起动。
- 不默认加风、雾、尘、手持抖动、写实滤镜；除非画面或剧情有依据。

---

## 6. 运镜

- **一条提示词只写一种运镜**。
- 写法：类型 → 起点 → 过程 → 终点 → 禁止。
- 推轨 ≠ 变焦；横移 ≠ 摇；环绕 ≠ 弧线；仰摇 ≠ 升起。
- 查 `camera-movements-46.md`。
- 高光 / 阴影 / 反射随视角、姿态、遮挡、光源变化，不凭空补轮廓光。

---

## 7. 时间组织

- 默认**阶段式**：「开始时…主要事件…结束时…」。
- 秒数只在用户给了、或明确要求按秒控制时使用；连续、不重叠；总时长与镜头卡一致。
- 一个阶段只安排一个主要状态变化，并写清结束状态。

---

## 8. 输出格式

1. **画面理解与增补**：读图依据、镜头意图、氛围、本轮新增的表演。
2. **镜头卡**：五字段；有前后镜时补衔接。
3. **动作节拍 + 元素表**。
4. **一个完整、可直接复制的正文**：无占位符、无分析说明。
5. **平台设置 / 素材绑定**：单列。
6. **关键检查**：冲突、待确认、生成后验收点。

正文顺序：素材职责 → 起始状态与事件 → 表演可见变化 → 连带反馈与环境 → 光色材质关系 → 运镜与结束状态 → 连续性约束。

不要用「极致电影感 / 顶级画质」代替具体动作、光照和材质关系。

---

## 9. 镜头衔接

- 先选类型：同镜延长 / 换机位切镜 / 时间或地点转换 / 生成桥接。
- **尾帧只证明可见状态，不证明速度与完整轨迹。**
- 同镜延长：姿态、接触、运动方向与速度、机位、光色、环境、声音连续。
- 换机位：世界空间与事件状态连续，屏幕坐标可以变化；用视线 / 动作 / 轴线匹配。
- 不要把「前镜尾帧 + 后镜不同机位图」直接当同一段首尾帧。
- 桥接段会增加时间与动作，不能一概替代剪辑。

---

## 10. 参考视频

- 只描述**实际看过**的范围与用户给的职责。
- 职责写清：动作节奏 / 风格 / 主体外形 / 运镜；逐条写「参考什么、不参考什么」。
- 一张静帧不能推断整段轨迹；未看视频不得声称已识别节奏。

---

## 11. 自查

- [ ] 图片实际打开过；标签与真实文件对应
- [ ] 首帧 / 外观 / 风格职责分清；未采用素材列出
- [ ] 可见事实 / 用户要求 / 新增 / 未知 分开
- [ ] 起始姿态、时长、视线、手物接触、重心能对上
- [ ] 结束状态能接下一镜
- [ ] 每个运动有原因；没有默认风雾尘手持
- [ ] 只有一种运镜，五段写清
- [ ] 光色反射随视角 / 姿态 / 遮挡变化
- [ ] 正文无占位符；设置与素材单列
- [ ] 未试片就标未试片

## 12. 与 AAA 第 5 站的关系

- `seedance25-playbook.md` 是官方格式权威；本文件是**前端**（读图、镜头卡、表演、元素遍历）。
- `performance-arc.md` / `microexpression-library.md` 管表演细节；`camera-movements-46.md` 管运镜；`model-adapters.md` 管模型格式；`stage-split.md` 管单帧 / 视频属性分工。
- 本文件**不替代**第 5 站的素材职责、参数分离、符号系统、官方铁律。

## 13. 一句话流程

**读图 → 分四层事实 → 填镜头卡 → 排表演 → 遍历元素 → 定一种运镜 → 写正文 → 单列素材与设置 → 自查 → 试片。**
