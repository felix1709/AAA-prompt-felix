## 一、模型能力与素材上限（速查）

| 项目 | 硬性上限 | 推荐范围 |
|---|---|---|
| 单段时长 | **30 秒直出** | — |
| 参考素材总数 | ≤ 50 份 | — |
| 图片 | ≤ 30 张（单张 ≤ 4K） | 主体图 **1–8 个主体** |
| 视频 | ≤ 10 段（总时长 ≤ 30s） | 主体音视频 **1–5 个主体、单段 5–10s** |
| 音频 | ≤ 10 段（总时长 ≤ 30s） | — |
| 视频编辑输入 | — | 原视频 ≤ 20s、参考图 1–5 张 |
| 宫格分镜 | — | **≤ 15 格**（18 格会静止／顺序错乱） |
| 白模 | — | **粗粒度**（简单几何体拼接）最好 |

**超额时**：优先保留用户明确指定的、覆盖必需实体的、唯一编辑母版／延长源的素材；其余不进 Prompt，并用一行 `素材提示：` 说明需缩减。
**主体数 > 5 时**：用「单视图」比「多视图」稳；多视角要拆成多张图，而非一张含多视角。

## 二、素材职责规范 ⭐核心

**铁律：每份素材只承担明确职责，不准"一图管所有"。**

每份素材逐条写清四件事：

| 素材 | 绑定对象/阶段 | 参考什么 | 不参考什么 | 优先级 |
|---|---|---|---|---|
| @图片1 | 主角 | 五官、发型、服装 | 图片背景、光线 | 硬约束 |
| @视频1 | 主角的手部动作 | 动作节奏、手腕轨迹 | 视频中的人物、服装、场景 | 风格参考 |

**写法要点**：
1. **逐条绑定，禁止范围句**
   - ✅ `<人物A>参考@图片1` 换行 `<人物B>参考@图片2`
   - ❌ `人物A和人物B参考@图片1、@图片2`
2. **必写"不参考什么"** —— 这是成功率提升最大的一条。动态参考尤其容易"污染"静态外观：
   > `@视频1用于参考四视角布局、步态和节奏；不要参考@视频1中的人物外观、服装、肤色、背景、文字、数字、时间轴或其他标记。`
3. **列出【未采用素材】** —— 实际可用但没分配职责的素材，逐个列编号，防止模型自作主张激活：
   > `【未采用素材】@图片5、@图片6未参与本任务，不用于人物、场景、道具、动作或镜头。`
4. **优先级二选一**：`硬约束`（用户明确要求严格遵循）或 `风格参考`（只借氛围）。**不要替用户假定。**

## 三、主体映射规范 ⭐核心

1. **建"必需实体清单"**（内部用，不输出）：故事里每个明确出场的人物、群体、关键道具、场景各占一槽。
2. **一人一图**：一张单人设定图**不得**同时定义两个会出场的人物。多个候选时先「一人分配一图」。
3. **禁止合并**：两个已命名角色不能合并成一个主体；不能因某素材不够醒目就漏掉对应角色。
4. **遗漏审计**：输出前逐个核对——每个必需实体在 Prompt 中恰好承担一个明确角色。
5. **映射优先级**（固定顺序）：
   ```
   用户明确指定 > Prompt 中的描述 > 素材内容 > 文件名和元数据 > 上传顺序
   ```
6. **事实与观察分离**：人物叫什么、什么关系、什么结局 → 以**用户文字**为准；五官发型服装材质 → 由**素材**补充。**不得从素材外观反推身份、年龄、关系。**

## 四、任务路由（三选一）

先判断是否修改已有视频，再判断是否在已有视频前后新增，其余进入生成：

| 主任务 | 定义 | 判断依据 |
|---|---|---|
| **① 视频编辑** | 以一条原视频为**唯一母版**，只改其中指定对象/区域/声音 | 目标画幅与时长须与原视频一致 |
| **② 视频延长** | 在原视频**之前或之后**生成新片段，不改写原片段 | 有明确"向前/向后延长/续写"意图 |
| **③ 视频生成** | 从文字和可选参考素材生成新视频 | 其余情况 |

### 画幅与时长兼容闸门（重要）

- 目标画幅与原视频不同 → **不得判为视频编辑**，按普通生成处理
- 目标时长与原视频相差 > 0.3 秒 → **不得判为视频编辑**（明确"延长"除外）
- 确认存在冲突时，在 Prompt 的【生成目标】句后紧跟一句：`请注意这不是视频编辑。`
- **"转换/调整/修改/改成"等动词本身不构成视频编辑**——这个声明只在规格冲突时加，不得滥用

**白模视频**作为运动/空间参考做重渲染时，属于**视频生成**，不因输入含视频就自动变成编辑。

## 五、时间组织：阶段 vs 时间段 ⭐核心

### 默认用「阶段」（不带数字）

```
【阶段一】开始时：<初始状态>。主要事件：<一个主要动作>。结束时：<可观察状态>。
【阶段二】承接上一阶段：<必须保持的状态>。主要事件：<一个主要动作>。结束时：<可观察状态>。
【阶段三】主要事件：<收束事件>。结束时：<最终画面状态>。
```

- **每阶段只安排一个主要状态变化**，并写清结束状态
- 阶段数由事件数决定，不强制三段

### 秒数只在两种情况下用

1. 用户**自己写了**数字时间段（这属于创作内容，必须保留）
2. 用户**明确要求**按秒控制交接、进出场或节拍

用时必须**连续、不重叠**：

```
0-5秒：<开始状态>；<主要事件>；结束时<可观察状态>。
5-10秒：承接上一段的<状态>；<主要事件>；结束时<可观察状态>。
10-15秒：<收束事件>；结束时<最终状态>。
```

> ⚠️ 秒数是**事件预算，不是帧级剪辑点**。不要声称能精确到 0.5 秒。
> ⚠️ 不得用时间戳控制频率（如"一秒摇头 3 次"）。
> ⚠️ 仅由页面/接口给出的目标时长，**不得反写成** `0-8秒`、`8-18秒` 塞进 Prompt —— 改用无数字阶段。

## 六、参数分离 ⭐核心

**比例、时长、分辨率、帧率、声音开关一律不进 Prompt 正文。**

| 参数 | 归属 | 默认建议 |
|---|---|---|
| 画幅比例 ratio | 页面/接口设置 | 按投放平台 + 主体运动 + 构图决定 |
| 总时长 duration | 页面/接口设置 | 按动作阶段数 + 镜头数决定 |
| 分辨率 resolution | 页面/接口设置 | 未指定时传 **720p** |

- 用户明确指定了就**保留其值**，有风险就简短标注风险，**不得用推荐值替换**
- 任务自动锁定的参数（编辑锁画幅与基本时长、首尾帧锁画幅、延长锁画幅）**不得写进 Prompt**
- 需要提示时，在正文后**最多追加一行** `参数提示：...`

## 七、符号系统（写入 Prompt 正文）

需要区分内容类型时用固定符号：

| 内容 | 符号 | 示例 |
|---|---|---|
| 音乐 | `()` | `(背景播放舒缓的钢琴乐)` |
| 音效 | `<>` | `<远处传来钟声>` |
| 台词 | `{}` | `{你好，欢迎回来}` |
| 字幕 | `【】` | `【第一章：启程】` |

**台词语言格式**：`语言 + 可选地区变体/口音 + 表达方式 + 说话人 + {台词}`
> 用户只给英语台词时**不得**擅自补"美式""英式"；没指定语言时**不得**擅自补"普通话"。

**多人对话**：逐阶段绑定说话人与音频，并写明**其他人物自然闭口聆听**。

> ⚠️ 用了 `<>` 标音效后，主体名称不要再用尖括号，改用普通角色名。
> ⚠️ `【】` 同时用于段落标签（如`【生成目标】`）和字幕。段落标签独占一行，字幕嵌在内容中，注意不要混。

**无对白任务**：同时限定说话、口型、声音来源、文字载体（人物自然闭口、无旁白、只保留指定环境声、画面不显示字幕）。

## 八、提示词模板库

### 8.1 基础生成（纯文字/少量参考）

```
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格或情绪>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

### 8.2 带参考素材的生成（主模板）

```
【生成目标】
生成<视频类型或核心事件>，核心主体是<主体>，主要事件是<概要>。

【参考素材职责】
@图片1用于<主体>的<外貌、服装、结构或材质>。
@视频1用于<动作、运镜或节奏>，不采用<容易误带的身份、服装或场景>。
@音频1用于<角色或声音类型>的<音色、台词、环境声或音乐>。

【未采用素材】
@图片2、@视频2未参与本任务，不用于人物、场景、道具、动作、镜头或声音。

【主体与关系】
<主体A>对应@图片1，始终保持<固定特征>。
<主体A>与<主体B>的关系是<关系>。

【事件脚本】
开始时：<人物、道具和场景状态>。
主要事件：<连续动作或事件>。
结束时：<人物位置、道具归属或最终画面状态>。

【保持一致】
保持<人物身份与数量、服装、道具归属、空间方向和声音关系>稳定。
```

### 8.3 多素材分组（素材多时用）

```
【人物】
<人物A>对应@图片1，只采用外貌、发型和服装。
<人物B>对应@图片2，只采用外貌、发型和服装。
两人的外貌、服装、动作、站位和台词不互相交换。

【道具】
<道具A>对应@图片3，只属于<人物A>，全程只有一件。

【场景】
<场景A>参考@图片5，只采用空间、材质和光线，不采用图中人物。

【动作与声音】
@视频1用于<人物A>的<动作或运镜>，不采用视频中的人物和场景。
@音频1用于<人物B>的<音色和指定台词>。
```

**空间站位写物理关系，不写屏幕左右**：
> ✅ `<店员>始终站在玻璃柜台内侧，身体朝向柜台外。<顾客>站在柜台外侧，隔着柜台与<店员>交谈。`
> ❌ `店员在左边，顾客在右边`

### 8.4 视频编辑

```
【编辑目标】
编辑@视频1，只把<原对象或区域>修改为<目标内容>。

【原视频职责】
@视频1是唯一编辑母版，负责原始场景、机位、镜头运动、动作轨迹、遮挡关系和事件顺序。

【目标素材职责】
@图片1用于<目标主体>的<外观、结构或材质>，不采用<无关背景、人物或构图>。

【编辑对象与范围】
只修改<明确对象和区域>。全片目标对象数量为<数量>。不修改<需要保持的内容>。
除以上明确修改对象外，@视频1中其他可见人物、道具和背景元素保持原样，不参与替换或删除。

【时间线继承】
<目标对象>继承<原对象>每次出现、运动、遮挡和离开的时点、持续时长、路径与速度变化。
其他人物动作、镜头运动、镜头切换和事件顺序保持@视频1。
```

- **范围闭环兜底句必须写**（上表倒数第二行），不能省
- **动态主体替换用"运动槽位覆盖"**：删原主体，让目标主体继承完全相同的出现时机、路径、速度和遮挡位置
- **连续编辑**：每轮以**上一轮结果**为输入，说明"这轮改什么 + 之前哪些改动保留"

### 8.5 视频延长

**向后延长**：
```
@视频1是需要向后延长的原视频。
向后延长@视频1。延长片段的第一个画面直接承接@视频1的尾帧：保持<主体姿态与朝向>、<道具位置>、<背景与空间关系>、<机位与构图>、<光线>、<声音状态>和<运动趋势>连续。
随后，<需要延长的新动作、事件、镜头或声音>。
延长过程中保持<人物身份与服装>、<关键道具>、<背景布局>、<摄影轴线>和<原有声音环境>连续。
同一主体始终保持为同一个连续对象，不重复、不分裂；人物外形或物体部件数量保持稳定。
```

**向前延长**：先描述原视频之前发生的内容，再把原视频首帧写成延长片段的**明确结束状态**；结尾补一句 `只属于原视频后续的角色、道具或特效不得提前出现。`

### 8.6 关键帧锚点

- 固定首帧必须**单独成句**：`@图片1作为首帧。`
- 固定尾帧同理：`@图片2作为尾帧。`
- **不得**弱化为"仅作为首帧参考""参考开场构图"
- 首帧锁定输出画幅，首尾帧应使用相同画幅

### 8.7 宫格分镜

```
@图片1提供<N格宫格分镜>的镜头顺序和大致构图，按照<从左到右、从上到下>的顺序读取；不采用图中的<线稿画风、文字标注或占位人物>。
镜头1：<景别、主体动作、场景状态>。
镜头2：<景别、主体动作、运镜或切换方式>。
……
```

> 宫格图**不会严格对齐**分镜内容；要严格控制就用多关键帧参考。推荐**火柴人/线稿分镜**，不推荐过度锐化或写满字的 AI 直出分镜图。

### 8.8 白模参考

- **粗粒度**：简单几何体，只提供动作路径/站位/机位/运镜/切镜；**每个几何体必须单独映射**到最终主体
- **细粒度**：结构完整，用于换形象/材质/颜色/风格，保持原结构动作镜头
- 白模视频**不会**因为它是视频就自动成为编辑母版
- 含轨迹线/坐标轴/相机锥体时，明确声明**不采用这些制作标记**

## 九、摄影与情绪写法

### 运镜（专业摄影表达）

```
热门运镜方式 + 作用主体 + 起始位置/状态 + 运动方向 + 到达位置/状态
```

热门运镜：一镜到底、希区柯克变焦、航拍视角、FPV、子弹时间、手持镜头、回弹变速。

**小众术语要展开成可观察结果**：
> 浅景深 → 说明主体保持清晰、背景如何虚化
> 移焦 → 说明焦点从哪个对象转到哪个对象
> 焦距/光圈/快门数值**只能补充，不能代替可见结果**

### 情绪（可观察表现）

```
情绪或氛围方向 + 触发事件 + 人物可观察表现 + 镜头/光线/声音的可观察变化
```

- 选**少量最清楚**的眼神、眉头、嘴角、呼吸、视线、手部、姿态，**不要堆满所有微表情**
- 多次情绪转折才按触发事件分阶段

范例：
> 整体情绪从克制的期待转为失落后的强装平静。看到服务员把退回的信放到桌面后，女人摩挲杯沿的手指突然停住，视线落在信封的退回标记上。她的眉头轻轻收紧，嘴角的微笑逐渐消失，缓慢吸气后把信封翻面扣在桌上。最终她抬眼看向对面的空椅，肩膀保持挺直，用平静但略微发紧的声音说：`{我知道了。}`

> **与本 skill 表演引擎的关系**：本 skill 的「心理动机 → 外显动作」= 官方的「触发事件 → 可观察表现」。两者合并使用：**动机来自剧情，触发来自画面，表现落到生理**。

## 十、症状 → 处方（遇到问题直接查）

| 症状 | 处方 |
|---|---|
| 角色能动但走法不对 | 补**匹配的动作参考视频**，明确"借用什么/不带入什么" |
| 武器拿不稳 / 滑出手掌 | 先生成一张「人物正确拿住武器」的**组合图**核对，原图仍负责外观 |
| 武器外观有了但细节不对 | 单独绑**武器参考图**，别让角色图承载武器细节 |
| 技能做出来了但镜头自行推近 | 把"固定镜头"写实：**机位/焦距/主体占比/背景边界不变 + 逐项禁止推拉摇移抖裁** |
| 动作顺序对但快慢/停顿不对 | **清理无关尾帧 → 降低参考速度 → 按段写清构图/景别/主体大小/镜头/特效** |
| 特效参考图里的细节没做出来 | 按原始分辨率**分区读图**，把"哪个部位、怎样变化"逐条转写进 Prompt |
| 多份素材互相打架 | 先分「保持什么/替换什么」，再明确各自参考来源 |
| 多个步骤挤在短片里 | 先保**关键流程**，再分配镜头时长；**不够就加时长，别硬塞** |
| 连续改了好几轮 | 每轮以**上一轮结果**为输入，说明这次改什么、之前哪些保留 |
| 延长后接不上 | 明确"承接尾帧/衔接首帧"，并写明保持项清单 |
| 出现未授权的多余元素 | 写**正向的允许范围**（允许哪些敌人/世界边界），而不是只写"不要" |
| 画面糊成一团 | 检查是不是同时叠了雾+光晕+颗粒+扩散（**软化最多两种全强度**） |
| 结果不符预期 | **先对照输入定位具体问题**，再决定改素材 / 改 Prompt / 多生成候选 |

## 十一、生成后诊断（第5.5站用）

### 诊断顺序（不得跳步）

1. 核心任务是否完成
2. 硬性约束（主体/武器/场景/文字/品牌）是否满足
3. 时间连续性（动作/故事/特效）是否成立
4. 镜头、节奏、视觉质量是否达标
5. 对照素材职责：是"参考正确"还是"错误复制了不该参考的维度"
6. 给出归因与下一步

### 五类归因（必须且仅能选一个主归因）

| 类别 | 证据 | 下一步 |
|---|---|---|
| **Prompt 问题** | 指令缺失/含糊、顺序不清、绑定错误、约束冲突 | 只改与证据直接相关的段落 |
| **参考素材问题** | 关键外观只靠文字、角度不足、素材冲突、动态参考不匹配 | 指明需补充/替换的具体素材 |
| **运行参数问题** | 内容超时长、比例不合适、镜头数与时长不匹配 | 调比例/时长/内容密度；**未经同意保留用户硬性参数** |
| **模型随机性** | **多个可比的有效运行**、失败位置不固定、且**至少有一个正常候选** | 保持方案，建议增加候选 |
| **模型能力问题** | Prompt 明确、素材充分、参数合理，且**连续 3 次**可比有效运行均失败于**同一**可观察要求 | 停止叠加 Prompt，记录能力边界或改方案 |

**判据纪律**：
- **单个结果不能证明**随机性或能力问题
- 三个不同失败但没有正常候选 → 结论是"**证据不足**"，不是随机性
- 任一比较项不同 → 只能记"证据不足"
- 没有证据 → 写"**无法判断**"，写明缺失原因，**不得虚构时间戳或画面帧**

### 单问题表达（五项，缺一不可）

```
问题：<可观察的未达成项>
证据：<时间 / 主体 / 变化>
归因：<五类中选一个>
处理：<建议，等用户授权>
复测标准：<下次如何判定通过>
```

### 修改纪律

- 每轮只处理 **1–3 个**主要问题
- **单个异常不得触发整体重写**
- 身份/武器/品牌/精确外观有缺口 → **优先补素材**，不是加文字
- 内容过载 → 减少可选事件或镜头，或加时长；**绝不擅删硬内容**
- 最多列 3 项修改建议并排序

## 十二、核心铁律（写 Prompt 前过一遍）

1. **意图优先**：不改人物身份数量、道具、场景、因果、空间关系、编辑对象、延长方向、故事结果
2. **模板优先**：必须套模板重组，**不能只做同义改写**
3. **素材逐份负责**：未分配职责的逐个列入 `【未采用素材】`
4. **用户映射优先**：用户指定的职责与关系不得被自动判断覆盖
5. **最少澄清**：能从上下文判断的直接做，只对**会改变核心结果**的歧义合并问一次
6. **只写可提交内容**：Prompt 内不得出现分析过程、评测说明、模型版本、修改理由
7. **参数分离**：画幅/时长/分辨率/帧率/声音开关不进 Prompt
8. **不滥加约束**：不得自动添加用户未要求的画质包、稳定包、水印、Logo、字幕或通用负向包
   > **与本 skill 的关系**：第2站用户**主动选定**的 LOOK 卡（含全局质量提示词与避免清单）属于**用户授权**，可用；但**不得在此基础上额外叠加**"无噪点/无水印/HDR"这类通用负向包。
9. **单一最佳版本**：默认只输出一个最合适的；用户明确要求对比才出多个
10. **事实与观察分离**：身份年龄关系以用户文字为准；素材只补充可见属性
11. **主体基数匹配**：单人设定图不得定义两个会同时出场的命名人物

## 十三、输出合同

- 默认**只输出 Prompt 正文**，不加 Markdown 标题、代码围栏或前后包装
- Prompt 内可保留 `【生成目标】`、`【参考素材职责】`、`【事件脚本】`、`【保持一致】` 等任务内标签（属于正文）
- 素材引用保留用户原有形式（`@图片1` / `@Image 1`），**不擅自翻译或重新编号**
- 用户写了的引用**一律保留**，不因当前无法读取素材而删除或改写
- 确有必要时，正文后**最多追加一行** `素材提示：` 或 `参数提示：` 或 `补充说明：`
