# 镜头构图引擎

> 用途：第4站「拆镜头定单帧」时使用。核心是 **cinematic-prompt-engine 九层架构的中文版**，把每个镜头先定格成一帧静态画面。

---

## 一、九层单帧模板（第4站核心 · 全中文）

每个镜头写一张「单帧」，按九层各写一句，合成一段连贯的中文描述；末尾挂第2站【全局质量提示词】。

### 九层结构总表

| 层 | 中文名 | 写什么 |
|---|---|---|
| ① | 场景 | 主体/人物 + 正在进行的动作或环境瞬间（像抓拍的一帧，不是摆拍清单） |
| ② | 构图 | 景别 + 画面比例 + 机位角度 + 构图（人物占位/动线/前后景/留白） |
| ③ | 景深 | 一个有物理动机的前景，或一种不遮挡主体的纵深手法 |
| ④ | 摄影机 | 机身 + 镜头 + 光圈（浅景深虚化等） |
| ⑤ | 灯光 | 光型 + 光源位置方向 + 补光 |
| ⑥ | 色彩质感 | 色板 + 饱和度 + 胶片/颗粒/光晕 |
| ⑦ | 情绪 | 情绪氛围 |
| ⑧ | 真实感 | 真实感锚点（皮肤/材质/清晰度/影调） |
| ⑨ | 避免 | 一行负面清单 |

### 每层写法要点（吸收 cinematic 的纪律）

- **① 场景**：用户场景是静态的，就轻轻改写成「进行中的一瞬间」，并先提示用户一句；绝不变更主体、地点、意图。两个以上主体时加一句「视觉中心是 X，其余为衬托 X 的环境层」。
- **③ 景深**：只用**一种**纵深机制，不堆雾/霾/模糊。有前景元素就保留；没有就从三项里三选一——①明暗/轮廓光分离主体、②距离渐变的空气透视（越远对比越低、去饱和、偏冷，但结构轮廓仍清楚）、③遮挡/尺度递进。真空、太空不带大气雾（除非场景自带尘埃/气体）。
- **④ 摄影机**：机身名作真实感锚点（35mm 电影机、50mm 镜头等）。
- **⑧ 真实感**：
  - 画面有人 →「皮肤保留真实毛孔瑕疵，表情自然未经摆拍，所有材质保留真实纹理瑕疵」；
  - 无人 →「所有材质保留真实纹理与自然瑕疵」；
  - 加清晰度锚点：`成像干净通透，主体细节清晰锐利（光学锐度非数字锐化），颗粒与光晕仅作质感点缀、不得掩盖细节`；
  - 夜景/暗部重的再加：`暗部深邃而纯净，无噪点污染，深黑处依然通透`；
  - 浅景深再加：`焦外为真实镜头光学虚化，背景结构连贯可辨，绝无涂抹感`。
- **⑨ 避免**：按当前风格写一行**有针对性的**清单，不要写「不过饱和/不HDR」这种万金油——有些风格就是要饱和和光晕。

### 软化预算（防整张图糊掉）

颗粒、光晕、雾、扩散、笔触柔化**最多两种全强度**，其余削弱或省略；强浅景深时不再加物理雾或扩散。

### 完整单帧示例（电影实拍写实风格）

```
① 场景：雨夜，一个中年男人靠在潮湿的卷帘门旁抽烟，烟头是画面里唯一的暖色光点。
② 构图：中远景，16:9，低机位，男人位于画面右侧中景面朝左，前景雨檐虚化，大面积暗部留白，烟头红点放在画面黄金分割处。
③ 景深：前景雨帘轻微虚化制造窥视感，不遮挡主体。
④ 摄影机：35mm 电影机，50mm 镜头，f/1.8 浅景深。
⑤ 灯光：冷蓝主光从左侧巷口进来，暖黄烟头光作补光，面部半明半暗。
⑥ 色彩质感：低饱和冷蓝为主，夜色浓黑有密度，细颗粒做质感点缀。
⑦ 情绪：疲惫、放空、孤独。
⑧ 真实感：皮肤保留真实毛孔瑕疵，表情自然未经摆拍；成像干净通透，主体锐利，颗粒仅作点缀不盖细节；暗部深邃纯净无噪点。
⑨ 避免：不要过曝死白，不要塑料皮肤，不要颗粒糊脸。

[全局质量提示词]
```

## 二、拆镜头总则

### 文戏拆法（剧情/对话/关系变化）

- 按**剧情节拍**拆，不按句子机械拆。
- 可成镜的节拍：入场、开门、审视、问答、反应、道具、沉默、尴尬、拒绝、冲突升级、环境建立、关系变温、底线显现。
- 拆镜时每镜记录字段：`镜头/时长/景别/运镜/画面/构图/表演/角色出场/结果/音效/台词`（表演字段写法见 performance-engine.md）。
- 一组总时长 **≤ 13.5 秒**。

### 武戏拆法（打斗/追逐/连续动作）

- **先缩写文案**：把故事压成若干句复合句，每句 =「谁做了什么 + 关键结果」，总时长锁 15 秒，越短越好。
- **再按时间轴拆**（0-3s / 3-6s …），相邻节点必须写构图衔接（人物从哪移到哪、景别怎么变、运镜方向是否切换）。
- **每节点含表演**：肌肉/眼神/呼吸/发力，紧跟动作后，逗号分隔、简短。

## 三、景别与运镜术语表

### 景别

| 中文 | 英文 | 说明 |
|------|------|------|
| 极特写 | Extreme close-up | 眼睛、嘴、细节 |
| 特写 | Close-up | 面部填满画面 |
| 近景 | Medium close-up | 头和肩 |
| 中景 | Medium shot | 腰以上 |
| 中远景 | Medium long shot | 膝以上 |
| 全景 | Full shot | 全身 |
| 大全景 | Extreme wide shot | 环境主导 |

### 运镜

| 中文 | 英文 | 说明 |
|------|------|------|
| 固定 | Static | 不动 |
| 摇 | Pan | 水平旋转 |
| 俯仰 | Tilt | 垂直旋转 |
| 推 | Dolly in | 靠近主体 |
| 拉 | Pull back | 远离主体 |
| 跟 | Tracking | 跟随主体 |
| 升降 | Crane | 垂直运动 |
| 环绕 | Orbit | 围绕主体 |
| 手持 | Handheld | 呼吸感 |
| 稳定器 | Steadicam | 平滑浮动 |
