# 角色设定资产规则（四招 + 两条实战补充）

> 用途：第3站建角色资产时照做。目的只有一个 —— **让模型只从设定图取"这个人是谁"，不取任何会污染后续镜头的多余信息。**

---

## 角色设定生成规范 v1（完整流程）

> 本项目实测出来的角色设定生成方法。后续所有角色设定按这个顺序执行。

### 0. 先定身份与结构

- 长相、发型、服装、四格布局先定。
- 四格 = 面部特写 + 全身正面无头 + 全身正侧面无头 + 全身背面保留头部。
- 无头身体版本：面部身份只从面部特写取；身体比例、服装从无头视图取。

### 1. 先做风格样张，和用户讨论选风格

- 同一角色做 2–4 档风格样张（纯写实 / 偏顺 / 色块 / 高级 CG / 其他），只用于讨论和比较。
- **由用户选择本次风格；不要把某一种风格固定成默认。** 不同项目、不同角色可以选不同风格。
- 选中后，把这个风格写进**本项目的风格卡/全局质量词**，只对本次项目生效。
- 风格写在第一句；目标是风格化时，不要写实锚点。
- 参考图同时锁画法：写“参考图也提供笔触/材质”，不是只取长相服装。

### 2. 按选定的风格做细节图

- **先定风格，再做细节图**；细节图的画法必须匹配选定的风格（写实就做写实材质，高级 CG 就做高级 CG 材质，色块就做色块材质）。
- 材质拆开：皮夹克、棉布/内搭、丹宁/裤子、头发、皮肤、靴子、金属五金。
- 100mm 微距，近工作距离，材质填满画面；一盏大柔光 + 一盏硬边轮廓光/掠射光。
- 只留材质、缝线、五金、边缘磨损；不要整件衣服/整只鞋/人物轮廓。
- 中性灰底、均匀柔光，避免把别的光带进镜头。
- 7 张单图 + 1 张无文字材质板（供一次引用）。

### 3. 引用角色参考 + 细节图，指定每张的作用，再生成设定图

- 参考图 1 = 角色参考（身份、发型、服装、四格结构）。
- 参考图 2..N = 细节图（材质/五金/发丝/皮肤），每张只承担一件事。
- 在提示词里逐张写清：这张参考提供什么、不采用什么。
- 再生成角色设定图；保持无头身体版本。
- 脸部干净：哑光、均匀、通透，没有色斑/雀斑/暗沉/黑眼圈/脏点；笔触只留在衣服和背景。

### 4. 验收

- 皮肤：不油、不黄、不脏、不斑。
- 头发：顺滑成束、分界清楚、不打结、不结团。
- 材质：皮革粒面/缝线/拉链齿、丹宁织纹/双缝线、金属拉丝/划痕、靴子磨砂皮/鞋眼。
- 四格：正面/侧面无头，背面保留头部。
- 风格：高级 CG，不粗犷、不光滑。

### 5. 归档

- 未确认 → `<角色>_待确认`；确认后 → 设定文件夹根下（不建 `_确认` 子文件夹）。
- 材质参考 → `06_参考/材质_<角色>`。
- 旧材质 → `99_废弃与归档/材质迭代`。

### 6. 单帧引用规则

- 一次最多 3 张参考；每张只承担一件事。
- 角色母版 + 对应材质（头发镜→头发微距；夹克镜→皮革微距；手部→皮肤/金属微距）+ 场景。
- 材质图只在材质是画面重点时引用；全身远景用母版即可。

### 7. 踩坑表（实测）

| 坑 | 真因 | 改法 |
|---|---|---|
| 纯文字生成 | 服装/场景漂移 | 必须带设定图/场景图参考 |
| 风格词放末尾 | 被写实描述压过 | 风格写第一句 |
| 写实锚点（35mm/真实毛孔/真实光学虚化） | 把风格拉回写实 | 风格化 3D 改用虚拟摄影机/等效焦段 |
| 参考图只锁长相服装 | 画法丢失 | 写“参考图也提供笔触/材质” |
| 材质参考拍成衣服局部 | 读不到纹理 | 100mm 微距、材质填满画面 |
| 真实皮肤结构 + 细腻材质 + 色块 | 脸部色斑/暗沉 | 写“干净均匀通透，笔触只留在衣服” |
| 发丝成束 | 打结/结节 | 写“顺滑成束、分界清楚、不打结” |
| 暖橙高光 + 低饱和 | 蜡黄肤色 | 写“中性色温、肤色准确不偏黄” |
| 参考图太多 | 稀释身份 | 一次 2–3 张，每张一件事 |
| 把风格固定成一种 | 后续项目被锁死 | 风格只由用户选，写进项目风格卡，不写进 skill 默认 |

## 第一招 · 分离全身与面部

**问题**：全景 / 全身镜头里人脸占比太小，全身照提供不了足够的面部信息，
反而会用模糊的脸去干扰模型。

**做法**：
- 全身图（正面 / 背面）**处理成无头版**——只保留身体比例、服装、发型轮廓；
- **单独提供一张高清面部特写**；
- 强制拆分取值：**面部身份只从面部特写取**，身体比例与服饰只从全身图取。

**效果**：面部身份只有一个来源，人物漂移明显减少。

> 落地写法（素材职责）：
> `@图片1 只提供面部五官与皮肤；@图片2 只提供身材比例与服装；两者的发型以 @图片1 为准。`

---

## 第二招 · 保留自然眼神光

**眼神光是真实感的关键**：它让人物在眨眼、转头、表演时"是活的"。

**做法**：
- 设定图里**保留一点自然眼神光**（窗光反射、柔和的点状高光）；
- **避免**环形打光灯那种正圆高光；
- **避免**彩色强烈高光（霓虹、彩色灯条）。

**原因**：这些突兀的光源特征会被**带进后续所有场景**——
设定图里那道环形光，会在每个镜头里都出现一次，破坏整体一致性。

---

## 第三招 · 设定图趋于中性

**目的**：给模型最干净的参考，减少一切可被误抄的元素。

**做法**：
- **纯灰色背景**（不要场景、不要渐变、不要环境光）
- **均匀柔光照明**（不要硬光、不要明显高光与阴影、不要戏剧光比）
- **画面里不要任何颗粒感**
- 皮肤质感**偏哑光**，但**保留毛孔与真实皮肤纹理**（哑光 ≠ 磨皮）
- 不要文字、不要标注、不要分格线

---

## 第四招 · 单独建立状态资产

**场景**：角色要流汗、受伤、血迹、换装。

**做法**：
- **永远从原始母版设定图出发**；
- 可用 AI 辅助改，但改完**只提取真正变化的区域**（伤疤 / 血迹 / 汗水），
  **贴回原始母版**；
- **禁止对同一张设定图做两次以上的迭代加工**。

**原因**：每多迭代一轮，**皮肤纹理与五官就多一次漂移**，
脸会越来越对称、越来越像塑料——这是不可逆的。

> 换句话说：**设定图是母版，状态是贴图。** 不要拿"改过的设定图"当新的母版。

---

## 补充一 · 设定图的"表情"必须显式排除

**踩过的坑**：设定图通常是拍证件照那种**面无表情的冷脸**。
模型会把这张脸当成"这个人的长相"，于是**每一个镜头都是冷脸**——
写多少"要笑"都没用，试了三轮文字全部失败。

**规则**：在素材职责里，把"表情"和"长相"拆开写：

```
只采用设定图上的长相、发型、发色、服装，
不采用设定图上这个人的表情——那只是拍证件照的状态，不是表演。
这一格的表情一律按本格写死的来。
```

**进阶做法**：当某一整段需要他"是笑的"，**单独做一张"微笑版设定图"**
（同人、同脸、同服装、同姿势、同灰底四格，只把表情换成微笑），
在这一段里改挂这张。一次就治好了文字治不好的问题。

> 通用规律：**参考图会连"它当时的状态"一起被抄走。**
> 所以素材职责里必须逐项点名"不采用它的 X"——**漏掉哪样，模型抄哪样。**

---

## 补充二 · 版本选择：A / B 双跑，别只跑一版

同一段提示词、同一个模型，**不同批次的结果会随机**（表情、手势、构图都会漂）。

**规则**：
- 每个关键格至少出 **2 版**；
- 用同一套检查标准过一遍再挑；
- 检查项固定三项：**头发 / 表情 / 透视**。

**透视检查要点**：人物有没有浮空、脚踩的地方对不对、两人大小比例、地面线条与影子方向是否一致、有没有肢体错位。
（转圈、后仰托背、牵手这类姿势最容易崩。）

---

## 补充三 · 材质参考用微距，不用衣服局部

**问题**：材质参考拍成“衣服局部”（整件夹克的肩、整双鞋），模型只能读到“这是一件皮衣”，读不到粒面、缝线、拉链齿。

**做法**：

- 100mm 微距，工作距离很近，材质表面填满画面
- 一盏大面积柔光 + 一盏硬边轮廓光，掠射光把纹理和高光打出来
- 画面里只留材质、缝线、五金、边缘磨损，不要整件衣服 / 整只鞋 / 人物轮廓
- 每张材质图只承担一件事：皮革、棉布、丹宁、头发、皮肤、靴子、金属分开做
- 材质图必须中性灰底、均匀柔光，避免把别的光带进镜头

---

## 补充四 · 脸部要干净，笔触留给衣服

**问题**：写“真实皮肤结构 + 细腻材质 + 克制的色块”，模型会在脸上加色斑、暗沉、斑驳色块，看起来脏。

**做法**：

- 皮肤写“哑光、干净、均匀、通透；没有色斑、雀斑、暗沉、黑眼圈、脏点”
- 面部不画斑驳笔触；笔触只留在衣服和背景
- 材质参考图只取衣服和五金的材质，**不要取它的皮肤纹理**
- 需要血色时只写“脸颊一点轻微血色”，不写“真实肤色/自然肤色”让模型自由发挥

---

## 验收清单

- [ ] 设定图：灰底、均匀柔光、无颗粒、哑光但有毛孔
- [ ] 眼睛里有自然眼神光，不是环形灯、不是彩色高光
- [ ] 全身与面部已分离（或至少：面部只从面部取）
- [ ] 素材职责里写明了"不采用它的表情"
- [ ] 状态变化是从母版贴图，不存在"迭代两次以上的设定图"
- [ ] 每格至少两版，三方检查（头发 / 表情 / 透视）都过
