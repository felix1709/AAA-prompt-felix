# 风格资产库（LOOK 卡）

> 用途：第2站问风格时，从这里列预置 LOOK 卡供用户选择；用户也可描述新风格，由你现场生成一张新卡。
>
> 每张卡必备字段：配色 / 渲染 / 光线 / 质感 / 情绪 / 全局质量提示词 / 避免清单 / 特殊引擎关联。
> **全局质量提示词**选卡后贯穿全案，挂载到第3/4/5站每一段提示词末尾，全篇不改。
>
> **新增一张卡的方法**：按下方格式填满字段即可；「特殊引擎」栏填 `h3-PV-test-doubao` / `film-darkroom-prompt` / `无`。

## LOOK 卡 1：电影实拍写实　〔特殊引擎：无·主线默认〕

- **配色**：自然色，电影级调色，暗部有密度不发灰
- **渲染**：真人写实电影质感，35mm 电影镜头，真实胶片实拍
- **光线**：自然光影，浅景深，眼神光自然，环境光真实反射
- **质感**：真实皮肤纹理毛孔，自然布料褶皱，发丝物理真实，电影颗粒
- **情绪**：电影叙事沉浸感，镜头呼吸感

**全局质量提示词**：

```
真人写实风格，电影级摄影，自然光影，真实皮肤纹理毛孔，自然布料褶皱，环境光真实反射，浅景深，电影颗粒，35mm电影镜头，手持呼吸感，色温自然，肤色还原准确，发丝物理真实，自然运动模糊，电影级后期调色，高清晰度
```

**避免**：塑料皮肤，棚拍级完美布光，广告片质感，过度磨皮，CG感

**适用模型**：Seedance 2.0 / 5.0、通用生图

## 扩展风格语法卡（16 张 · 第2站可选）

> 前三张是**基础质量卡**，自带【全局质量提示词】。
> 下面 16 张是**叙事风格语法**，讲的是"这场戏该怎么被看"，不自带质量词。
>
> **用法（必须遵守）**：选中任意一张扩展卡后，仍要从上面三张基础卡里**挂载一张**，产出【全局质量提示词】。
> 扩展卡负责「风格方向」，基础卡负责「画质质感」，两者组合使用，缺一不可。
>
> 这 16 张**不触发第6站特殊引擎**，一律走主线。

---

### 1. 观察式社会现实　〔挂载：卡1〕

- **适合的戏**：劳作、公共空间、家庭压力、普通机构
- **故事引擎**：社会处境通过日常流程显现，不靠台词解释
- **光线**：只有可解释的现成光源；光照不到的地方保持暗
- **配色**：克制的本地色；皮肤和墙面接受不均匀曝光
- **空间**：环境与机构几何和人物同等重要
- **材质**：磨损来自重复使用、维护、天气和阶层条件
- **调度/机位**：人物处在实际作业位置，很少外放情绪；耐心的旁观距离，有时被建筑挡住
- **不要**：苦难奇观、贫困抒情、英雄式劳动者肖像、美化破败

### 2. 家庭余波　〔挂载：卡1〕

- **适合的戏**：争吵、离开、秘密、疲惫、家庭日常被打断
- **故事引擎**：事情已经过去了；错位的物件和没做完的事承载后果
- **光线**：窗光或实景光不均匀地落在有人生活的房间里
- **配色**：熟悉的居家颜色在阴影或傍晚光里掉饱和度
- **空间**：门槛、空椅子、台面、相邻房间揭示关系
- **材质**：杯子凉了、布料起皱、食物变干、水渍留着
- **调度/机位**：身体分到不同区域，手继续做一件没必要的小事；从门口、走廊或坐着的视点安静地看
- **不要**：含泪特写、完美室内陈设、符号化道具堆砌、煽情逆光

### 3. 夜间程序　〔挂载：卡1〕

- **适合的戏**：维护、调查、运输、医护、安保的例行工作
- **故事引擎**：一个重复的任务在继续，疲劳或隐患在累积
- **光线**：实景光源区之间隔着阴影；外面的溢光是次要的
- **配色**：由具体光源带来的脏色，不是全局青橙调
- **空间**：走廊、泊位、车辆、台面、门禁边界组织画面
- **材质**：油、玻璃、金属、反光胶带、皮肤、制服反应各不相同
- **调度/机位**：工具和工作顺序决定姿势与距离；从一个有用但不特权的作业位观察
- **不要**：泛指霓虹黑、战术英雄姿势、装饰性烟雾、一尘不染的设备

### 4. 旅途记忆　〔挂载：卡1；要怀旧暖调改挂卡2〕

- **适合的戏**：公交、火车、汽车、渡口、车站、临时分别
- **故事引擎**：外面的移动和人物内心停在某件事上形成对照
- **光线**：掠过的光源、车窗反射、站台溢光，或天将亮时的过渡
- **配色**：混杂的交通光，因移动带一点曝光漂移
- **空间**：层叠的玻璃和重复的座椅把私密和公共压在一起
- **材质**：水汽、震动、磨旧的座椅、票、行李都保持因果
- **调度/机位**：坐着或站着的人通过过道、车窗、空位建立关系；像同车的乘客或站台上的目击者，不做全知的怀旧
- **不要**：到处梦幻虚化、旅游广告式美、随意镜头光斑、完美的思念姿势

### 5. 历史材质现实　〔挂载：卡1〕

- **适合的戏**：年代劳作、家庭生活、机构、出行、非英雄式历史
- **故事引擎**：历史通过人必须动手做什么显现，不靠排场
- **光线**：那个年代能有的光源；阴影保持物质性的厚重
- **配色**：染料、涂料、金属、烟、日光都保留当时的限制
- **空间**：门、灶、街、作坊、交通依然好用，拓扑清楚
- **材质**：包浆跟年龄和把玩有关，不是装饰性的"复古处理"
- **调度/机位**：服装结构、工具、家具、礼数限制动作；观察者站在年代建筑里可以站的位置，不是博物馆展台
- **不要**：戏服走秀、幻想式洁净、万能棕褐、穿越的器具

### 6. 静默悬念　〔挂载：卡1〕

- **适合的戏**：隐瞒信息、擦肩而过、延迟发现、模糊的威胁
- **故事引擎**：一个普通动作在继续，而第二个事实改变了它的含义
- **光线**：光源有主次，藏起一个相关区域，但不靠戏剧性死黑
- **配色**：克制，用曝光而不是点缀色来控制注意力
- **空间**：走廊、反射、门、纵深制造延迟的信息
- **材质**：窗帘、液体、灰尘、松动物件的一点小动，暗示后果
- **调度/机位**：人物面对不同的信息区，视线不解释全部；比人物多知道一点或少知道一点，站在可信的边界上
- **不要**：荷兰角、明显的反派剪影、恐怖片蓝光、跳吓式构图

### 7. 天气承载的亲密　〔挂载：卡1〕

- **适合的戏**：被雨、雪、热、风、潮湿塑造的克制关系
- **故事引擎**：天气改变人怎么共用遮蔽、距离、衣物和物件
- **光线**：天气改变真实光源、能见度和表面高光
- **配色**：大气衰减与颜色污染跟着距离和湿度走
- **空间**：遮蔽的边界和暴露区构成情感距离
- **材质**：布料重量、皮肤、玻璃、路面、呼吸、头发都有物理反应
- **调度/机位**：身体在伞、外套、热度、湿座位、有限遮蔽之间协商；镜头留在同一种天气里，不站在绝对安全处围观
- **不要**：雨中机位的浪漫化、万物统一水光、装饰性雾、MV 式拥抱

### 8. 职责之地　〔挂载：卡1〕

- **适合的戏**：偏远作业、巡逻、农业、基础设施、大空间里的照护
- **故事引擎**：职责在尺度、孤立或缓慢环境变化中继续
- **光线**：大范围环境光为主，有理由时才补局部实景光
- **配色**：风景主导色彩，人不获得广告式的分离打光
- **空间**：路径、屏障、地平线、作业区解释移动
- **材质**：风、尘、水、锈、植被、衣物显示长期暴露
- **调度/机位**：人保持小而有意地排在路线与设备之间；远处的目击者，位置尊重地形与可达性
- **不要**：旅游全景、默认无人机奇观、孤胆英雄剪影、史诗调色

### 9. 偶发时尚感　〔挂载：卡1〕

- **适合的戏**：普通行为偶然形成视觉上紧绷的排列
- **故事引擎**：一个没被摆拍的事件，恰好让服装、手势、建筑对齐
- **光线**：现成光制造图形化分离，但不带广告片抛光
- **配色**：服装色可以领一次，但皮肤和环境保持自然
- **空间**：线条与负空间来自场地本身，不是搭出来的
- **材质**：布料褶皱、重量、天气、运动都看得见
- **调度/机位**：不对称和身体角度来自动作，绝不走台步；从一个可信的经过位置抓到这个对齐
- **不要**：时尚摆拍、广告布光、奢侈商业抛光、完美的服装陈列

### 10. 都市异物现实主义　〔挂载：卡1〕

- **适合的戏**：当代普通城市里出现**一个**不寻常的人、衣物或物件
- **故事引擎**：只有一样东西不正常，日常系统照常运转
- **光线**：城市现成光源照它，不用"揭示"式打光
- **配色**：城市保持普通，异物不给全世界换色
- **空间**：车位、电梯、办公室、道路、护栏完全写实
- **材质**：异常材质对混凝土、雨、灰、荧光灯做出物理反应
- **调度/机位**：异常物遵守和其他一切相同的重力、通行与社会距离；像路人或边缘目击者那样看
- **不要**：完整奇幻世界、赛博朋克化、戏剧化的围观反应、全球性异象

### 11. 基础设施崇高　〔挂载：卡1〕

- **适合的戏**：隧道、排水系统、电站、机场、港口、大坝、工业设施
- **故事引擎**：人的流程在一个大到一眼看不全的系统里继续
- **光线**：工业实景光和环境溢光只揭示系统的一部分
- **配色**：功能漆色、混凝土、金属、天气、安全色主导
- **空间**：重复的结构单元和通行路线建立尺度
- **材质**：质量、湿度、腐蚀、粉尘、震动、高温都有物理后果
- **调度/机位**：人保持小，绑在通道、车辆、控制台或安全区；站在可达的作业位，不是不可能的俯拍位
- **不要**：泛指科幻巨构、不可能的架构、默认无人机奇观、微缩英雄崇拜

### 12. 边缘目击　〔挂载：卡1〕

- **适合的戏**：私密手势、社会距离、不确定、够不着的事件
- **故事引擎**：部分可达让观众自己补出关键
- **光线**：遮挡物本身有自己的曝光和反射行为
- **配色**：前景遮挡不变成装饰性色框
- **空间**：遮挡跟着真实的目击位置走，拓扑不乱
- **材质**：玻璃、车漆、布料、车身表面以合理方式影响清晰度
- **调度/机位**：在车后、隔着玻璃、柱子旁、门内侧、帘子后、走廊拐角；动作在部分遮挡和偏轴关系里仍然读得懂
- **不要**：完美前排机位、干净的英雄覆盖、贴上去的遮挡、主体动作看不清

### 13. 静默灾变　〔挂载：卡1〕

- **适合的戏**：大事件通过改变了的日常和小后果来呈现
- **故事引擎**：灾难已经发生；普通行为现在才显出它的规模
- **光线**：天气和残余实景光决定能见度
- **配色**：避免海报级危险色，让环境变化自己说明语气
- **空间**：一条被堵的路、一件不见了的东西、一片受损区、一个改了的流程，锚住这个事件
- **材质**：碎屑、水、尘、灰、破损都有可信成因
- **调度/机位**：人做有限的事，不表演恐慌；在地面、人的尺度上观察后果
- **不要**：爆炸、英雄式奔跑、群体恐慌、灾难海报式构图

### 14. 现实仪式感　〔挂载：卡1〕

- **适合的戏**：穿戴装备、检查机器、关店、卸甲、收工具、备餐
- **故事引擎**：重复的次序显出用心、职责、疲劳或过渡
- **光线**：作业光或现成光优先照亮正在做的那一步
- **配色**：功能色和受控高光把材质状态说清楚
- **空间**：物件各在其位；缺席或位移有意义
- **材质**：触摸、重量、热度、残留、磨损显出重复
- **调度/机位**：手、工具、台面、顺序决定姿态；尊重作业区，不把它纪念碑化
- **不要**：没有依据的仪式奇幻、英雄姿势、把慢镜陈词滥调写成一帧、符号堆砌

### 15. 材质冲突　〔挂载：卡1〕

- **适合的戏**：视觉中心就是一组物理关系——金属与湿混凝土、丝绸与石头、皮肤与玻璃、瓷与雾、油与布
- **故事引擎**：动作把两种材料带到接触或对照里
- **光线**：光源角度体现不同的反射、吸收、透光
- **配色**：颜色跟着材质和光源走，不做装饰性调色
- **空间**：周围空间解释这两种材料为什么会相遇
- **材质**：每种表面对自己的粗糙度、湿度、形变、温度负责
- **调度/机位**：手和物件显出重量、温度、摩擦和风险；近到能读出关系，又保留它的空间成因
- **不要**：随意的材质形容词、所有东西都发亮、不可能的反射、材质属性与光矛盾

### 16. 过渡时刻　〔挂载：卡1；傍晚暖调改挂卡2〕

- **适合的戏**：日出前、日落后、雨刚停、警报刚结束、门刚开、灯刚灭、云刚散
- **故事引擎**：一个光源状态正在变化，而动作还在继续
- **光线**：一个主导性的过渡，阴影与高光有因果地移动
- **配色**：混合色只出现在两组光源重叠照到的地方
- **空间**：门窗、云、灯具、移动的遮蔽解释这个变化
- **材质**：湿度、玻璃、皮肤、布料、金属以不同速度响应
- **调度/机位**：人物对能见度和温度变化做实际反应；机位放在新旧两种光源状态都看得清的位置
- **不要**：永久的黄金时刻、多个装饰性光源、无来源轮廓光、普照式辉光
