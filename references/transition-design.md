# 转场设计知识库

> 用途：第4/5站拆镜与串片时，决定"这一刀怎么接"。
> **总原则：无技巧转场是拼接最优解。** 不用转场特效、不用叠化、不用黑场——
> 靠**动作、视线、形状、节奏**让两刀之间"顺"。

---

## 一、六种可落地的转场（按优先级）

### 1 · 动作接动作（最顺，最不易被察觉）

上一刀结尾正在进行的动作，**在下一刀里继续做**。

```
上一拍：他正要抬手往下放 → 动作到一半切走
下一拍：切过来，手还在原位置、继续往下放
```

**要求**：切过来第一帧必须接得上——**同一个位置、同一个角度、同一只手**。
提示词里要写死"这是上一拍的下一个瞬间，不换手、不换位置"。

> 这是所有转场里最"看不见"的一种，优先用。

---

### 2 · 视线接力（人物看 → 切 → 他看到的东西）

他/她望向画外 → 下一刀就是那个方向上的内容。

```
上一拍：她抬眼看向街道深处
下一拍：他正从街道深处走来
```

**要求**：上一刀的视线方向必须明确（写死看向画面哪一侧），
下一刀的构图要顺着那个方向给。**方向错了观众会觉得跳。**

---

### 3 · 焦点转移替代剪切（同机位里完成"换主体"）

不切，用**焦点的移动**把注意力从一个主体交到另一个主体。

```
起幅：焦点在近处她的手（手清楚、远处虚）
过程：焦点连续地拉向远处
落幅：远处走过来的人清楚、手虚掉
```

**要求**：写死"**不许跳变、不许硬切、不许同时都清楚**"。
一条连续的焦点移动，比硬切更顺，但更难做——要有心理准备多跑几版。

---

### 4 · 匹配剪辑（靠相似元素粘合）

相邻两刀之间有**形状 / 动作 / 方向 / 颜色**的相似性。

| 匹配类型 | 例子 |
|---|---|
| 动作匹配 | 上一刀她抬手 → 下一刀他抬手 |
| 方向匹配 | 上一刀向右走 → 下一刀继续向右走 |
| 形状匹配 | 上一刀圆形光斑 → 下一刀圆形表盘 |
| 颜色匹配 | 上一刀红色衣角 → 下一刀红色车门 |

---

### 5 · 段落信号（每组交界处的"逗号"）

不用转场技巧，用一个**可感知的变化**告诉观众"这一段结束了"。

| 信号 | 写法 |
|---|---|
| **光的变化** | 光从上方漫进来、画面变亮；或变柔、像云散开 |
| **声音的变化** | 环境音整体抽掉；或心跳消失、只剩风声 |
| **元素进出** | 一个之前没有的人影走进画面；或最后一个元素走出画面 |
| **定格** | 镜头停住（**镜头停 ≠ 画面停**：风还在吹、发丝还在飘） |

> 光的变化最省事也最有效：**不用黑场、不用特效，光一变，观众就知道进另一段了。**

---

### 6 · 同机位回环（结构机关）

开头与结尾用**同一个机位、同一个构图**，中间跑一圈再回来。

**效果**：观众在潜意识里感到"闭合了"。
**要求**：两刀的机位、景别、光向必须几乎一致，否则机关不成立。

---

## 二、节奏：本体是"反差"，不是"快"

> 节奏不是剪得快，是**快慢之间有差**。

四种可落地的手法：

| 手法 | 做法 |
|---|---|
| **尺数长短对比** | 主动安排"极短"与"极长"相邻（闪切接长镜、一秒接五秒） |
| **急停** | 视觉停住：突然定格 / 突然升格 / 一次突然的黑场 |
| **情绪突变** | 相邻段落情绪刻意反向（热烈 ↔ 安静） |
| **匹配剪辑** | 见上，用相似元素把两刀粘住 |

### 组内节奏怎么排

- **三短一长**：前三刀各 1 秒上下、一刀比一刀短，最后一刀给足时间——前面越短，最后越有分量。
- **递进收紧**：尺数逐拍递减（如 14/12/10/7 帧），像心跳加速——**慎用**，容易做成煽情。
- **快慢交替**：正常 → 快 → 快 → 慢 → 快 → 慢，落点在最后那个"停"。
- **越切越快然后砸停**：前三拍一个比一个短，最后一拍拉长并定格。

### 落点在哪

> **节奏的落点不是最响的那一下，是停下来的那一下。**

## 三、切点选择（一刀切在哪一帧）

| 情况 | 切在哪 |
|---|---|
| 动作进行中 | 切在**动作最有劲的那一瞬**（不是动作开始、也不是完成） |
| 要隐藏切换 | 切在**运动模糊最大**的那一帧 |
| 要强调停顿 | 切在**动作刚停住**的那一帧 |
| 跨刀连续动作 | 上一刀**切在半路**，下一刀接在同一位置 |

**反面**：切在动作已经完成后 → 观众感觉"卡了一下"。

---

## 四、速度设计

### 变速必须写清"切换点"

```
0-4.2 秒 正常速度 → 4.2 秒起突然升格
```

- **不许整条都正常、也不许整条都慢**（两个方向都要堵）；
- 切换点要绑在一个**可观察的事件**上（"他的肩膀擦过她的椅背那一下""头扬到最高那一下"）；
- **升格用在情绪最高点**，不是用在所有地方——用多了就变成煽情。

### 升格里的拖影

升格时动作被放慢，**拖影会比正常速度柔和**，但慢门的质感仍要在
（发梢、衣摆、花瓣依然是柔的、带方向的）。

## 五、运镜的四种基本型（一条提示词只写一种）

| 运镜 | 写清什么 | 常见误做 |
|---|---|---|
| **固定** | "完全固定，一动不动，不推不拉不摇不晃" | 被做成手持微晃 |
| **手持** | 幅度（占画面宽度百分比）、频率、地平线是否歪 | 被做成稳定器平滑 |
| **环绕** | "绕着他转，不是原地摇" | 被做成横移或摇镜 |
| **推 / 拉** | 景别从什么收到什么 | 推到位却没变景别 |

> **推和拉要分清楚**：写"往后拉"却写"距离缩短"会自相矛盾（两种都出现过）。

---

## 六、一致性检查（跨刀必须一致的东西）

- **左右关系**：他是左是右，换个景别不能翻
- **光向**：影子方向、轮廓光在哪一侧
- **动作轴**：他从哪走向哪，不能中途反向
- **道具位置**：桌上的杯子、画架、空桌，每一刀都要在同一处
- **服装状态**：袖口、领口、腰带，镜头之间不能自己变

---

## 七、验收清单

- [ ] 每组交界处有没有一个"逗号"（光 / 声 / 元素 / 定格）
- [ ] 有没有至少一处"动作接动作"或"视线接力"
- [ ] 相邻两刀的左右关系、光向、动作轴对得上
- [ ] 每一刀只写一种运镜
- [ ] 变速写了切换点，且绑在可观察事件上
- [ ] 落点是"停下来的那一下"，不是最响的那一下
