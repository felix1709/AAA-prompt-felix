# 前期 / 后期分工：单帧管什么、视频管什么

> 用途：一管到底做 AI 片子时，把「风格资产」正确切成两半，分别喂给生图和图生视频。
> 核心原则：**一个视觉属性只属于一个阶段。写两遍 = 两遍叠加 = 打架。**

---

## 一、一句话分工

| 阶段 | 负责 | 不负责 |
|---|---|---|
| **单帧（生图）** | **静态属性**：色调、光的方向与质感、材质、景深、构图、人物造型、服装、发型 | 运镜、速度、动作、运动模糊、时间节奏 |
| **视频（图生视频）** | **动态属性**：运镜、速度变化、运动模糊/慢门、动作、表情变化、物理反应、节拍、声音 | 色调、光、材质、长相、服装（已由首帧锁定） |

> **判断方法**：问一句"这个属性在一张静止照片里存在吗？"
> 存在 → 单帧；只存在于时间里 → 视频。

---

## 二、为什么要分离（踩过的坑）

### 坑 1 · 噪点会叠加

**单帧里写了"胶片颗粒 / 细腻颗粒 / 噪点"→ 图生视频时会再叠一层运动噪声 → 画面变脏、糊。**

原因：视频模型以首帧为基准，还要生成帧间差异与压缩噪声，等于在同一张画面上加两次颗粒。

**规则：**
- **单帧提示词里禁止出现任何颗粒 / 噪点 / 高频纹理的词**；
- 需要颗粒质感 → **放到后期剪辑统一加**（一次，全片一致）；
- 单帧追求的是**干净、结构清楚**——它首先要让视频模型读得懂形状，其次才好看。

### 坑 2 · 风格词写两遍会互相稀释

同一段风格描述既写在单帧、又写在视频提示词里 → 视频模型会"重新理解"一遍风格，可能把首帧改掉。

**规则：**
- 视频提示词**不重描**色调 / 材质 / 长相 / 服装；
- 但要用**一句短锁定句**兜住漂移：
  `沿用首帧的画面、色调、光线与质感——不要改变色调、不要改变质感、不要改变画风。`
- **短锁定 ≠ 重描**：锁定句是"别动"，重描是"再画一遍"。

### 坑 3 · 运动描述写进单帧 → 单帧变成"动感照片"

单帧里写"镜头推近""横向拖影""慢门"，会得到一张**已经带运动痕迹的静帧**，
视频再动起来就是双重运动，看着晕。

**规则：单帧只写"抓到的那一瞬"，不写镜头怎么动。**

## 三、风格参考怎么切（收集完先分类，再落笔）

拿到一批风格参考（海报、截图、参考片）后，**不要整段抄进提示词**，先拆成两张表：

### 表 A · 静态属性 → 写进单帧

| 类别 | 具体项 |
|---|---|
| 色调 | 底色、主色、饱和度、冷/暖、对比度 |
| 光 | 光源方向、软/硬、色温、逆光/侧逆光、高光是否过曝 |
| 材质 | 皮肤质感、发丝、布料织法、环境材质（石/木/金属/玻璃） |
| 景深 | 深/浅、前景是否虚、背景是否成光斑 |
| 构图 | 机位、景别、画幅、留白、遮挡关系 |
| 造型 | 发型轮廓与体积、服装剪裁与配件 |
| 气质 | 一句话氛围（"松弛的下午""冷冽的清晨"） |

### 表 B · 动态属性 → 写进视频

| 类别 | 具体项 |
|---|---|
| 运镜 | 固定 / 手持 / 环绕 / 推 / 拉 / 摇 / 跟随 |
| 速度 | 正常 / 升格 / 变速点在哪一拍 |
| 运动模糊 | 慢门、拖影、背景横流 |
| 动作 | 主位移（从哪到哪）、部位级细节 |
| 表演 | 眼睑、眼球、呼吸、嘴角、肩线、颈部 |
| 物理 | 发丝滞后、衣摆回弹、花瓣翻面 |
| 节拍 | 每拍时长、长短对比 |
| 声音 | 同期声 / 音乐 / 音效 |

### 切分纪律

1. **每条属性只落一处**，落完在旁边标注"已用"。
2. **单帧阶段不要预留"视频再说"的风格**——风格必须在单帧定死。
3. **视频阶段不要补风格**——补了就会跟首帧打架。
4. 若必须让视频阶段的风格变化（如"越走越暖"），**用光线/时间变化描述**，不要重写色调词。

---

## 四、单帧的三条硬约束（给图生视频用）

1. **干净、结构清楚**：形体明确、明暗过渡连续、边缘自然——让视频模型读得懂"这是什么形状、光从哪来"。
2. **不加噪点**（见坑 1）。
3. **抓在动作开头 / 三分之一**：不要抓动作做完的样子。
   - 视频是顺着首帧往下演的，抓在"已经开始"的瞬间才有东西可接；
   - 例外：落版 / 定格格抓最终状态（它本身就是海报）；
   - 慢门格抓"拖影最明显的那一瞬"。

---

## 五、验收清单

**单帧阶段**
- [ ] 全片色调、光、材质统一（同一套风格块）
- [ ] 没有颗粒 / 噪点 / 高频纹理的词
- [ ] 没有运镜 / 速度 / 运动模糊的描述
- [ ] 每一格都是"动作刚开始"，不是完成态
- [ ] 结构清楚：缩到 1/4 大小仍能看出人物与光向

**视频阶段**
- [ ] 没有重描色调 / 材质 / 长相 / 服装
- [ ] 有短锁定句
- [ ] 每一拍只有一个运镜
- [ ] 每拍都有可观察的结束状态
- [ ] 速度变化写清了切换点

---

## 六、单帧质检三件套（每格至少两版，逐项过）

顺序：**头发 → 表情 → 透视**。三项都过才算可用。

### 6.1 头发（最容易翻车，排第一）

**先看三种典型坏相，一种都不能有：**

| 坏相 | 长什么样 | 真因 |
|---|---|---|
| **炸毛** | 顶部炸开一大簇细碎飞丝、额前垂几根孤零零的 | "一根一根看得见"被做成了建模硬管 |
| **湿发 / 刺猬** | 发束细而尖、硬邦邦立着、像刚洗过没吹干 | 把设定图"向上立起"的造型误解成"湿+尖" |
| **糊成一片** | 没有分束、看不出走向、像一团色块 | 细节过密，运动或弱光下会糊 |

**合格标准（逐条看）：**

- [ ] **干爽**：不是湿的、不贴头皮、没有发油反光
- [ ] **蓬松有体积**：一大团向外鼓起来，有空气感
- [ ] **发束是宽的、成片的**：不是一根根细硬发，也不是一团糊
- [ ] **束与束之间有分界**：看得出走向与层次
- [ ] **边缘有一层被光照透的、散开的细发丝**（这是"真实"的关键，不是"炸毛"）
- [ ] **没有**：湿发束 / 细尖发束 / 硬刺 / 零散飞散碎发 / 密集交叉乱发 / 额前孤零零几根垂发
- [ ] **发型形状照角色设定图**：轮廓、体积、走向、分缝都对
      —— **不要从构图参考图继承发型**（参考图的头发经常比设定图更炸、更扎）
- [ ] **男主保留"向上立起"的造型**（那是设定图的一部分），但**质感必须干爽**——"向上"对，"湿"错

> **最有用的一句配方**：
> 「发型形状照角色设定图（包含向上立起的造型），但质感要干爽蓬松柔软、发束宽而成片」。
> 只写"不要刺猬头"会跟设定图打架；把"向上"和"湿"拆开才治得住。

**动态头发（视频阶段的对应项）**
- 一直在动：一阵一阵被吹起、停一下、落回（不是贴在头上不动）
- 大动作时要有三态：**甩出去 → 停一下 → 落回来**
- 甩开的瞬间要：一缕一缕拉开、束与束有分界、发梢边缘逆光透亮、**一根一根看得见**、不是一团糊

### 6.2 表情

- [ ] 跟这一格**要的**一致（不该笑的别笑、该笑的笑到位）
- [ ] **设定图的表情没有被抄过来**（证件照冷脸 → 每格都冷脸，是最常见的病）
- [ ] 用**动作**描述核对：眼睑开合、嘴角位置、眉头平不平、下巴抬没抬
- [ ] 注意"眉形上扬"≠"皱眉"：他天生眉形上挑时，要说"眉间平滑、两眉头之间有距离"

### 6.3 透视

- [ ] 人物没有浮空 / 没有陷进地面
- [ ] 脚踩的位置对（影子落点与地面接触）
- [ ] 两人大小比例合理（身高差、近大远小）
- [ ] 地面线条与影子方向一致
- [ ] 没有肢体错位（手指数目、关节方向、牵手处）
- [ ] 转圈、后仰托背、牵手这类姿势**重点看**

### 6.4 检查口径（很重要）

- **让模型"描述"，不要让模型"判断"。**
  问"眼睛、嘴角、眉头分别什么样"能拿到可用信息；
  问"他开心吗"会把"背影看不到脸"直接判成"不开心"——结论是废的。
- 每格 **A/B 两版**，同提示词不同批次会随机（表情、手势、构图都会漂）。
- 批量出图**串行**，不要并行（会撞限流 429）。
