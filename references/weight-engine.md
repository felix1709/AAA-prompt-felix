# 权重评估引擎（Seedance 权重语法）

> 用途：第5站生视频提示词产出后，做权重优化。用户实测总结，适配 Seedance 全系（2.0 / 5.0）。
>
> **权重优化为可选项**：第5站产出基础版提示词后，必须询问用户是否启用；未启用则输出不带任何权重符号的普通自然语言版。

---

## 一、权重优先级（自上而下递减，分配必须贴合，否则全部加权无效）

```
核心主体人设 & 关键动作 ＞ 时序动态特效 ＞ 运镜景别 ＞ 场景光影 ＞ 氛围画质 ＞ 普通修饰词
```

- 词序前置加权：越靠前的关键词识别优先级越高，复杂镜头严禁乱序堆砌。

## 二、权重分级（唯一不翻车配比，禁止四层及以上叠加，会僵硬失真）

| 写法 | 权重 | 用途 |
|---|---|---|
| `关键词` | 1.0 基础 | 氛围、配色、画质、背景等次要修饰 |
| `(关键词)` | 1.2 轻加强 | 衣纹、发丝、光影质感、粒子细节 |
| `((关键词))` | 1.4 中加强 | 运镜方式、特效形态、场景动态、配饰细节 |
| `(((关键词)))` | 1.5 顶配锁死 | 人物主体、核心动作、姿态约束、关键特效交互（唯一核心加权项） |

## 三、分镜头精准加权实操

1. **静态定帧镜头**（人偶静置、悬浮画面）：顶配锁死 `(((人物姿态凝固、极轻微漂浮、固定构图位置)))`；中配 `((少量鱼群、顺时针慢游、柔和静态光影))`；**不给氛围词加权**，重点压制人物晃动、鱼群泛滥。
2. **特效交互镜头**（能量罩破碎、流光托举）：顶配锁死 `(((特效运动轨迹、破碎时序、托举升空动态)))`；中配 `((光屑四散、流光缠绕、粒子层次))`；特效加权 + 人物姿态保底加权，避免特效穿模、吞噬主体、动作断层。
3. **人物动态转变镜头**（苏醒睁眼、幻化、展翼）：顶配锁死 `(((时序动作唯一执行、睁眼神态、手部幻化动作)))`；多个动作只给主动作顶配加权，次要动作轻加权，杜绝动作重叠、错乱、跳帧。
4. **运镜镜头**（环绕、追随、推拉）：运镜指令中配，不抢主体权重；固定机位弱化运镜权重，防止画面轻微抖动偏移。

## 四、三大黄金使用规则（成片率从 30% → 90%）

1. **权重二八分配**：80% 顶配权重留给主体、核心动作、硬性约束，20% 轻权重给细节、氛围、特效；拒绝全员加权（权重稀释，核心指令失效）。
2. **时序镜头权重隔离**：每段时长镜头独立加权、不跨段叠加；前一段的凝固/沉睡权重在后一段苏醒镜头中取消，避免新旧指令冲突，解决前后不一致。
3. **负面词定向加权压制**：高频崩坏词统一轻度加权 `((畸形手部、穿模、闪烁、卡顿、动态杂乱))`，比普通负面词效果翻倍。

## 五、高频踩坑避雷

- ❌ 所有关键词都加三重权重 → 画面僵硬、细节丢失、特效失真
- ❌ 氛围词放在最前面、主体词后置 → 模型优先识别氛围，主体动作跑偏
- ❌ 跨镜头保留旧权重指令 → 动作衔接错乱、人物状态冲突
- ❌ 不加权约束数量 / 动态 → 鱼群、粒子、流光极易 AI 自主增殖失控

## 六、最终极简落地公式

```
顶配锁主体动作 + 中配强化特效运镜 + 轻配修饰细节光影 + 加权负面控崩坏 + 时序分段隔离权重
```

## 七、权重规则说明（必须写入提示词正文）

**提示词中必须包含【权重规则】段，置于时间轴之前**，让生成模型先理解括号含义，再解析下方时间轴；否则括号会被当成无意义符号忽略。

规则说明段写法：

```
【权重规则】请先理解本规则再阅读下方时间轴：
() 轻微加权——细节修饰（衣纹、发丝、光影、粒子）
(()) 中度加权——特效形态、运镜方式、配饰细节、场景动态
((( ))) 核心强加权——人物主体、核心动作、姿态约束、关键特效交互
[ ] 弱化规避——降低该描述的影响（旧状态、易泛滥元素）
附加：词序越靠前优先级越高；每镜独立加权、不跨段叠加；氛围画质词不额外加权（基础1.0）；负面崩坏词用(())定向压制。
```

> 权重语法默认仅适配 Seedance；其他模型若提示词中含括号，需先确认该模型支持权重语法，不支持则去掉括号、改用自然语言强调（如「极其重要：」「务必保持」）。
