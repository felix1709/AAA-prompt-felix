# 资产模板库

> 用途：第3站建资产（角色 / 场景 / 道具）时按需调用。
> 通用规则：
> 1. 每段资产提示词 = 【模板正文】 + 【第2站定下的全局质量提示词】。
> 2. 素材引用只写资产名（男主 / 女主 / 场景A / 道具1），不写文件扩展名。
> 3. 有参考图 → 以图为准；无参考图 → 把「以参考图为准/去掉背景」改为对特征的文字描述。

---

## 1. 角色三视图模板

### 版本A · 有角色参考图（以参考图形象为准）

```
去掉背景图片中的背景，以参考图的人物形象、服装、发型为准，生成角色的三视图。
背景为纯灰色背景。
需要包含：人物面部特写、全身正面、全身正侧面、全身背面。
三视图横向排列、相互不遮挡，不要出现文字。
[身体比例：男角色写「标准男模身体比例」；女角色写「标准女模身体比例」]
人物有湿润眼神，自然窗光反射，轻微泪膜感，真实眼下阴影，柔软但不直勾勾的注视。
皮肤超写实毛孔清晰，匀净健康肤色透3%淡粉血色，带细微肌理[男角色加：与浅淡胡茬痕迹]，轻微细纹拒绝假肤。
原生裸感唇态无妆，唇周2%色素沉淀。
发丝根根分明微毛躁，发型蓬松微乱。
服装质感写实，柔焦照片级真实感，光影细腻阴影过渡自然，四肢边缘极轻微动态模糊，色调清透柔和高清。
[全局质量提示词]
```

把版本A第一句换成用户提供的外貌描述（发型/服装/体型/肤色等），其余相同。

## 2. 道具模板

### 版本A · 有道具参考图（以参考图为准）

```
以道具参考图为准，横向拼接构图，画面元素互不遮挡，纯白色纯色背景，无任何文字标识，道具比例严格与参考图保持一致。
一套画面包含：道具特写、道具正面、道具正侧面、道具背面。
同一个道具，器物造型、结构、花纹、材质细节与参考形象完全统一。
超写实照片级 CG 道具渲染，真实物理材质 PBR，材质表面细微纹理完整保留，器物表面自然环境柔光，柔和高光反射，真实细腻的材质反光，无过曝死白，器物缝隙、边角阴影过渡柔和自然。
面料 / 金属 / 漆面写实质感，光影层次细腻，阴影过渡柔和自然。
整体色调清透柔和，超高清晰度，8K，电影级渲染，细腻景深。
[全局质量提示词]
```

### 版本B · 无参考图

把第一句「以道具参考图为准……保持参考图一致」改为道具的造型/材质文字描述，其余相同。

## 3. 场景模板（精简版）

> 由 storyboard-prompt-optimizer2.0 的场景模板精简而来：保留「主画面 + 俯视/布局辅画面 + 关键区域辅画面」结构，砍掉多格拼版、六宫格细节与长段字体要求。

```
为我生成一张场景图。
场景描述：[场景名称]，主画面为[场景名称][视角描述]，环境[氛围描述]，具有鲜明的[风格/时代]特征。既有近处[近景细节]，也有中景[中景内容]和远景[远景内容]，体现[场景核心感受]。场景中点缀有[关键元素列表]，整体空间层次分明。
辅画面1：呈现场景的俯视/布局视角，明确空间结构与物品排布。
辅画面2：呈现关键区域的细节特写。
辅画面约束：辅画面与主画面的空间位置、道具比例保持一致，不得偏移或变形。
光影氛围：[光影描述]
避免：不要人物特写，不要卡通感，不要建筑变形，不要透视错误，不要多余文字，不要水印，不要模糊，不要杂乱无章。
宽高比 16:9
[全局质量提示词]
```

### 标准样例（明代皇宫·精简）

```
为我生成一张场景图。
场景描述：中国明代皇宫，主画面为皇宫俯瞰总览，环境庄重、肃穆、典雅，具有鲜明的古代皇家建筑特征。既有近处墙体与宫灯细节，也有中景巷道延伸和远景宫殿轮廓，体现皇宫的恢弘与秩序感。场景中点缀有宫灯、红灯笼、石阶、朱红宫墙、木质门窗，整体空间层次分明。
辅画面1：呈现场景的俯视布局视角，明确宫墙、巷道与宫殿的排布关系。
辅画面2：呈现飞檐屋脊、青砖铺地、灰瓦纹理等关键区域的细节特写。
辅画面约束：辅画面与主画面的空间位置、道具比例保持一致，不得偏移或变形。
光影氛围：清晨或黄昏柔和光线，暖色阳光洒在红墙灰瓦上形成冷暖对比，轻微空气透视增强纵深。
避免：不要现代建筑，不要现代物品，不要人物特写，不要卡通感，不要建筑变形，不要透视错误，不要多余文字，不要水印，不要模糊，不要杂乱无章。
宽高比 16:9
```
