# 资产模板库

> 用途：第3站建资产（角色 / 场景 / 道具）时按需调用。
> 通用规则：
> 1. 每段资产提示词 = 【模板正文】 + 【第2站定下的全局质量提示词】。
> 2. 素材引用只写资产名（男主 / 女主 / 场景A / 道具1），不写文件扩展名。
> 3. 有参考图 → 以图为准；无参考图 → 把「以参考图为准/去掉背景」改为对特征的文字描述。

## 3. 场景模板（精简版）

> 由 storyboard-prompt-optimizer2.0 的场景模板精简而来：保留「主画面 + 俯视/布局辅画面 + 关键区域辅画面」结构，砍掉多格拼版、六宫格细节与长段字体要求。

```
为我生成一张场景图。
场景描述：[场景名称]，主画面为[场景名称][视角描述]，环境[氛围描述]，具有鲜明的[风格/时代]特征。既有近处[近景细节]，也有中景[中景内容]和远景[远景内容]，体现[场景核心感受]。场景中点缀有[关键元素列表]，整体空间层次分明。
辅画面1：呈现场景的俯视/布局视角，明确空间结构与物品排布。
辅画面2：呈现关键区域的细节特写。
辅画面约束：辅画面与主画面的空间位置、道具比例保持一致，不得偏移或变形。
光影氛围：[光影描述]
避免：不要人物特写，不要卡通感，不要建筑变形，不要透视错误，不要多余文字，不要水印，不要模糊，不要杂乱无章。

```

## 1b. 角色设定图 · 中性母版（推荐，给图生视频用）

> 详细规则见 `references/character-asset-rules.md`。这里只给可直接复制的模板。

### 中性母版模板

```
以参考图的人物形象、服装、发型为准，生成角色设定图。
【背景】纯灰色背景，不要场景、不要渐变、不要环境光。
【照明】均匀柔光，不要硬光、不要明显高光与阴影、不要戏剧光比。
【画面】不要任何颗粒感、不要噪点、不要高频纹理；不要文字、不要标注、不要分格线。
【内容】包含：面部特写（高清）、全身正面（处理成无头版）、全身背面（无头版）、全身正侧面。
　　　　横向排列、互不遮挡。
【皮肤】偏哑光处理，但保留毛孔与真实皮肤纹理（哑光 ≠ 磨皮）。
【眼睛】保留一点自然眼神光（柔和窗光反射）；
　　　　不要环形打光灯那种正圆高光，不要彩色强烈高光。
【比例】标准模特身体比例。
[全局质量提示词]
```

### 为什么要这样

| 项 | 为什么 |
|---|---|
| 灰底 + 均匀柔光 | 减少可被误抄的环境信息 |
| 不要颗粒 | 设定图的颗粒会被带进每一张单帧，再到视频里再叠一层 |
| 分离全身与面部 | 面部身份只有一个来源，减少人物漂移 |
| 自然眼神光 | 让角色在眨眼、转头时有生气；但异常光源会被带进所有场景 |
| 哑光 + 保留毛孔 | 既干净又不是塑料 |

### 状态变化（流汗 / 受伤 / 血迹 / 换装）

从**原始母版**出发改，改完**只提取变化区域贴回母版**。
**禁止对同一张设定图迭代两次以上**——每多一轮，皮肤纹理与五官就多漂移一次，脸会越来越对称、越像塑料。

### 表情版（按需另做一张）

某一段需要角色"是笑的"，就**另做一张微笑版**：
同人、同脸、同服装、同姿势、同灰底四格，**只把表情换成微笑**。
生成那一段时改挂微笑版，并在素材职责里写：

```
只采用设定图上的长相、发型、发色、服装，
不采用设定图上这个人的表情——那只是拍证件照的状态，不是表演。
```
