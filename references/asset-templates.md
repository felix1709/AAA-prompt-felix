# 资产模板库

> 用途：第3站建资产（角色 / 场景 / 道具）时按需调用。
> **状态（2026-11-17 实测）**：三份模板各跑一张 2K，结构与版式均成立——角色无头四格 / 道具横向五联 / 场景 2×2 四视图。**设定阶段只认这三份，不临时自创模板、不跨类套用。**
> 通用规则：
> 1. 每段资产提示词 = 【模板正文】 + 【第2站定下的全局质量提示词】。
> 2. 素材引用只写资产名（男主 / 女主 / 场景A / 道具1），不写文件扩展名。
> 3. 有参考图 → 以图为准；无参考图 → 把「以参考图为准/去掉背景」改为对特征的文字描述。
> 4. **三类资产各用各的模板，禁止跨类套用。**
>
> | 资产 | 用哪节 | 版式 | 背景 |
> |---|---|---|---|
> | **角色** | §1b 中性母版 / §1c 通用模板 v1 | 横向一排**四格**：面部特写 + 正面（无头）+ 正侧面（无头）+ 背面（有头） | 纯**灰** |
> | **道具** | §2 道具模板 v2 | 横向**五联**：正面 + 正侧面 + 3/4侧面 + 背面 + 关键细节特写 | 纯**浅灰** |
> | **场景** | §3 | **2×2 四视图**：主视角 / 高位俯视 / 斜侧全景 / 反向全景 | 随场景 |
>
> 角色模板里的「面部特写 / 无头版 / 哑光皮肤 / 眼神光 / 标准身体比例」只属于角色，**绝不能出现在道具或场景提示词里**。反过来，道具模板的「尺度参考方块 / 五联版式 / 浅灰底」也只属于道具，不要带进角色或场景。

### 3b-2. 灰模交互层（已模板化，直接复用）

> 模板文件：`references/grey-model-template.html`（与本文件同目录）。
> 以后要搭灰模，**直接复制这个 HTML**，只替换 `SCENE BUILD START / END` 之间的场景搭建，交互层不要重写。
> 模板只含**交互层 + 一个最小占位台/地面**，不含任何具体项目场景（不写舞台、走廊、座位、灯位）。具体场景在项目里按当次四视图重搭，**不要把某个项目的场景写回模板**。

**必带功能（模板已实现）**

1. 参考机位：主视角 / 高位俯视 / 斜侧全景 / 反向全景
2. 摄影机焦段：24 / 35 / 50 / 85 / 135 / 200mm（36mm 传感器，FOV = 2·atan(18/f)）
3. 角色列表：添加 / 改名 / 改色 / 删除；名字和颜色实时同步到灰模人和头顶标签
4. 角色自由拖动：可拖到舞台和观众席，自动落到表面高度
5. 摄影机模式：WASD 移动 + Q/E 升降 + 鼠标拖动转头 + Shift 加速
6. 网格开关
7. 导出 1920×1080：隐藏网格，保留角色

**复用步骤**

1. 复制模板到项目 `灰模/` 目录
2. 只改 `SCENE BUILD START / END` 之间的几何
3. 保留 `stageMesh` / `floorMesh` / `START_Y` 三个变量名（拖拽落地和角色初始高度要用）；`START_Y` 改成项目台面高度
4. 启动 `python -m http.server 8765 --directory <项目根>`
5. 打开对应 URL，先点四个参考机位检查比例

**Eagle 归档（每个场景各存一条）**

1. 网页 `<title>` 直接写成 `<场景>_灰模`（Eagle 书签会拿它当名字）
2. 在该场景所在文件夹加一条书签，URL 用本地地址，备注写启动命令：
   `cd /d <项目根> && python -m http.server 8765`
3. 在场景图的 annotation 里追加同一个链接，看到图就能点开灰模
4. 本地地址只在服务运行时有效；**服务器必须后台运行**（不要占住终端），关掉服务链接就失效。备注里必须写清启动命令

**关键实现坑（模板已处理，改的时候别破坏）**

- 拾取必须返回**角色对象**，不是 Three.js 的 `Group`。返回 Group 会导致 `group.position` 取不到，拖拽直接抛错。
- `setPointerCapture` 要包 `try/catch`，否则合成事件或重复捕获会中断拖拽。
- 拖拽时先射线打 `stageMesh` / `floorMesh`，打空时退回水平面，保证任何角度都能拖。
- 角色标签用 `CanvasTexture + Sprite`，并把 `sprite.raycast` 置空，避免标签挡住拾取。
- 角色组的 y 要跟随表面高度：项目里把 `START_Y` 设成台面高度（模板默认 1.0），地面 0。

### 3b-3. 灰模交付规范 v1（固定，不要每次改）

> 来源：`423舞台发型`（stage_grey / corridor_grey）与后续项目实测。以后所有灰模按这一套出，不再临场发挥。

#### 1. 目录与命名
- 项目根下建 `灰模/`，不要用「白模」或其他名字。
- HTML：`<场景slug>_grey.html`，slug 用短英文小写下划线（例：`plaza_grey.html`、`stage_grey.html`）。
- 预览图：`<场景slug>_preview.png`，**1280×720，带 HUD**，与 HTML 同目录。
- 不再额外放 `.url` 文件。

#### 2. 模板
- 复制 `references/grey-model-template.html`，只替换 `SCENE BUILD START/END` 之间的几何。
- 保留 `stageMesh` / `floorMesh` / `START_Y` 三个变量名。
- 交互层（HUD、机位、焦段、角色、拖拽、导出）不改。

#### 3. 默认机位与焦段（最容易返工）
- **主视角 = 场地内无遮挡概览**，不是门洞 / 牌坊 / 窗框的电影构图。灰模先解决「看得清全场」。
- 默认焦段 **35mm**（24–200 可切）。
- 机位放在场地内部或边缘，不把建筑当画框挡住中央空地。
- 角色初始站位放在中景，不挡主视角。

#### 4. 相机范围（防「自动飘逸」）
- 相机移动范围必须覆盖所有预设机位，按场景边界外扩 10–20%。
- `orbit.maxDistance` 必须 ≥ 最远预设距离 × 1.2。
- **进入摄影机模式前后，相机位置不能跳变**；交付前分别读一次位置验证。

#### 5. 预设机位
- 固定四个：`main`（场地内概览）、`top`（高位俯视）、`side`（斜侧全景）、`back`（反向全景）。
- 四个机位必须能互相验证同一空间：门洞 / 牌坊 / 水渠 / 建筑的位置不能互换。

#### 6. 材质
- 沿用灰阶：floor `0x666666`、stage `0x8f8f8f`、dark `0x484848`；可加 roof / wall / wood / cloth，但保持灰阶块面，不做写实材质。

#### 7. 服务与地址
- 默认端口 **8765**：`python -m http.server 8765 --directory <项目根>`。

## 1b. 角色设定图 · 中性母版（推荐，给图生视频用）

> 详细规则见 `references/character-asset-rules.md`。这里只给可直接复制的模板。

### 中性母版模板

```
以参考图的人物形象、服装、发型为准，生成角色设定图。
【背景】纯灰色背景，不要场景、不要渐变、不要环境光。
【照明】均匀柔光，不要硬光、不要明显高光与阴影、不要戏剧光比。
【画面】不要任何颗粒感、不要噪点、不要高频纹理；不要文字、不要标注、不要分格线。
【内容】包含（从左到右）：面部特写（高清）、全身正面（无头版）、全身正侧面（无头版）、全身背面（保留头部）。
　　　　横向排列、互不遮挡。正面与正侧面从颈部以下开始，不出现头部和脸；背面保留头部、背对镜头、完整入画。
【皮肤】偏哑光处理，但保留毛孔与真实皮肤纹理（哑光 ≠ 磨皮）。
【眼睛】保留一点自然眼神光（柔和窗光反射）；
　　　　不要环形打光灯那种正圆高光，不要彩色强烈高光。
【比例】标准模特身体比例。
[全局质量提示词]
```

### 为什么要这样

| 项 | 为什么 |
|---|---|
| 灰底 + 均匀柔光 | 减少可被误抄的环境信息 |
| 不要颗粒 | 设定图的颗粒会被带进每一张单帧，再到视频里再叠一层 |
| 分离全身与面部 | 面部身份只有一个来源，减少人物漂移 |
| 自然眼神光 | 让角色在眨眼、转头时有生气；但异常光源会被带进所有场景 |
| 哑光 + 保留毛孔 | 既干净又不是塑料 |

### 状态变化（流汗 / 受伤 / 血迹 / 换装）

从**原始母版**出发改，改完**只提取变化区域贴回母版**。
**禁止对同一张设定图迭代两次以上**——每多一轮，皮肤纹理与五官就多漂移一次，脸会越来越对称、越像塑料。

### 表情版（按需另做一张）

某一段需要角色"是笑的"，就**另做一张微笑版**：
同人、同脸、同服装、同姿势、同灰底四格，**只把表情换成微笑**。
生成那一段时改挂微笑版，并在素材职责里写：

```
只采用设定图上的长相、发型、发色、服装，
不采用设定图上这个人的表情——那只是拍证件照的状态，不是表演。
```

## 1c. 角色设定图 · 通用模板 v1（带风格，可换项目）

> 用途：任何项目的角色四格设定图（无头四格）。骨架经 5 轮实测，不建议随意改。
> 与 1b 的区别：1b 是**中性母版**（灰底、无光比、无颗粒），偏给图生视频用；本模板是**带风格的设定图**，用于设计确认与风格定稿。
> 变量只有长相、服装、风格三项，其余骨架照抄。

### 模板正文（复制后替换【】）

```
生成一张横版【风格】角色设定图，这不是真人照片，而是【渲染质感】。纯灰色背景，画面里只有这一个角色，横向排列四个部分：最左是高清面部特写，然后依次是全身正面无头版、全身正侧面无头版、全身背面，四部分互不遮挡、间距均匀，整体在画面内留出清楚的上下边距，不贴到画面边缘，画面里不出现任何文字、标注、分格线或水印。

全身正面和正侧面从颈部以下开始，不出现头部和脸，只保留身材比例、服装，以及垂在肩上的头发；全身背面保留头部，背对镜头，从头顶到鞋底完整入画，头顶上方留出清晰边距，完整呈现后脑到发尾的头发形状、发量、层次和走向，以及背部的服装结构。面部身份只由最左侧的面部特写提供。

角色是一位【年龄与气质】的【身份或职业】。【脸型与骨相】；【眉眼】；【鼻子与嘴唇】；皮肤干净均匀，肤色一致，只有厚涂笔触形成的明暗关系和结构转折。【发型：长度、形状、发束感、分缝、碎发位置】。标准【男/女】模身体比例，【体型描述】。服装是【服装主色与结构】，布料褶皱用笔触概括，不佩戴【配饰清单】等任何配饰。

在全身背面的视图里，头发与【服装主色】之间要有清楚的分界，发丝受光处的高光略亮于衣服，发型的轮廓、层次和发尾走向清晰可辨，不要糊成一片。

姿势语言统一：面部特写是正面平视、表情中性不笑、嘴唇自然闭合；全身正面和正侧面是自然站姿、双臂自然下垂、重心平均落在双脚；全身背面是背对镜头、头发自然垂落。

照明是均匀柔光，从正面偏上方打，没有硬光、没有戏剧性明暗比、没有彩色光。背景是纯灰色，不要渐变、不要环境反射、不要投影。眼睛保留一点柔和的窗光反射作为眼神光，不要环形灯那种正圆高光，不要彩色高光。皮肤的明暗用厚涂笔触表现，明暗交界处能看到笔刷走向，不要照片级皮肤纹理，不要磨皮。

整张图像一幅画，能看见笔触走向、色块边界和笔刷溢出的松动感；形状优先于细节，角色先立大块几何形状再补细微；全身部分的皮肤、布料、头发用和面部特写同一种厚涂画法，不要变成干净光滑的概念设定图；整体低饱和，暗部有彩不发灰；金属冷硬高光、布料哑光、皮肤次表面散射三种质感分明；三维体积明确，高清晰度。避免【真人摄影类词】、【多余配饰】、【卡通或赛璐璐类词】、硬光、强投影、背景渐变、文字、水印、分格线、颗粒、噪点。

参数提示：横版 16:9，尺寸 1536×864。
```

### 可替换槽位

| 槽位 | 填什么 |
|---|---|
| 【风格】 | 一句话定死风格方向，放最前面 |
| 【渲染质感】 | 风格的具体质感（如手绘厚涂的三维动画电影画面） |
| 【年龄与气质】 | 年龄 + 一句话气质 |
| 【身份或职业】 | 这个人是谁 |

| 【鼻子与嘴唇】 | 鼻梁、唇形 |
| 【发型】 | 长度、形状、发束感、分缝、碎发位置 |

| 【卡通或赛璐璐类词】 | 排除错误画风的词 |

### 固定骨架（不要改）

1. 四格结构：面部特写 + 正面无头 + 正侧面无头 + 背面**有头**
2. 正面和侧面必须无头（防止脸部信息重复干扰）
3. 背面必须保留头部（背面看不到脸，去头会把后脑的头发一起切掉）
4. 灰底 + 均匀柔光 + 无投影
5. 表情中性、自然站姿
6. 画面里不出现文字、标注、分格线、水印
7. 参数提示单独一行，不写进正文（写正文可能画出黑边）

### 常见坑与改法

| 坑 | 原因 | 改法 |
|---|---|---|
| 出来像真人照片 | 写实词太多、风格词放末尾 | 风格写第一句，明确写“不是真人照片” |
| 身体三格比脸干净 | 模型把特写与全身分开处理 | 加“全身部分的皮肤、布料、头发用和面部特写同一种厚涂画法” |
| 模型自己加项链、耳环 | 默认审美补全 | 在服装句里显式写“不佩戴 X、Y、Z 等任何配饰” |
| 写“不要雀斑”反而出雀斑 | 负向词提到它等于提示它 | 删掉这个词，改成“皮肤干净均匀” |
| 背面头顶被切 | 四格塞在 16:9 里，背面多一个头 | 整排缩小留边，或背面单独出一张大图 |
| 脸太“标准美人” | 默认审美 | 加“骨相硬朗、左右略不对称、不要磨成标准美人脸” |

## 3c. 场景四视图 · 清洁版规则（实测）

> 用途：生成舞台、走廊、房间等场景四视图时，避免“脏、乱、糊”。
> 来源：舞台 v01–v05、后台走廊 v01–v03 实测。

### 四条硬规则

1. **减元素**：只留 3–5 类必要物体。不要成排音箱、成堆箱体、散落线缆、鼓组。
2. **减雾**：雾只在光束或光源附近可见，不铺满空间。
3. **减光源**：3–5 束主光，不要成排灯海全开。
4. **暗部干净**：暗部是深色有密度，不是灰绿雾；不要靠加颗粒制造质感。

### 写法顺序

1. 第一句写风格，并明确“不是真实照片”
2. 场景事实（主体、地标、材质）
3. 时间与光（光源数量、雾的范围、暗部要求）
4. 四格机位
5. 一致性 + 避免清单
6. 质量词（场景版：去掉“角色/发丝/皮肤”，换成“石材粗糙反光”）

### 风格参考图（可选，但有效）

- 用**材质区域**当参考，不要用带脸的人像：只参考笔触、色块、材质处理
- 素材职责必须逐项写：只参考 X，不采用 Y
- 实测：参考图能改善屏幕、幕布、墙面的笔触，但压不住金属和设备的照片感

### 常见坑

| 坑 | 原因 | 改法 |
|---|---|---|
| 场景像真实照片 | “舞台/走廊”默认写实 | 风格句前置 + 明确“不是照片” + 附材质参考 |
| 画面脏 | 雾铺满 + 设备太多 + 光束太密 | 执行上面四条硬规则 |
| 空得像样板间 | 过度减元素 | 加使用痕迹：胶带、鞋印、磕碰、撕掉的贴纸 |
| 太整齐 | 杂物摆得像陈列 | 让箱子歪、开盖、线缆垂落、地上散落小物，但中央通道保持可走 |
| 换机位东西消失 | 四格没有共用元素清单 | 在四格里逐一点名同一批物体和数量 |
