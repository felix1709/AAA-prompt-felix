# 视觉情绪推导引擎

> 用途：**第4站 4.0 步骤**使用。解决一个核心问题——**构图不是填空题，是情绪推导题。**
> 融合自：本地 `cinematic-director`（注意力/视觉钩子/故事瞬间/七维摄影语言）、`banana-box-skill` 构图卡、GitHub `cinematography-prompt-master`、电影摄影通用理论。

---

## 一、核心原理（先读这三条）

### 1. 构图不是填空，是推导
旧做法：把九层里的「②构图」当成一个格子填满（景别/机位/占位/留白）。
新做法：**先问"这一镜要让观众感受到什么"，再由情绪反推景别、机位、构图、留白。**

```
❌ 旧：这镜用什么景别？→ 中景吧 → 填进去
✅ 新：这镜要让观众感到"压抑"→ 压抑=低机位仰拍+居中撑满+极少留白 → 中景+低机位+压缩空间
```

### 2. 环境是情绪的可视化载体（"景语皆情语"）
情绪是看不见的，**必须借环境元素变成看得见的**：

```
凄美（看不见） → 花瓣缓缓飘落 + 人物静立（看得见）
肃杀（看不见） → 竹叶骤然卷起 + 寒光一闪（看得见）
孤独（看不见） → 大雾弥漫 + 人物在空旷地面上拉出长影（看得见）
```

### 3. 摄影记录的不是姿态，是注意力
人物看哪里，观众就看哪里，故事就在哪里。
- 看远方 = 等待｜看手中之物 = 回忆｜看地面 = 失落｜闭眼 = 承受
- **人物永远不看镜头**（看镜头 = 立刻变写真，故事感归零）

## 二、四步推导法（4.0 步骤的操作手册）

对**每一个镜头**，按顺序走四步：

```
第1步 定意图  → 这一镜要让观众感受到什么？（选一个情绪词）
第2步 定锚点  → 观众第一眼应该看哪里？（人 / 物 / 环境）
第3步 定构图  → 用情绪查【第三节大表】→ 得景别 / 机位 / 构图法则 / 留白 / 光线
第4步 定元素  → 用情绪查【第六节调度表】→ 得环境元素 + 元素动态
```

**产出物**：一句「**构图依据**」（例如 `凄美 → 中近景+平视略俯+花瓣环绕+逆光柔焦`）

> ⚠️ **「构图依据」是内部推理，绝对不写进提示词。** 它只用来指导九层里②③⑤⑥⑦各怎么填。
> ⚠️ 若这一镜**没有人物表演**（空镜/环境镜/过渡镜），先走【第七节 无情绪镜头处理流程】。

## 四、情绪实例卡（24 张）

> 每张卡 = 构图配置 + 环境元素 + **完整单帧范例**（九层精简版，可直接改写使用）。
> 范例里的人物/场景是**通用的**，用时替换成你自己的角色与场景。

### 卡 01 · 孤独 / 疏离

**构图配置**：远景｜高机位俯拍｜三分法·人物偏置一角｜大量留白｜低照度冷光

**环境元素**：雾、空旷地面、长影、孤树、大片天空

**单帧范例**：
> ①场景：破晓的旷野，一个人独自立在画面右下角，周围只有被雾吞没的荒草。
> ②构图：大远景，低对比，高机位俯拍，人物仅占画面一角，其余全是空茫的雾与原野。
> ③景深：雾作为距离渐变，越远越淡，人物是全画面唯一的清晰点。
> ④摄影机：35mm 电影机，35mm 镜头，f/4。
> ⑤灯光：天光未亮，唯一光源是地平线泛起的冷白微光，人物近乎剪影。
> ⑥色彩质感：低饱和青灰，大面积低对比，细颗粒。
> ⑦情绪：孤独、疏离、被世界遗忘。
> ⑧真实感：雾气有真实颗粒与流动感，人物衣料保留纹理。
> ⑨避免：不要阳光明媚，不要人物居中，不要彩色。

### 卡 02 · 凄美 / 哀伤

**构图配置**：中近景｜平视略俯｜三分法+元素环绕｜中等留白｜柔和逆光

**环境元素**：花瓣、落叶、细雨、柳絮、飞絮（缓慢飘落类）

**单帧范例**：
> ①场景：午后庭院，一个人静静立着，花瓣正缓缓飘落，落满他的肩头。
> ②构图：中近景，人物在画面左侧三分之一，右侧留给飘落的花瓣与虚化的庭院。
> ③景深：前景有半透明的花瓣掠过镜头，轻微虚化，不遮挡面部。
> ④摄影机：35mm 电影机，85mm 镜头，f/1.8 浅景深。
> ⑤灯光：柔和的侧逆光穿过花瓣，形成半透明光边。
> ⑥色彩质感：低饱和，暖粉与灰绿交融，细颗粒与轻微光晕。
> ⑦情绪：凄美、哀伤、时间凝固。
> ⑧真实感：花瓣叶脉真实，皮肤保留毛孔，无妆感。
> ⑨避免：不要花瓣糊满画面，不要高饱和，不要塑料皮肤。

### 卡 03 · 压抑 / 窒息

**构图配置**：中景｜低机位仰拍｜居中撑满·压缩空间｜极少留白｜顶光压下

**环境元素**：低矮天花板、密集的柱列、逼近的墙壁、压顶的云

**单帧范例**：
> ①场景：狭窄的走廊，一个人被两侧高墙夹在中间，头顶是被压缩的一线天。
> ②构图：中景，低机位仰拍，人物居中且几乎撑满画幅，两侧墙体向中挤压。
> ③景深：深景深，让走廊纵深一览无余，强化无处可逃。
> ④摄影机：35mm 电影机，35mm 镜头，f/4。
> ⑤灯光：顶光垂直压下，眼窝陷在阴影里，暗部厚重。
> ⑥色彩质感：低饱和，冷灰与土黄，暗部有密度，细颗粒。
> ⑦情绪：压抑、窒息、无处可退。
> ⑧真实感：墙面保留斑驳纹理，皮肤保留毛孔与汗光。
> ⑨避免：不要明亮通透，不要广角畸变过头，不要暖色调。

### 卡 04 · 压迫 / 威压

**构图配置**：中景·中近景｜低机位仰拍｜中心对称·人物居中｜极少留白｜硬光强对比

**环境元素**：高背座椅、背后的巨大结构、压低的天空、逆光轮廓

**单帧范例**：
> ①场景：大殿深处，一个人端坐其中，背后是压顶的巨大梁柱，光从他身后斜切过来。
> ②构图：中近景，极低机位仰拍，人物居中且占据画面上半部，形成俯视观众之势。
> ③景深：浅景深，背景结构虚化但仍可辨其庞大。
> ④摄影机：35mm 电影机，50mm 镜头，f/2。
> ⑤灯光：硬质侧逆光勾出轮廓，面部半明半暗，暗部极深。
> ⑥色彩质感：低饱和，冷褐与暗金，强明暗对比，细颗粒。
> ⑦情绪：压迫、威压、不可撼动。
> ⑧真实感：织物纹理真实，皮肤保留毛孔，眼神有真实反光。
> ⑨避免：不要平视，不要柔光，不要人物变小。

### 卡 05 · 决绝 / 肃杀

**构图配置**：近景｜平视正面｜中心对称·水平极稳｜无留白｜冷硬侧光

**环境元素**：落叶静止、寒光、兵器反光、无风的空间

**单帧范例**：
> ①场景：竹林空地，一个人持刀静立，周身无风，叶尖一动不动。
> ②构图：近景，平视正面，人物严格居中，画面水平线稳如刀切，四角填满。
> ③景深：中等景深，人物清晰，背景竹林成整齐竖线。
> ④摄影机：35mm 电影机，85mm 镜头，f/2.8。
> ⑤灯光：冷硬侧光，一半脸亮一半脸沉，眼中有极小的反光点。
> ⑥色彩质感：极低饱和，冷青与墨绿，高对比，细颗粒。
> ⑦情绪：决绝、肃杀、一触即发。
> ⑧真实感：刀身有真实金属反光与细微划痕，皮肤保留毛孔。
> ⑨避免：不要笑容，不要暖光，不要倾斜构图。

### 卡 06 · 温柔 / 亲密

**构图配置**：近景·特写｜平视｜双人紧凑·彼此倾向｜少留白｜柔光暖调

**环境元素**：暖灯、窗帘透光、轻烟、柔软的织物

**单帧范例**：
> ①场景：傍晚室内，两个人靠得很近，一人正低头看另一人，窗光柔柔落在两人之间。
> ②构图：近景，平视，两人占据画面中央且身体微微向彼此倾斜，背景虚化成暖色块。
> ③景深：极浅景深，两人面部清晰，背景完全化开成光斑。
> ④摄影机：35mm 电影机，85mm 镜头，f/1.4。
> ⑤灯光：窗光作为唯一光源，柔和包裹面部，眼中有柔和的眼神光。
> ⑥色彩质感：低对比暖调，奶白与浅琥珀，柔和光晕，细颗粒。
> ⑦情绪：温柔、亲密、时间变慢。
> ⑧真实感：皮肤保留毛孔与真实血色，发丝根根分明。
> ⑨避免：不要硬光，不要高对比，不要构图松散。

### 卡 07 · 喜悦 / 明媚

**构图配置**：中景·全景｜平视略仰｜三分法·动作舒展｜中等留白｜明亮顺光高调

**环境元素**：阳光、飞鸟、水花、跃动的光斑、盛开的花

### 卡 08 · 愤怒 / 暴烈

### 卡 09 · 恐惧 / 惊惧

**构图配置**：特写·近景｜高机位俯拍｜人物被挤向边缘｜大量背后空虚｜冷光吞噬

**环境元素**：黑暗、雾、空荡的空间、逼近的影子

**单帧范例**：
> ①场景：昏暗的房间，一个人猛地回头，瞳孔骤缩，身后是无边的黑。

> ⑧真实感：热饮有真实雾气，织物有真实绒毛纹理，皮肤有真实血色与毛孔。
> ⑨避免：不要冷光，不要空旷，不要人物表情紧绷。

---

## 五、情绪曲线衔接（镜头之间怎么过渡）

情绪**不能跳变**。相邻镜头之间要有过渡桥梁：

| 从 → 到 | 过渡手法 |
|---|---|
| 平静 → 紧张 | 加一个"环境先变"的镜头（风起、光暗、声音消失） |
| 紧张 → 爆发 | 加一个极短的静止镜头（蓄力）再爆 |
| 爆发 → 平静 | 加一个"尘埃落定"的空镜 |
| 喜悦 → 悲伤 | 加一个"笑容慢慢消失"的中间镜 |
| 孤独 → 温暖 | 加一个"光进来"的镜头 |

**原则**：情绪转折处，**先变环境，再变人**。

## 六、环境元素调度表 ⭐（回答"花瓣满天飞怎么用"）

> **核心**：情绪是看不见的，环境元素是它的可视化载体。
> 用错元素 = 情绪传达失败；用对元素 = 观众"感觉到了"却说不出为什么。

| 情绪 | 可用元素 | 元素的动态 | 元素位置 |
|------|----------|-----------|----------|
| **凄美 / 哀伤** | 花瓣、落叶、细雨、柳絮 | 缓缓飘落、旋转、掠过镜头 | 前景掠过 + 环绕人物 |
| **肃杀 / 决绝** | 竹叶、枯枝、寒气 | 骤然卷起、横向扫过 | 从人物两侧切入 |
| **孤独 / 疏离** | 雾、空旷地面、长影、孤树 | 缓慢流动、拉长、静置 | 占据大面积画面 |
| **压抑 / 窒息** | 低云、烟尘、密集柱列 | 压顶、逼近、静止 | 占满画面上方 |
| **紧张 / 对峙** | 静止的空气、被风吹动的衣角 | 极缓、几乎不动 | 两人之间的空档 |
| **喜悦 / 明媚** | 阳光、飞鸟、水花、花瓣 | 跳跃、闪烁、飞扬 | 环绕人物 |
| **愤怒 / 暴烈** | 扬尘、碎片、火星 | 炸开、四散、剧烈翻飞 | 从人物向外辐射 |
| **恐惧 / 惊惧** | 黑影、雾、飘动的帘 | 突然逼近、缓慢靠近 | 人物背后 |
| **希望 / 向往** | 光柱、浮尘、云开、飞鸟 | 光缓缓扩大、浮尘上升 | 视线前方 |
| **思念 / 回忆** | 浮尘、旧物、光斑 | 缓慢浮动、静止 | 光里 |
| **浪漫 / 心动** | 花瓣、光斑、灯串、微风 | 轻柔飘落、缓慢摇曳 | 两人之间 |
| **悲壮 / 牺牲** | 风、旗帜、残云、灰烬 | 猛烈飘动、上升、飘散 | 顺着逆光方向 |
| **神秘 / 未知** | 帘幕、雾、门缝的光 | 极缓飘动、忽明忽暗 | 框架内 |
| **温暖 / 治愈** | 热气、绒毛、猫、暖灯 | 缓慢上升、轻微起伏 | 人物周围 |
| **震撼 / 史诗** | 云海、光柱、飞雪、巨物 | 恢弘流动、从天而降 | 占满整个背景 |
| **恬淡 / 闲适** | 茶烟、竹帘光斑、微波 | 极缓飘动、几乎静止 | 人物四周 |

### 五条使用纪律

1. **元素必须服务情绪** —— 不是"好看就加"，而是"这个情绪需要它"
2. **元素要有物理动机** —— 花瓣要飘落得有风、有重力（`被风卷起` 而不是 `悬浮`）
3. **动态要有方向** —— 飘落 / 上升 / 横扫 / 逼近，四选一，别含糊
4. **位置要有讲究** —— 前景掠过（代入感）／环绕人物（包裹感）／背景铺满（压迫感）
5. **一个情绪最多两种元素** —— 堆三种以上，模型会把画面糊成一团（对照 camera-engine 的"软化预算"）

> ⚠️ **反例**：写"花瓣 + 落叶 + 柳絮 + 雨 + 雾" → 画面必糊。
> ✅ **正例**：写"花瓣缓缓飘落，掠过前景" → 干净且情绪准确。

## 七、无情绪镜头的处理流程 ⭐（回答"没有表演情绪时怎么办"）

有些镜头**没有人物表演**（空镜、环境镜、过渡镜、物件镜），这时不能瞎填构图。

### 判断流程

```
这一镜有表演吗？
├─ 有 → 从表演推情绪（performance-engine.md）
└─ 没有 → 按下面三类处理 ↓
```

| 类型 | 例子 | 情绪怎么定 |
|------|------|-----------|
| **空镜 / 环境镜** | 竹林、街道、天空、水面 | 转成**"摄影机的注意力"**：摄影机今天在看什么？ |
| **过渡镜** | 连接两场戏 | 取**前后两镜的情绪中间值** |
| **物件镜** | 特写道具/线索 | 情绪 = **这个物件对人物意味着什么** |

### 空镜的核心心法

> **摄影机也有注意力。** 无人物时，问："摄影机今天观察什么？"
>
> ```
> The camera observes the bamboo forest, not the traveler.
> Today the subject is the mist. The person is only a coordinate inside it.
> ```

### 询问话术（当情绪不明确时）

> 主动问用户，**给 2–3 个候选方向**让他选，比开放式提问有效：
>
> "这一镜没有人物表演，我需要确认它的情绪方向才能定构图。你想要的是——
> **A.** 清冷肃杀（暗示危险将至）
> **B.** 静谧安宁（大战前的平静）
> **C.** 凄清孤寂（人已离去）"

### ⚠️ 铁律

**思考结果只作为构图标准，绝对不写进提示词。**
用户选的是"清冷肃杀"，提示词里写的是"低照度冷光、竹影稀疏、地面有霜"，**而不是**"这一镜要表现肃杀的情绪"。

## 八、构图法则速查

| 法则 | 做法 | ✅ 适合情绪 | ❌ 避免用于 |
|------|------|-----------|-----------|
| **三分法** | 主体放在三分线/交点 | 通用、自然、叙事 | —— |
| **中心对称** | 主体居中，左右对称 | 庄重、威压、决绝、对峙 | 孤独、迷茫 |
| **对角线** | 元素沿对角线分布 | 动感、愤怒、疯狂、失控 | 平静、释然 |
| **框架式** | 前景形成天然画框 | 神秘、窥视、聚焦 | 开阔、史诗 |
| **引导线** | 线条把视线引向主体 | 纵深、希望、向往 | 封闭空间 |
| **留白** | 大面积空白，主体偏一侧 | 孤独、迷茫、希望、悲壮 | 压迫、紧张 |
| **黄金分割** | 主体在 0.618 处 | 通用、经典、耐看 | —— |
| **荷兰角（倾斜）** | 画面刻意倾斜 | 疯狂、失控、不安 | 平静、庄重、威压 |

> **构图与人物占比铁律**（来自 cinematic-director）：
> **电影不会把角色放满画面。** 环境人像通常人物占 **20–40%**，风景/武侠类只占 **1–5%**。
> AI 默认喜欢让人物占 80% —— 那立刻变成证件照/海报，不是电影。

## 九、注意力指向表（人物看向哪里 = 画面主题是什么）

> 摄影真正记录的不是人物的姿势，而是**人物的注意力**。

| 注意力指向 | 画面主题 | 构图要点 |
|-----------|----------|----------|
| 看远方 | 等待、向往 | 视线方向留出大空间 |
| 看天空 | 向往、祈祷 | 上方留白 + 略仰角 |
| 看环境（竹林/街道/海） | 观察、疏离 | 人物占小比例，环境占主导 |
| 看手中之物 | **回忆、不舍** | 手部/物件特写 + 极浅景深 |
| 看另一个人 | 关系、对峙 | 双人构图，视线连线 |
| 看地面 | 疲惫、沉思、失落 | 略俯视 + 重心下沉 |
| 闭眼 | 感受、承受 | 面部特写 + 柔光 |
| **看镜头** | ❌ **禁止** | 立刻变写真，故事感归零 |

**三条规则**：
1. 注意力必须落在**画面内的具体对象**上（或明确指向画面外）
2. **人物永远不注意摄影机**——这是"偶然被目击"感的来源
3. 注意力对象应与**视觉锚点一致**（她看剑 → 剑是最亮处 → 观众先看剑，再看她的眼神）
