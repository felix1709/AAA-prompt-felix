# 图生视频首帧预检与首帧提示词规范

本文件用于判断首帧是否适合承载连续微表情，或在用户只有人设图、三视图、定妆照时生成首帧生图提示词。只分析和写提示词，不调用任何生图工具。

## 输入路由

### 用户提供首帧图

先查看原图，再根据目标情节和表演时间线做预检。用户只问“能不能做首帧”时，只输出分析结论，不顺带生成视频提示词。

### 用户只提供人设图、三视图或定妆照

根据人物身份和目标表演生成一段首帧生图提示词，包含必要负面约束。不要实际生成图片。

### 用户没有提供任何人物图

如果人物身份连续性重要，请用户提供一张人设图、三视图、定妆照或已有角色图。若身份不重要，可按用户文字设定直接写首帧提示词。

## 首帧预检

逐项检查以下内容。

### 1. 单一表演主体

- 微表情反应镜头优先只出现一个清晰人物。
- 其他角色尽量留在画外，或只作为无法辨认的静态背景信息。
- 多个清晰人物、重复角色、镜面分身会增加身份与动作漂移。

### 2. 面部可见度

- 双眼、眉心、嘴角和下颌应清晰可见。
- 人脸应占据足够画面面积，能够看见眼睑和嘴角的小幅变化。
- 头发、手、道具、眼镜反光和强阴影不应遮挡关键区域。

### 3. 头部与视线

- 近正面或轻微三分之二侧脸最适合连续微表情。
- 目标事件位于画外时，首帧视线应已落在正确方向。
- 头部偏转过大时，模型容易把眼球变化扩展成转头、抬头或低头。

### 4. 背景运动竞争

高风险背景包括：

- 可辨认的行人、车辆、动物、自行车；
- 电子屏幕、闪烁招牌、密集车灯；
- 水面、火焰、雨雪、烟雾等持续变化区域；
- 大量强逆光发丝、飘动衣物或复杂前景遮挡。

优先使用静态、低信息量背景。可以保留街景属性，但不要让清晰运动主体进入画面。

### 5. 初始情绪

- 首帧应对应时间线的第一个阶段。
- 需要“中性→难以置信”时，首帧不能已经明显瞪眼、皱眉或哭泣。
- 需要“冷峻→心软”时，首帧应先建立冷峻基准。
- 首帧已经预置的情绪不能可靠地靠文字瞬间消除。

### 6. 嘴唇与口型

- 自然闭合或保留极小自然缝隙都可以作为无台词首帧。
- 不要把“无台词”机械等同于“全程闭唇”。
- 真正需要限制的是连续说话式口型、反复张合、露齿和无目的嘴部运动。
- 首帧明显张嘴、露齿或已经形成说话口型时，无台词视频风险较高。
- 嘴唇可以在明确情绪节点短暂微分、抿紧、颤动或无声合拢，但每次变化必须有表演目的并及时收束。

### 7. 环境微动

只保留一种低幅环境微动，例如极少量发丝轻动。不要同时要求手持漂移、风吹头发、衣物摆动、行人走动和车辆移动。

### 8. 身体支撑

- 病弱、受伤、酒醉、失衡或精疲力尽状态必须有明确支撑点，如椅背、墙面、桌沿、扶手、手杖或稳定双脚。
- 首帧已经倚靠支撑物时，时间线不得无过程让支撑关系消失。
- 画面看不到手部、腿部或支撑物时，不安排依赖它们才能读懂的表演。

## 证据与表演上限

首帧的表情、姿态、手部、道具和身体支撑关系共同决定可靠的表演幅度。

- 神态平静、肩颈放松、手部稳定：优先从 1—2 级表演开始。
- 已有泪光、明显紧绷、防御姿态或握力变化：可以承接 2—3 级，但不重复生成同一前兆。
- 剧情要求的强度明显高于首帧证据：降低目标强度、延长发展时间，或重做首帧；不用更多动作和负面词强行跨越。
- 12—15 秒先用于增加停顿、承接和结尾保持，不因时长增加就自动添加第二个事件。

## 表演余量

设计时间线前，记录首帧各通道还能向哪里变化。不要要求已经处于极值的区域继续增强。

| 首帧状态 | 不要继续要求 | 优先替代 |
|---|---|---|
| 眼睛已经睁得较大 | 再次明显睁大、持续抬上眼睑 | 视线停顿、焦点凝固、眨眼延迟 |
| 眉心已经收紧 | 继续加深皱眉 | 保持紧张、下眼睑收紧、呼吸变化 |
| 嘴唇自然微分 | 强制瞬间闭紧或再次连续张开 | 保持基准，随后一次有目的的合拢 |
| 嘴唇自然闭合 | 全程冻结嘴部 | 触发时短暂微分一次，随后收束 |
| 嘴角已有笑意 | 直接要求中性起步 | 重做首帧，或把笑意消失设为第一阶段 |
| 头部已经侧转 | 再次转头寻找目标 | 使用眼球小幅移动，保持头部朝向 |
| 眼眶已经湿润 | 再写湿润逐渐出现 | 从强忍、眨眼或泪光停留开始 |
| 下颌已经绷紧 | 立即再加大紧张 | 先保持，再通过呼吸或握力泄露 |

时间线的第一个动作必须从首帧现状出发，而不是从理想化的中性脸出发。

## 风险结论

### 通过

满足以下条件时可直接进入视频提示词：

- 单一清晰主体；
- 面部关键区域可见；
- 背景没有明显运动竞争；
- 首帧情绪与第一个阶段一致；
- 眼睛、嘴唇、头部和视线仍有合理动作余量。
- 表演强度没有越过首帧可见证据，特殊身体状态有稳定支撑。

### 有条件通过

存在一到两个可通过时间线适配的问题，例如眼睛已经较大、嘴唇有自然小缝、头部轻微侧转。明确指出需要删除或替换的动作，不要求重新生图。

### 不建议生成

出现以下情况时先重做首帧：

- 多个清晰人物或复杂动态背景；
- 首帧与起始情绪相反；
- 明显张嘴、露齿或说话口型，但目标是无台词表演；
- 双眼或嘴角被遮挡；
- 人脸过小或头部偏转过大；
- 需要依赖大量负面词才能压住首帧中的动态元素。
- 病弱、受伤或失衡姿态没有可见支撑，目标动作容易导致身体漂移。

## 从人设图生成首帧提示词

首帧提示词只补充表演需要的画面条件，不扩写完整摄影、美术和世界观。

采用以下结构：

```text
以@人物参考图作为唯一身份参考，保持脸型、五官比例、年龄感、发型、服装和人物比例一致；不复制三视图拼版、多角度人物、文字标注和纯色参考背景。

[单一人物与必要景别]。[目标视线方向与头部角度]。[与时间线第一个阶段一致的眉眼、嘴唇、下颌和呼吸基准]。[干净静态背景，只保留场景属性，不出现可辨认运动主体]。[真实皮肤与身份稳定要求]。

负面约束：[重复人物、多角度拼版、动态背景主体、预置错误情绪、遮挡、身份漂移、文字水印]
```

必须明确：

- 只出现一个表演主体；
- 双眼、眉心、嘴角和下颌清晰；
- 视线已经落在剧情触发方向；
- 嘴唇状态与第一个时间段一致；
- 背景无可辨认行人、车辆或其他持续运动对象；
- 不提前生成后续目标情绪。

## 输出格式

### 用户提供首帧并要求分析

```text
首帧结论：通过 / 有条件通过 / 不建议生成

可用条件：
- ...

主要风险：
- ...

时间线适配：
- 删除或替换哪些动作
```

只做分析，不调用生图，不自动附加视频提示词。

### 用户只提供人设图

输出：

1. 一段可直接用于生图的首帧提示词；
2. 一段简短负面提示词。

不要生成图片，不追加视频时间线。

## 检查清单

- [ ] 是否识别用户提供的是首帧还是人设参考？
- [ ] 是否只分析或写提示词，没有擅自生成图片？
- [ ] 是否检查单一主体、面部可见度和背景运动竞争？
- [ ] 是否检查首帧情绪与时间线第一阶段一致？
- [ ] 是否根据首帧证据限定表演强度，并检查了特殊姿态的支撑点？
- [ ] 是否记录眼睛、眉心、嘴唇、下颌和头部的动作余量？
- [ ] 是否避免把自然微分的嘴唇误判为失败？
- [ ] 是否限制连续口型，而不是机械要求全程闭唇？
- [ ] 是否在不合格时先修首帧，而非继续堆强约束？
- [ ] 从人设图写提示词时，是否排除三视图拼版和重复人物？
- [ ] 是否没有擅自附加用户未要求的视频提示词？
