# 表演与情绪引擎

> 用途：第5站生视频时，给每个镜头补【表演细节】。核心语法：**心理动机 → 外显动作**，不写孤立表情。
> 继承自 seedance-emotion-director（情绪工程）+ storyboard-prompt-optimizer2.0（6 维度心理驱动）。

---

## 一、总原则

1. 表演由清晰心理动机驱动，不是「让人物做表情/加动作」，而是让内心动机外化成生物力学真实的肢体。
2. **禁止文学修辞**（心如刀割、柔情似水…）、**禁止精确物理数值**（毫米/厘米/角度/赫兹）。
3. 情绪曲线连续，相邻阶段必须有过渡缓冲，禁止突然跳变。
4. 禁止角色长时间静止、面无表情、动作机械重复。

## 二、两层结构

- **第一层 镜头级表演标签**（给人看分镜，≤20 字）：写「心理动机 + 最关键外显动作」。例：`克制解释，低头组织语言，抬眼未对准镜头，指尖轻叩杯沿`。
- **第二层 模型表演规则**（给生视频模型）：从下方挂载矩阵抽取适用维度，浓缩成一两句话 + 一行负面清单。

### 心理动机词库

克制 / 试探 / 隐忍 / 回忆 / 撒谎 / 后悔 / 故作轻松 / 解释 / 隐瞒 / 压迫 / 委屈 / 警觉 / 得意 / 惊惧 / 决绝 / 麻木

## 三、6 维度表演挂载矩阵

| 维度 | 真人写实·文戏 | CG·文戏 | 二维动画·文戏 | 武戏（任意风格） |
|---|---|---|---|---|
| 1 心理与表演一致性 | ✅ 全量 | ✅ 全量 | △ 简化为表情夸张度+色调 | △ 杀气/决心/惊惧 |
| 2 伴随性肢体语言 | ✅ 全量 | ✅ 全量 | △ 关键帧 pose 替代 | △ 紧绷有力肢体 |
| 3 身体生物力学 | ✅ 全量 | ✅ 全量 | ✗ 不适用 | △ 动力学联动 |
| 4 物理与接触真实感 | ✅ 全量 | ✅ 全量 | ✗ 不适用 | △ 打击感+碰撞 |
| 5 环境响应 | ✅ 全量 | △ 粒子/布料模拟 | △ 速度线/残影 | △ 粒子特效+布料 |
| 6 影像与空间一致性 | ✅ 实拍设备感 | ✅ 电影级镜头 | ✗ 不适用 | ✅ 电影级镜头 |

**使用规则**：只写 ✅ / △ 维度；✗ 维度绝不出现（例如二维动画里不写「呼吸起伏、肌肉联动」）。△ 维度按括号里的简化方式描述。末尾附一行负面清单。

## 四、情绪生理表现表（抽象情绪 → 可拍生理指标）

| 情绪 | 生理表现 |
|------|----------|
| 恐惧 | 瞳孔明显扩大，眼白暴露增多，胸口快速起伏，手指轻微颤抖，身体向后缩紧 |
| 愤怒 | 下颌肌肉隆起，颈部青筋可见，鼻孔扩张呼气粗重，拳头紧握至指节发白 |
| 悲伤 | 眼睑缓慢下垂，下眼睑湿润反光，嘴角明显下拉，肩膀向内收紧，头部低垂 |
| 喜悦 | 嘴角明显上扬，眼角出现皱纹，身体舒展打开，动作幅度增大 |
| 震惊 | 瞳孔骤然收缩，嘴巴微张未合，身体瞬间僵直，长时间不眨眼 |
| 决绝 | 下颌向前顶出，眼神直视固定一点，嘴唇抿成一线，动作变慢但用力加重 |
| 麻木 | 面部松弛无表情，眨眼间隔变长，身体长时间静止，胸口几乎无起伏 |
| 绝望 | 瞳孔涣散无焦点，头部无力下垂，双手自然垂落身侧，膝盖弯曲跪地 |
| 仇恨 | 眼神直盯目标，嘴角下拉，下颌咬紧，呼吸平稳控制，动作精准无多余 |
| 爱恋 | 视线缓慢扫过对方面部，眼睑低垂，嘴角轻微上扬，身体不自觉倾向对方 |

**情绪曲线模板**（按剧情选用或组合）：
- 正向链：平静 → 疑惑 → 震惊 → 狂喜 → 失控 → 崩溃 → 释然
- 负向链：压抑 → 愤怒 → 爆发 → 疯狂 → 毁灭 → 空洞

## 五、动作四要素 + 四层次

**动作四要素**：起点/过程/终点齐全；动作间有过渡；速度有变化（缓慢→加速→骤停）；幅度与情绪强度成正比。用「耗时约 X 秒」替代速度数值，用「轻柔/用力/爆发」替代力度数值。

**四层次**（角色必须具备）：

| 类型 | 定义 | 示例 |
|------|------|------|
| 微动作 | 无意识持续小幅动作 | 手指轻微抽搐、脚尖轻点地面 |
| 惯性动作 | 情绪驱动的习惯动作 | 紧张摸耳垂、愤怒握拳松开反复 |
| 神经反应 | 突发刺激的本能反应 | 瞳孔震动、吞咽、喉结滚动 |
| 失控反应 | 情绪峰值的身体失控 | 肩膀剧烈抖动、膝盖发软、牙齿打颤 |

## 六、台词与声音

- 台词标注维度：音量（耳语/低声/正常/大声/嘶喊）+ 音质（清晰/沙哑/颤抖/劈裂/含混）+ 语速（缓慢/正常/急促/断续）。
- 笑声、哭声必须写形成过程，禁止直接写「哈哈哈」：先短促吸气 → 鼻腔挤出笑声 → 演变成狂笑。
- 声音四层都要照顾：环境声 / 动作声 / 呼吸声 / 情绪声。

## 七、禁忌清单（输出前自检）

- [ ] 无文学修辞、无精确物理数值
- [ ] 表演为「心理动机 → 外显动作」，不写孤立表情
- [ ] 情绪曲线连续，有过渡缓冲
- [ ] 只写适用维度的维度指令，✗ 维度未出现
- [ ] 笑声/哭声写了形成过程
- [ ] 角色有生命感，无木偶化（不静止/不面瘫/不机械重复）

## 八、人物动作表演规则（连续镜头必备）

**核心：每个含人物的镜头，人物必须有主动肢体动作，禁止只写被动状态（衣摆被吹、被托举）或完全不写。**

1. **主动肢体动作必写**：每个含人物的镜头，写明人物「四肢姿态 + 躯干方向 + 头部朝向 + 身体重心/漂浮状态」四要素，让模型有具体动作可执行。
   - 反例（僵硬）：「二创女位于爆炸中心，衣摆与发丝被掀起」——人物完全静止，AI 只能僵站。
   - 正例（有动作）：「冲击波将她从直立向后上方掀动，双脚离地，上身向后仰起，双臂向两侧张开稳住身形，头微微扬起，随后保持后仰悬浮姿态」。
2. **连续镜头动作衔接**：镜与镜之间写「承接上文，从 XX 姿态转为 XX」，把上一镜结尾的姿态接到下一镜开头，避免人物状态跳变、动作断层。
   - 例：「承接上文，她在爆炸后的后仰悬浮中，随流光托举缓缓竖直升起…」
3. **特效镜头人物不能没有动作**：即使角色设定为宁静/被保护（如八音盒人偶、不被冲击），特效镜头中人物也要有克制的微动作（睁眼、呼吸起伏、指尖轻抬、衣摆轻动、缓缓抬头等），禁止完全静止木偶化。
   - **冲击与否先询问**：特效（爆炸/冲击）发生时，人物是「保持不动」还是「受到冲击」，若剧情未明确，必须先询问用户确认，不得自行猜测。
4. **轻盈/漂浮人物设定**：动作词用「缓慢舒展、轻抬、随流而转、自然下垂、失重上浮」，明确无重力感，禁止僵硬站立姿态；漂浮人物双腿自然微屈下垂而非笔直紧绷。
5. 身体部位一律用日常词（手臂、上身、双腿、指尖、头），禁用精确数值。

6. **pose 剧情与衔接检查**：任何带人物的镜头，自检人物 pose 是否符合剧情逻辑（该保持还是被冲击、该苏醒还是沉睡），并与前一镜/后一镜姿态衔接一致；发现矛盾立即修正，输出前逐镜过一遍。

## 九、官方四要素公式（v1.0 融合自字节 Seedance 规范）

本引擎原有的「**心理动机 → 外显动作**」是**纵向**的（从内心到身体）；官方补充的是**横向**的（从触发到画面）。两者合并，表演才完整。

### 合并公式

```
心理动机 / 情绪方向
  + 触发事件（画面上发生了什么）
  + 人物可观察表现（生理层）
  + 镜头 / 光线 / 声音的可观察变化
```

### 四要素逐条说明

| 要素 | 写什么 | 范例 |
|---|---|---|
| **① 情绪方向** | 整体从什么情绪转到什么情绪 | 整体情绪从克制的期待转为失落后的强装平静 |
| **② 触发事件** | 画面上发生的具体事，是反应的因 | 服务员把退回的信放到桌面 |
| **③ 可观察表现** | 生理层：眼神/眉头/嘴角/呼吸/视线/手部/姿态 | 摩挲杯沿的手指突然停住，视线落在退回标记上 |
| **④ 声光镜头变化** | 镜头、光线、声音随情绪的可观察变化 | 缓慢吸气后把信翻面扣在桌上，肩膀保持挺直 |

### 三条纪律

1. **先因后果**：先展示触发原因，再展示人物反应。原因与反应距离远时，用一次明确的视线或镜头转移建立关系；能同框就在同一构图内同时保留原因与反应。
2. **少量而准**：选**少量最清楚**的表现，不要堆满所有微表情（堆多了模型会糊）。
3. **多次转折才分阶段**：只有情绪转折好几次时才按触发事件分阶段，单次转变不要拆。

### 与原「心理动机→外显动作」的对应

```
                 心理动机（来自剧情）
                        ↓
情绪方向  →  触发事件（来自画面）  →  可观察表现  →  声光镜头变化
                        ↑
                 外显动作（落到生理）
```

**结论**：动机来自剧情，触发来自画面，表现落到生理，声光负责强化。
