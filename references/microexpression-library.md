## 使用规则

1. 先判断人物的主情绪，再选择一个基础模块。
2. 需要复合情绪时，只增加一个“抵抗情绪”或“次级情绪”，不要同时拼接三个模块。
3. 先复制模块中的可复制提示词，再替换人物、触发事件、视线对象、道具和最终动作。
4. 保留模块的动作顺序，不把所有动作改成同时发生。
5. 允许删除不适合当前画面的动作，不强行补齐每个面部区域。
6. 道具或手部不可见时，删除相关反馈，不凭空加入。
7. 用户指定时长后，按 `performance-arc.md` 第四节「时间轴密度」重新分配动作。
8. 模块中的情绪词只用于定调；最终输出必须保留可见动作。
9. 找不到完全匹配的模块时，按“情绪方向、唤醒强度、自我控制、关系姿态”选择最近模块。
10. 同一人物连续镜头中避免反复使用完全相同的泄露动作。

## 通用选择卡

无论用户输入情节、情绪词还是旧提示词，都按以下顺序选择：

1. 读首帧与情节证据，确定人物姿态和表演强度上限。
2. 选一个主模块，明确人物正在感受什么。
3. 选一个主导通道：眼神、呼吸、嘴角、下颌、手部或身体。
4. 如有复合情绪，只选一个次级通道留下破绽。
5. 让每个阶段承接上一段的呼吸、泪光、手势、姿态和道具位置。
6. 用一个可见开关引发新变化，最后锁定物理落点和最后一帧。

这张卡的优先级高于“多选几个表情”。证据不足时降低强度，不靠增加动作补偿。

## 强度与节奏

### 三级强度

| 强度 | 动作数量 | 幅度与节奏 | 适用 |
|---|---:|---|---|
| 1 级：极轻 | 1 个主动作 + 1 个辅助动作 | 几乎不可察觉，短暂出现后收束 | 暗流、潜台词、初次破绽 |
| 2 级：克制 | 1—2 个主动作 + 1 个泄露 | 清晰但不过度，允许一次停顿 | 电影近景、主要默认值 |
| 3 级：明显但真实 | 2 个主动作 + 1 个身体或道具反馈 | 观众可明确识别，仍避免舞台化 | 强冲突、转折、高潮前 |

默认使用 2 级。用户只说“微表情”时使用 1—2 级，不自动升级到 3 级。

### 幅度词

- 极轻：几乎不可察觉、极其细微、短暂闪过、只动了一瞬；
- 克制：小幅、缓慢形成、短暂停留、随后压回；
- 明显但真实：清晰可见、逐渐加强、仍保持连续、不突然爆发；
- 收束：重新稳定、逐渐放松、恢复表面平静、停在未完成状态。

### 时间词

- 起点：起初、最开始、短暂保持；
- 触发：听见后、看清后、意识到后、对视的一瞬；
- 发展：随后、逐渐、慢慢、停顿片刻；
- 抵抗：又强迫自己、试图压住、迅速收回、重新控制；
- 泄露：却仍然、但手指、然而呼吸、只有眼神；
- 结尾：最终、最后、停留在、动作没有完全完成。

### 升档、降档与主导通道

- 升档：注视更稳或更窄，呼吸压力增加，下颌、手部或重心随后参与；不只把“轻微”改成“剧烈”。
- 降档：眼神失去抓取，呼吸变长或变浅，肩颈、手势和重心逐步下沉；保留上一状态的痕迹。
- 平档：强度不变，只让一个通道产生新信号，用于潜台词、怀疑、礼貌伪装和安静对视。
- 批量或多角色输出时轮换主导通道，相邻镜头不连续使用同一套垂眼、吸气、抿嘴和抬眼。

## 易混情绪辨别

| 组合 | 前者的主要信号 | 后者的主要信号 |
|---|---|---|
| 真诚微笑 / 讨好假笑 | 眼神稳定变柔，眼周和面颊自然参与 | 嘴角先用力，眼神仍在观察对方反应 |
| 压抑愤怒 / 坚定 | 目光带对抗，下颌和手部积压张力 | 目光清醒稳定，呼吸受控，身体站稳而不逼近 |
| 忧郁 / 绝望麻木 | 仍会看、叹气、触碰或微弱回应 | 视线失去抓取，动作意图和身体支撑明显减少 |
| 惊讶 / 惊恐 | 短暂停住后开始确认信息 | 身体后撤或防御，呼吸卡住并持续寻找威胁 |
| 轻蔑 / 冷漠 | 会用余光、单侧嘴角或下巴主动表达优越 | 几乎不给反应，视线越过对方并继续原动作 |
| 委屈 / 哀求 | 想解释却后撤，身体缩小 | 目光持续追随，身体主动靠近或降低姿态 |
| 无奈苦笑 / 释然微笑 | 笑只停在单侧嘴角，眼神仍疲惫 | 眉眼、下颌和肩颈的紧张真正松开 |

| 动作 | 视觉效果 | 使用提示 |

| 视线停顿 | 认知被打断、突然理解 | 适合作为第一处情绪裂缝 |

## A. 自然、认知与思考

### A01 自然中性

- 适用：等待、待机、无明显情绪前的基准。
- 路径：稳定注视 → 自然眨眼 → 轻微呼吸与平衡微动。
- 落点：维持放松但非照片式静止。
- 可复制：人物保持自然放松的中性表情，目光稳定落在前方，眼球有极轻微的自然注视调整，间隔自然地缓慢眨眼。眉心放松，嘴唇自然闭合，下颌没有用力，胸口随平稳呼吸轻微起伏，头部只有几乎不可察觉的平衡微动。
- 避免：完全冻结、频繁眨眼、嘴部随机动作。

### A02 专注倾听

- 适用：听取重要信息但尚未作出判断。
- 路径：注视说话者 → 下眼睑轻收 → 眨眼变慢 → 头部微微前倾。
- 落点：持续而克制的关注。
- 可复制：人物安静看着说话者，目光停留时间逐渐变长，下眼睑轻微收紧，眉毛内侧略有抬起，嘴唇自然闭合。她缓慢眨眼一次，头部极小幅度前倾，呼吸保持平稳，最后继续专注倾听，不产生多余口型。
- 避免：连续点头、目光乱飘、夸张挑眉。

### A03 若有所思

- 适用：整理信息、回想、权衡。
- 路径：视线移向侧下方 → 短暂失焦 → 眉心浅收 → 嘴唇轻抿后放松。
- 落点：停在尚未得出答案的思考中。
- 可复制：人物原本平静注视前方，随后目光缓慢移向侧下方并短暂失焦，眉心极浅地聚拢。双唇轻轻抿住又松开，下颌略微下沉，头部向一侧偏几度，最后停留在安静整理信息的状态。
- 避免：眼球快速左右乱转、抓头、明显自言自语。

### A04 回忆浮现

- 适用：某个细节唤起过去。
- 路径：视线停顿 → 焦点越过眼前对象 → 呼吸变慢 → 嘴角产生与回忆性质一致的轻微变化。
- 落点：短暂停在回忆中后重新感知现实。
- 可复制：听见熟悉的信息后，人物的视线停顿片刻，焦点像越过眼前的人落到更远处，眨眼速度变慢。她轻轻呼吸，嘴角只产生极浅的松动，随后重新聚焦眼前，回忆没有完全消失。
- 避免：突然闪回式大幅变脸、长时间呆滞。

### A05 突然想明白

- 适用：恍然大悟、找到关键、理解隐含意义。
- 路径：目光游移 → 突然聚焦 → 眉心舒展 → 双唇微分后形成轻微确认。
- 落点：稳定而克制的“明白了”。
- 可复制：人物原本目光略有游移，眉心轻轻收紧。某个瞬间，她的视线突然重新聚焦，眉间紧张迅速舒展，双唇短暂微分，随后嘴角出现一丝极浅的确认感。她轻轻吸气，头部几乎不可察觉地点动一下。
- 避免：夸张瞪眼、拍头、明显大笑。

### A06 轻微困惑

- 适用：信息不合逻辑、没有听懂、需要确认。
- 路径：注视停顿 → 双眼轻收 → 单侧眉尾轻抬 → 头部小幅倾斜。
- 落点：重新观察而非直接否定。
- 可复制：人物先保持正常凝视，随后目光短暂游移，双眼轻微收窄。一侧眉尾缓慢抬起，眉心形成很浅的不对称变化，嘴唇轻轻压住，头部向一侧倾斜几度，最后停在重新理解信息的状态。
- 避免：大幅歪头、双眉夸张抬高、滑稽表情。

### A07 怀疑判断

- 适用：不完全相信、审视动机、确认谎言。
- 路径：注视时间变长 → 下眼睑收紧 → 眉心浅纹 → 一侧嘴角轻动。
- 落点：保持审视，不急于表态。
- 可复制：人物沉默看着对方，目光停留得比平时更久，下眼睑逐渐收紧，眉心出现极浅纹路。一侧嘴角几乎不可察觉地动了一下，下巴轻轻抬高，呼吸放慢，最后仍不移开视线。
- 避免：眯眼过度、明显冷笑、连续摇头。

### A08 犹豫不决

- 适用：两个选择之间摇摆、无法回答。
- 路径：视线在两个落点间缓慢移动 → 嘴唇轻抿 → 头部欲转又停 → 呼吸略浅。
- 落点：动作未完成，决定尚未形成。
- 可复制：人物的目光在两个方向之间缓慢移动，短暂看向一侧又收回。她轻轻抿唇，下颌产生极小幅度的移动，头部像要转过去却停住，呼吸逐渐变浅，最后仍没有作出决定。
- 避免：眼神快速乱飘、来回摇头、重复小动作。

### A09 意识到自己犯错

- 适用：发现误解、失言或造成伤害。
- 路径：视线冻结 → 眉部轻抬 → 嘴唇微分 → 目光下落 → 吞咽。
- 落点：想解释但暂时说不出口。
- 可复制：人物意识到自己犯错后，视线突然停住，眉毛内侧极轻抬起，嘴唇微微分开。她想立刻解释，却在开口前将目光缓慢移向下方，无声吞咽一次，双唇重新合拢，最后停在后悔而不知如何补救的状态。
- 避免：立刻大哭、夸张捂嘴、大幅后退。

### A10 下定决心

- 适用：从犹豫转为行动、承担后果。
- 路径：目光回避 → 缓慢吸气 → 重新聚焦 → 下颌稳定 → 头部轻抬。
- 落点：一个小而明确的行动信号。
- 可复制：人物起初目光略有游移，随后缓慢吸气，重新抬眼并稳定看向目标。眉毛轻微下压，下颌逐渐绷稳，双唇收成平静直线。她的头部轻轻抬起，最后用收紧手指或向前迈出前的微小重心变化表达决定已经形成。
- 避免：突然握拳怒吼、夸张点头、英雄式摆姿势。

## B. 喜悦、亲密与被打动

### B01 浅淡喜悦

- 适用：得到好消息、小小满足。
- 路径：眼神变柔 → 面颊轻抬 → 嘴角小幅上扬 → 呼吸放松。
- 落点：闭口浅笑短暂停留。
- 可复制：人物起初保持平静，随后眼神逐渐柔和，下眼睑轻微抬起，面颊缓慢上升，嘴角以很小幅度自然上扬，始终闭口不露齿。她缓慢呼气，笑意短暂停留在克制温和的状态。
- 避免：咧嘴、持续固定笑容、机械对称。

### B02 真诚开心

- 适用：明确而真实的好消息，但仍保持电影式克制。
- 路径：眼睛先亮 → 面颊与眼角参与 → 嘴角自然上扬 → 肩颈放松。
- 落点：笑容具有呼吸变化，不僵住。
- 可复制：人物听见好消息后，视线迅速变得明亮，眼周逐渐放松，下眼睑和面颊共同轻轻抬起。嘴角自然上扬，露齿很少或不露齿，肩颈随一口轻快的呼气放松，最后保持真实但不过度的喜悦。
- 避免：突然大笑、笑容冻结、只有嘴角没有眼部参与。

### B03 忍不住想笑

- 适用：需要保持严肃却被逗笑。
- 路径：嘴唇抿住 → 单侧嘴角先动 → 眼角轻收 → 鼻腔呼气 → 压回。
- 落点：表面恢复严肃，眼神仍有笑意。
- 可复制：人物努力维持严肃，先轻轻抿住嘴唇，一侧嘴角却短暂上扬，另一侧慢半拍跟随，眼角出现很浅的笑纹。她从鼻腔轻轻呼气，把笑意重新压回去，最后嘴角恢复平静，眼神里仍残留一点笑意。
- 避免：耸肩大笑、连续憋笑抽动、明显露齿。

### B04 暗自得意

- 适用：小胜利、判断得到验证、掌握优势。
- 路径：侧向一瞥 → 单侧眉尾轻抬 → 单侧嘴角上扬 → 下巴轻抬 → 收敛。
- 落点：不动声色的满足。
- 可复制：人物表面保持平静，目光短暂向侧方瞥去后重新看向前方。一侧眉尾轻轻抬起，同侧嘴角缓慢上扬，形成极浅的不对称闭口微笑。她的下巴略微抬高，笑意很快被收敛，只留下不动声色的满足感。
- 避免：夸张挑眉、明显坏笑、摇头晃脑。

### B05 温柔注视

- 适用：亲近、安慰、理解对方。
- 路径：注视稳定 → 眼睑放松 → 眉心舒展 → 面颊与嘴角轻抬 → 头部轻倾。
- 落点：安静而有亲近感的凝视。
- 可复制：人物持续看着对方，原本集中的目光逐渐变柔，眨眼速度稍慢。眉心完全舒展，面颊轻轻抬起，嘴角形成极浅的闭口微笑。她呼吸缓慢，头部向对方轻微倾斜，最后保持温柔而不黏腻的注视。
- 避免：持续傻笑、过度歪头、眼神失去焦点。

### B06 看见喜欢的人

- 适用：突然见到有好感的人。
- 路径：呼吸漏拍 → 目光锁定 → 眼神变柔 → 嘴角不受控上扬 → 意识到后移开 → 偷看。
- 落点：好感被压住但没有完全藏住。
- 可复制：人物看到对方的一瞬呼吸短暂停顿，眼睛略微睁大，目光快速锁定。随后眼神变柔，面颊轻抬，嘴角不受控制地形成很浅的闭口微笑。她意识到自己的反应后轻轻抿唇，短暂移开视线，最后又用余光看回去。
- 避免：花痴式大笑、连续眨眼、夸张脸红。

### B07 害羞心动

- 适用：亲密对视、被夸奖、关系升温。
- 路径：短暂对视 → 视线移向侧下 → 下巴轻收 → 嘴角被抿住 → 再次偷看。
- 落点：想靠近又保留距离。
- 可复制：人物与对方短暂对视后，将目光迅速移向侧下方，轻轻眨眼一次。下巴自然收回，嘴角刚要上扬便被双唇轻轻抿住，呼吸略微加快。停顿片刻，她再次用余光看向对方，没有大幅移动身体。
- 避免：大幅扭头、连续捂脸、夸张咬唇。

### B08 欣慰满足

- 适用：看到努力有结果、确认对方平安或成长。
- 路径：眉心紧张舒展 → 眼神变柔 → 面颊轻抬 → 缓慢呼气 → 肩膀放松。
- 落点：稳定、温和的满足。
- 可复制：人物原本认真注视，随后眉心残留的紧张逐渐舒展，眼神变得柔和，面颊缓慢上升，嘴角形成稳定而克制的闭口微笑。她缓慢呼出一口气，下颌和肩膀同步放松，最后极轻地点动一下。
- 避免：明显鼓掌、大笑、连续点头。

### B09 如释重负

- 适用：危险解除、结果比预期更好。
- 路径：紧绷基准 → 闭眼或眨眼停顿 → 长呼气 → 下颌放松 → 浅笑。
- 落点：身体比面部先明显松下来。
- 可复制：人物起初眉心轻锁、嘴唇闭紧。确认结果后，她短暂闭眼并缓慢呼出一口气，下颌和牙关逐渐松开，眉部舒展，肩膀轻轻下沉。嘴角最后出现一丝很浅的笑意，头部略微低下。
- 避免：夸张瘫坐、放声大笑、用力拍胸。

### B10 久别重逢

- 适用：重见重要的人、确认对方真实存在。
- 路径：愣住 → 双唇微分 → 长时间确认 → 眼眶湿润 → 含泪浅笑。
- 落点：想靠近但先停在凝视中。
- 可复制：人物看见对方后先短暂愣住，上眼睑轻抬，双唇微微分开，像是不敢确认。目光停留片刻后逐渐变柔，眼眶中的湿润慢慢积聚，嘴角缓慢上扬。她轻轻吸气，身体想向前靠近却只移动少许，最后停在含泪而克制的微笑中。
- 避免：立刻扑抱、大哭、剧烈摇头。

### B11 被打动与感激

- 适用：收到真诚帮助、听见重要承诺、发现自己被理解。
- 路径：防备或紧张停顿 → 眼神逐渐变柔 → 眉心舒展 → 眼眶轻湿 → 嘴角极浅上扬。
- 落点：想表达感谢但先停在安静注视中。
- 可复制：人物起初仍保留一点紧张，听见对方的话后，视线停顿片刻，眼神逐渐变柔，眉心慢慢舒展。眼眶边缘浮起极浅湿润，嘴角轻轻上扬又被克制住。她缓慢吸气，双唇微微分开像要道谢，却先停在安静而真诚的凝视中。
- 避免：立刻流泪拥抱、连续点头、咧嘴大笑。

## C. 悲伤、失落与脆弱

### C01 失望

- 适用：期待落空、被拒绝、结果不如预期。
- 路径：期待凝视 → 眼神黯淡 → 上眼睑下落 → 笑意消失 → 视线下移。
- 落点：不再继续追问。
- 可复制：人物原本带着轻微期待看向前方，听见结果后目光逐渐失去亮度，上眼睑缓慢下落，嘴角残留的笑意一点点消失。她几乎无声地呼出一口气，视线移向地面，最后不再看向对方。
- 避免：突然哭泣、大幅低头、明显撇嘴。

### C02 克制悲伤

- 适用：难过但必须保持体面。
- 路径：焦点不稳 → 内眉轻抬靠拢 → 嘴角轻下 → 下唇微颤 → 抿回。
- 落点：情绪被压回，但没有消失。
- 可复制：人物努力保持正常注视，但目光的焦点逐渐变得不稳定。内眉缓慢抬起并轻轻靠拢，上眼睑略显沉重，嘴角只有极小幅度的下沉。她轻轻吸气，下唇短暂颤动，随即抿紧双唇，把情绪重新压回平静。
- 避免：嚎啕大哭、连续抽泣、明显皱成苦脸。

### C03 委屈

- 适用：被误解、无法解释、付出未被看见。
- 路径：内眉抬起 → 眼眶湿润 → 下唇轻颤 → 想说又闭口 → 头部偏开。
- 落点：想解释但放弃。
- 可复制：人物努力维持平静，内眉却逐渐抬高并靠拢，下眼睑轻微绷紧，眼眶开始湿润。嘴角向下牵动，下唇出现极弱颤抖。她短促吸气，嘴唇微微分开像要解释，最终又闭紧，头部轻微偏开。
- 避免：噘嘴卖萌、大声哭诉、持续颤抖。

### C04 后悔自责

- 适用：意识到伤害了别人、错过机会。
- 路径：断开对视 → 眉心收紧 → 嘴唇抿紧 → 下颌绷紧 → 吞咽 → 头部降低。
- 落点：沉默承担而非求安慰。
- 可复制：人物原本看着前方，随后缓慢低下视线，不再与任何人对视。眉心收紧，双唇轻轻抿住，下颌和咬肌出现细微紧张。她无声吞咽一次，缓慢呼气，头部逐渐低下，最后停在沉默自责中。
- 避免：夸张捶胸、立刻跪下、大幅摇头。

### C05 愧疚心虚

- 适用：隐瞒造成伤害、面对受害者。
- 路径：对视变短 → 视线侧下回避 → 嘴唇压紧 → 吞咽 → 强迫重新对视。
- 落点：表面恢复但仍不自然。
- 可复制：人物与对方对视的时间明显缩短，目光短暂移向侧下方，嘴唇迅速压紧。她无声吞咽一次，呼吸变浅，随后强迫自己重新看向对方。眉心被主动放松，但下颌仍残留轻微紧张。
- 避免：把动作当作现实测谎依据、连续躲闪、夸张冒汗。

### C06 强忍眼泪

- 适用：不愿在别人面前哭、必须继续说话或行动。
- 路径：湿润积聚 → 目光短暂上移 → 快速眨眼一次 → 下唇轻颤 → 吞咽 → 移开。
- 落点：泪光停留但不落下。
- 可复制：人物眼眶中的湿润逐渐积聚，目光短暂向上移动，随后快速眨眼一次，试图把眼泪压回去。内眉轻抬，下唇只颤动一瞬。她无声吞咽，双唇重新闭紧，最后缓慢移开视线，泪光仍停留在眼眶中。
- 避免：眼泪突然喷涌、连续快速眨眼、明显抽泣。

### C07 泪水即将落下

- 适用：情绪接近阈值，但尚未崩溃。
- 路径：泪光增多 → 下眼睑轻抬 → 呼吸变浅 → 嘴角轻下 → 一滴泪形成。
- 落点：最多一滴泪，面部仍克制。
- 可复制：人物持续看着前方，眼眶中的湿润缓慢积聚，下眼睑轻微抬起，泪水停留在边缘。她的呼吸逐渐变浅，嘴角小幅下沉，下唇出现极弱颤动。最终只有一滴眼泪缓慢滑落，面部没有明显哭相。
- 避免：多股泪水、哭到变形、持续抽噎。

### C08 心碎失神

- 适用：重大情感打击、无法立即消化。
- 路径：面部短暂停住 → 目光失焦 → 眉部张力消失 → 双唇微分 → 下颌失去力量。
- 落点：空洞而非外放痛哭。
- 可复制：听完消息后，人物的面部短暂静止，呼吸停顿，随后目光逐渐失去焦点。眉心原有的紧张慢慢消失，眼睑变得沉重，双唇无意识地微微分开，下颌逐渐失去力量。她缓慢呼气，没有哭泣，只剩空洞的凝视。
- 避免：突然尖叫、抓头、立即跌倒。

### C09 被抛下的失落

- 适用：对方离开、关系断裂、挽留失败。
- 路径：视线追随 → 想开口 → 手或身体想追上 → 动作停住 → 手垂下。
- 落点：未完成的挽留。
- 可复制：人物的目光跟随对方离开的方向，嘴唇微微分开，像想叫住对方，却没有发出声音。身体向前移动少许，手也抬起一点，随后动作停在半途。她缓慢合拢嘴唇，手臂一点点垂下，最后仍看着对方离开的方向。
- 避免：追跑、大喊、夸张伸手。

### C10 孤独空落

- 适用：热闹之后独处、等待落空。
- 路径：保持姿态 → 视线从外界收回 → 眨眼变慢 → 呼气变长 → 肩膀轻沉。
- 落点：安静地失去外部连接。
- 可复制：人物起初仍维持原来的坐姿或站姿，随后视线从远处缓慢收回，却没有落到任何明确目标。眨眼速度逐渐变慢，双唇自然微张，呼气比吸气更长，肩膀随之轻轻下沉，最后停在安静而空落的状态。
- 避免：抱膝大哭、持续叹气、过度低头。

### C11 怀念

- 适用：看到旧物、想起故人、温柔的遗憾。
- 路径：触碰或注视旧物 → 眼神变柔 → 极浅笑意 → 笑意被失落覆盖 → 指尖停住。
- 落点：温柔与悲伤同时存在。
- 可复制：人物看着眼前的旧物，目光逐渐变柔，嘴角出现一丝很浅的笑意。停顿片刻，笑意没有继续扩大，反而慢慢收敛，眼神里浮出淡淡失落。她的指尖停在物体边缘，没有立即收回，最后缓慢呼出一口气。
- 避免：单纯开心笑、突然泪崩、反复抚摸。

### C12 不舍告别

- 适用：必须离开但感情仍在。
- 路径：保持对视 → 嘴角尝试微笑 → 视线回避 → 转身欲走 → 停顿 → 最后离开或回看。
- 落点：由一个延迟动作表达不舍。
- 可复制：人物努力保持平静对视，嘴角勉强形成很浅的微笑，很快又收敛。她短暂移开视线，缓慢转身，却在动作刚开始时停顿片刻。呼吸变得更深，最后才继续离开，或在离开前只回看一眼。
- 避免：长时间挥手、大哭拥抱、反复回头。

### C13 羞愧

- 适用：公开失误、道德自责、无法面对对方。
- 路径：对视迅速缩短 → 视线下落 → 面部张力收紧 → 双唇压住 → 肩颈轻缩 → 尝试抬眼失败。
- 落点：愿意承担但暂时无法直视。
- 可复制：人物意识到自己的行为被看见后，与对方的对视迅速缩短，目光缓慢落向下方。眉心和面颊出现细微紧张，双唇轻轻压住，下巴收回少许，肩颈也有极小幅度内缩。她尝试重新抬眼，却只看了一瞬便再次垂下视线。
- 避免：捂脸逃跑、夸张脸红、自我惩罚式动作。

## D. 惊讶、紧张与恐惧

### D01 轻微惊讶

- 适用：意外信息、小幅超出预期。
- 路径：呼吸漏拍 → 上眼睑轻抬 → 眉毛轻抬 → 双唇微分 → 恢复。
- 落点：回到观察状态。
- 可复制：人物看到意外情况时呼吸短暂停顿，上眼睑迅速但小幅抬起，双眼略微睁大，眉毛轻轻上扬，双唇短暂分开少许。惊讶只停留一瞬，随后眼睑和眉部逐渐恢复，嘴唇重新闭合。
- 避免：瞪大眼睛、张大嘴、后仰。

### D02 难以置信

- 适用：信息与认知严重冲突。
- 路径：眼睛先睁大 → 再缓慢眯起确认 → 眉毛由抬高转为靠拢 → 微幅摇头一次。
- 落点：仍无法接受但保持控制。
- 可复制：人物先短暂睁大双眼，随后目光在对方脸上停留得更久，双眼缓慢收窄，像在重新确认。眉毛先轻抬，再向眉心靠拢，双唇微分后重新抿紧，头部只极小幅度左右移动一次。
- 避免：连续摇头、夸张张嘴、反复眨眼。

### D03 强装镇定的震惊

- 适用：重大消息下仍需维持权威或体面。
- 路径：目光冻结 → 双唇微分 → 下颌迅速绷紧 → 吞咽 → 主动恢复表情。
- 落点：表面镇定，眼神仍有余震。
- 可复制：人物听见消息后视线瞬间定住，上眼睑小幅抬起，双唇几乎不可察觉地分开。她迅速绷紧下颌，无声吞咽一次，缓慢用鼻腔吸气，主动将嘴唇重新闭合。眉部恢复平静，但眼神中的震动没有完全消失。
- 避免：大幅后退、捂嘴、全脸夸张僵硬。

### D04 警觉

- 适用：听见异常声音、发现有人靠近。
- 路径：停止当前小动作 → 视线迅速转向来源 → 上眼睑轻抬、下眼睑收紧 → 头部缓慢跟随。
- 落点：身体保持克制的戒备。
- 可复制：人物原本自然观察周围，听见异常后立即停止当前小动作，目光先迅速转向声音来源。上眼睑轻抬，下眼睑收紧，嘴唇自然闭紧，下颌逐渐稳定。头部随后以很小幅度缓慢转向同一方向，最后保持警觉。
- 避免：突然甩头、眼球乱转、身体剧烈后退。

### D05 紧张不安

- 适用：等待结果、面对审问、担心暴露。
- 路径：注视难以维持 → 眨眼略增 → 嘴唇反复轻抿后停止 → 呼吸变浅 → 手指微动。
- 落点：努力恢复正常。
- 可复制：人物试图保持平静，但目光只能短暂维持，随后向侧方移开又迅速收回。眨眼频率略有增加，双唇轻轻抿住后放松，下颌出现细小无意识移动。呼吸逐渐变浅，手指在道具边缘轻微收紧，最后强迫自己重新稳定视线。
- 避免：持续眼神乱飘、全身发抖、反复舔唇。

### D06 害怕但不敢表现

- 适用：权力压迫、危险逼近、不能示弱。
- 路径：眼睛略宽 → 下眼睑收紧 → 嘴唇压紧 → 头部轻后缩 → 短促吸气 → 恢复。
- 落点：僵硬但克制的凝视。
- 可复制：人物脸部尽量维持平静，上眼睑却逐渐抬起，眼睛比平时略宽，下眼睑同时收紧。她压紧双唇，下颌绷住，短促吸气，头部几乎不可察觉地后缩。随后她强迫眉部放松，重新维持稳定凝视。
- 避免：尖叫、瞪眼到变形、明显后仰。

### D07 惊慌但不失控

- 适用：突发危险，需要立即判断。
- 路径：视线快速确认多个位置 → 强行锁定目标 → 呼吸加快 → 嘴唇闭紧 → 身体停止多余动作。
- 落点：惊慌被压缩成高度警觉。
- 可复制：人物的双眼迅速睁大，视线在前方几个位置之间快速确认，随后强迫自己固定在一个目标上。眉毛轻抬并向眉心靠拢，双唇短暂张开后立即闭紧，呼吸变快。她稳定下颌和头部，最后把惊慌压成高度警觉。
- 避免：持续扫视、乱跑、夸张喘气。

### D08 察觉危险

- 适用：从正常状态进入威胁判断。
- 路径：目光突然停住 → 呼吸暂停 → 眉心收紧 → 嘴唇闭紧 → 身体或道具进入准备。
- 落点：决定尚未行动。
- 可复制：人物的目光突然定住，呼吸短暂停顿，眼睛小幅睁大，眉心同时轻轻收紧。她缓慢闭紧嘴唇，下颌逐渐绷稳，头部极轻地转向危险来源，握持道具的手指随之收紧，但身体还没有作出更大动作。
- 避免：直接攻击、夸张转身、突然切换表情。

### D09 受惊后一瞬失措

- 适用：突然声响、意外触碰、被叫住。
- 路径：眨眼或闭眼反射 → 肩颈短暂绷紧 → 呼吸急促一拍 → 迅速辨认来源。
- 落点：判断是否安全。
- 可复制：突发刺激出现时，人物反射性地快速眨眼一次，肩颈短暂绷紧，呼吸急促地漏掉一拍。她没有大幅后退，而是立即把视线转向来源，眼神从本能受惊逐渐变成确认和判断。
- 避免：整个人跳起、持续尖叫、镜头式甩头。

### D10 脱险后的余悸

- 适用：危险刚刚解除但身体尚未恢复。
- 路径：确认安全 → 呼吸仍快 → 手部颤抖泄露 → 缓慢呼气 → 肩膀放松。
- 落点：表情恢复快于身体。
- 可复制：确认危险已经解除后，人物的眉部逐渐放松，视线重新稳定，但呼吸仍然偏快。她低头看了一眼自己的手，指尖残留轻微颤抖。随后她缓慢呼出一口气，肩膀一点点放松，最后仍带着尚未完全消散的余悸。
- 避免：立刻完全轻松、夸张瘫倒、持续大喘气。

### D11 冻结型错愕

- 适用：信息超出预期，人物一时无法组织反应。
- 路径：当前动作中断 → 视线固定 → 眨眼延迟 → 嘴唇微分 → 缓慢确认。
- 落点：停住而不是后撤防御。
- 可复制：听见意外信息后，人物正在进行的小动作立即停在原位，视线固定在对方身上，眨眼短暂延迟。她的嘴唇无声微分，却没有形成说话口型；停顿后才缓慢眨眼一次，仍在确认自己是否听错。
- 避免：立即后退、大幅张嘴、连续摇头。

### D12 敬畏震撼

- 适用：面对宏大、庄严、神圣或远超预期的人与事物。
- 路径：视线缓慢抬高 → 眼睑小幅打开 → 嘴唇自然轻启 → 呼吸变轻 → 姿态安静稳定。
- 落点：情绪强，动作反而收敛。
- 可复制：人物的目光缓慢抬向目标，眼睑只小幅打开，双唇不自觉地轻启一丝。她没有立即靠近或后退，只让呼吸逐渐变轻，肩颈保持安静，最后稳定仰望。
- 避免：恐惧式防御、欢呼跳跃、夸张张嘴。

## E. 愤怒、敌意与负面判断

### E01 轻微不悦

- 适用：被冒犯、计划受阻、听见不中听的话。
- 路径：眨眼停顿 → 眉毛轻压 → 嘴角微下 → 鼻腔呼气 → 恢复礼貌。
- 落点：不悦被看见但未升级。
- 可复制：人物听见不合心意的话后，眨眼短暂停顿，眉毛轻微下压，嘴角出现很小的下沉。她从鼻腔缓慢呼出一口气，视线仍留在对方身上，随后主动放松眉心，保持基本礼貌。
- 避免：翻白眼、明显冷哼、夸张撇嘴。

### E02 压抑愤怒

- 适用：不能爆发、权力克制、重要对峙。
- 路径：眉毛下压靠拢 → 下眼睑收紧 → 鼻翼轻扩 → 嘴唇抿紧 → 下颌绷起。
- 落点：怒意集中在稳定凝视和肌肉张力中。
- 可复制：人物沉默注视对方，眉毛缓慢下压并向眉心靠拢，下眼睑逐渐收紧，目光变得锐利。鼻翼轻微扩张，双唇用力抿紧，下颌和咬肌逐渐绷起。她通过鼻腔缓慢呼吸，头部保持不动。
- 避免：怒吼、瞪眼到变形、全身剧烈颤抖。

### E03 怒意逐渐上升

- 适用：耐心不断被消耗、冲突升级。
- 路径：眉心浅收 → 视线锁定 → 鼻翼随呼吸增强 → 嘴角抽动 → 下颌咬紧。
- 落点：即将失去耐心但尚未爆发。
- 可复制：人物最初只有眉心极浅的紧张，随后下眼睑进一步收紧，视线牢牢锁定对方。鼻翼随呼吸逐渐扩张，一侧嘴角短促抽动，双唇压成紧绷直线，下颌慢慢咬紧。呼吸从平稳变得稍重，身体仍保持克制。
- 避免：突然爆发、动作同步全部增强、重复抽动。

### E04 冷漠敌视

- 适用：长期对立、没有交流意愿的威胁。
- 路径：眨眼减少 → 上眼睑略降、下眼睑收紧 → 嘴角静止 → 下颌稳定。
- 落点：没有明显怒容但具有压迫感。
- 可复制：人物长时间注视对方，眨眼自然减少，上眼睑略微降低，下眼睑收紧，使目光变得狭窄而集中。眉毛轻微下压，嘴角几乎不动，双唇保持闭合，下颌稳定绷住，呼吸缓慢。
- 避免：完全不眨眼、夸张邪笑、面部僵死。

### E05 厌恶

- 适用：闻到、看到或听见令人反感的事物。
- 路径：鼻梁轻皱 → 单侧上唇轻抬 → 双眼轻收 → 下巴后收 → 头部偏离。
- 落点：短暂排斥后收敛。
- 可复制：人物看到令自己反感的事物后，鼻梁短暂轻皱，鼻翼收紧，一侧上唇小幅抬高。双眼轻微收窄，下巴向后收少许，头部极轻地偏离目标。反应只出现一瞬，随后嘴唇重新闭合。
- 避免：持续龇牙、夸张吐舌、整张脸扭曲。

### E06 轻蔑

- 适用：认为对方不值得认真回应。
- 路径：稳定凝视 → 单侧嘴角上牵 → 同侧面颊收紧 → 下巴轻抬。
- 落点：不对称、低温度的微笑。
- 可复制：人物平静看着对方，下眼睑轻微收紧，眼神没有笑意。一侧嘴角缓慢向上牵动，同侧面颊略微收紧，形成极浅的不对称笑意。眉毛基本不动，下巴轻轻抬高，最后保持短暂轻蔑。
- 避免：明显坏笑、夸张挑眉、仰头大笑。

### E07 嫉妒

- 适用：关注被别人夺走、关系比较。
- 路径：注视目标 → 视线转向第三人 → 下眼睑收紧 → 嘴唇抿住 → 一侧嘴角短暂下压 → 假装无事。
- 落点：表情收回，眼神仍残留敌意。
- 可复制：人物先注视重要对象，随后目光缓慢转向旁边的人，下眼睑逐渐收紧，眉心形成浅纹。她轻轻抿唇，一侧嘴角极短暂地下压，下颌略微绷紧。随后她主动放松表情，假装若无其事地移开视线。
- 避免：翻白眼、明显瞪人、夸张撇嘴。

### E08 怨恨

- 适用：旧伤被重新提起、无法原谅。
- 路径：视线停留很久 → 眉心轻收 → 嘴角僵直 → 下颌逐渐紧 → 目光最终移开。
- 落点：不愿继续交流。
- 可复制：人物听见触及旧事的话后，目光在对方脸上停留得很久，眉心极浅地收紧，嘴角失去松弛感。她的下颌逐渐绷紧，呼吸变慢，没有立即反驳。停顿后，她先移开视线，再缓慢转开头部，拒绝继续回应。
- 避免：咬牙切齿、立即争吵、夸张甩头。

### E09 不耐烦

- 适用：重复信息、拖延、被迫等待。
- 路径：视线移开 → 缓慢眨眼 → 一侧嘴角下牵 → 鼻腔呼气 → 重新看回。
- 落点：情绪被压住但交流意愿下降。
- 可复制：人物听到重复或冗长的信息后，目光短暂移向旁边，缓慢眨眼一次。眉毛轻抬又落下，一侧嘴角向下牵动。她从鼻腔明显但克制地呼出一口气，头部偏开少许，随后重新看向对方。
- 避免：翻白眼、敲桌子、连续叹气。

### E10 受伤后用愤怒掩饰

- 适用：被背叛、被拒绝，却不愿暴露脆弱。
- 路径：眼神先受伤 → 迅速收紧下眼睑 → 嘴唇抿紧 → 下颌绷住 → 泪光或呼吸泄露。
- 落点：表面强硬，脆弱仍在眼神里。
- 可复制：人物听见伤人的话后，眼神先短暂失去防备，视线停顿一瞬。她很快收紧下眼睑，压低眉毛，双唇用力抿住，下颌逐渐绷紧，试图把受伤转成愤怒。她仍直视对方，但眼眶边缘残留一点湿润，呼吸也比开始更浅。
- 避免：直接怒吼、悲伤和愤怒同时夸张爆发。

## F. 社交伪装、复杂心理与意志

### F01 礼貌性微笑

- 适用：社交应对、保持距离、没有真正亲近。
- 路径：嘴角对称轻抬 → 眼周参与很少 → 短暂停留 → 嘴角恢复。
- 落点：礼貌完成，眼神仍疏离。
- 可复制：人物面对对方时，嘴角缓慢而对称地轻微上扬，形成闭口微笑，眼睑和眼周肌肉参与很少，眼神仍然平静。面颊只轻微抬起，笑容短暂停留后嘴角恢复水平，呼吸和姿态始终稳定。
- 避免：持续固定微笑、露齿过多、眼睛同步大笑。

### F02 尴尬

- 适用：听到不合时宜的话、社交失误。
- 路径：目光迅速移开 → 眨眼一次 → 眉毛短暂抬起 → 不稳定浅笑 → 笑容消失。
- 落点：避免继续对视。
- 可复制：人物听见令人尴尬的话后，目光迅速移开，眨眼一次，眉毛短暂抬起。双唇轻轻压紧，随后嘴角勉强形成一个很浅且不稳定的微笑，一侧面颊比另一侧更紧。她短促呼气，笑容很快消失。
- 避免：大笑掩饰、连续抓头、夸张耸肩。

### F03 紧张陪笑

- 适用：讨好权威、缓解冲突、害怕冷场。
- 路径：嘴角快速上扬但不均匀 → 眼神躲闪 → 眉心仍紧 → 再次勉强笑 → 先收嘴角。
- 落点：笑容先于紧张消失。
- 可复制：人物试图用笑容缓解紧张，嘴角快速上扬但幅度略不均匀，面颊轻抬，眼神却短暂躲闪。眉心仍残留紧张，呼吸较浅。她再次勉强微笑，随后嘴角先恢复平静，眼神和下颌仍显拘谨。
- 避免：连续咧嘴、傻笑、频繁点头。

### F04 强装平静

- 适用：隐藏震动、维持身份、不能暴露软弱。
- 路径：眼神短暂波动 → 主动放慢眨眼与呼吸 → 眉心压平 → 嘴唇闭合 → 咬肌残留。
- 落点：表面恢复，细节仍泄露。
- 可复制：人物的眼神先出现短暂波动，随后主动放慢眨眼和呼吸，把视线重新固定在前方。她逐渐压平眉心，轻轻闭合双唇，头部保持稳定。表面已经恢复平静，但下颌和咬肌仍保留细微紧张。
- 避免：面部完全僵住、突然变成无表情、全身停止呼吸。

### F05 有所隐瞒

- 适用：不愿回答、保留真相、绕开问题。
- 路径：视线侧下回避 → 眨眼一次 → 嘴唇迅速抿紧 → 一侧嘴角抽动 → 吞咽 → 恢复凝视。
- 落点：刻意正常但略显用力。
- 可复制：人物听见问题后，目光短暂转向侧下方，眨眼一次，随后重新看向对方。双唇迅速抿紧，一侧嘴角出现短促细微的抽动。她无声吞咽，呼吸短暂变浅，最后刻意保持正常凝视。
- 避免：将这些动作描述为现实测谎证据、连续躲闪。

### F06 被看穿后的心虚

- 适用：伪装被识破、谎言遭到指出。
- 路径：对视冻结 → 快速移开 → 眨眼略增 → 下颌瞬间绷紧 → 尝试微笑失败。
- 落点：僵硬回避。
- 可复制：人物与对方对视时，眼神突然停顿，随后快速移开，眨眼频率短暂增加。眉毛略微抬高，眉心收紧，双唇闭紧，下颌瞬间绷住。她吞咽一次，短促吸气后尝试恢复微笑，但嘴角无法稳定。
- 避免：过度冒汗、全脸抽搐、连续后退。

### F07 表面关心、内心疏离

- 适用：礼貌慰问、复杂关系、职业性回应。
- 路径：眉毛内侧轻抬 → 嘴角礼貌松动 → 头部小幅前倾 → 眼神保持距离 → 很快收束。
- 落点：动作正确但缺少情感投入。
- 可复制：人物听对方说话时，眉毛内侧轻轻抬起，嘴角形成礼貌而克制的松动，头部小幅前倾，像是在表示关心。她的眼神却始终保持稳定距离，没有明显变柔。回应结束后，嘴角很快恢复平静。
- 避免：夸张同情脸、持续皱眉、明显冷笑。

### F08 真诚道歉

- 适用：承认错误、请求原谅。
- 路径：主动保持对视 → 说话前吸气 → 目光短暂下落 → 重新看回 → 小幅口型 → 不抢先求回应。
- 落点：承担而非自我辩护。
- 可复制：人物起初努力保持与对方的对视，轻轻吸气后，目光短暂垂下，像在确认自己必须说出这句话。她无声吞咽一次，重新抬眼，双唇以克制的小幅度开合。说完后没有立即微笑或靠近，只保持安静而坦诚的凝视。
- 避免：连续鞠躬、哭着求原谅、说完立刻笑。

### F09 想原谅但仍不敢相信

- 适用：迟来的道歉、关系修复。
- 路径：防备对视 → 触发后眼神变柔 → 马上回避 → 欲言又止 → 重新对视 → 点头未完成。
- 落点：接受意愿与保留同时存在。
- 可复制：人物起初保持防备的对视，嘴唇闭紧，下颌略微绷住。听见对方的道歉后，她的眼神短暂变柔，却马上移向一侧。双唇微微分开，像要回应，最终无声合拢。停顿后她重新看向对方，嘴角有一丝松动，头部轻轻点动到一半又停住。
- 避免：立刻拥抱、马上大笑、彻底解除防备。

### F10 不忍拒绝

- 适用：想拒绝请求但在意对方感受。
- 路径：看着对方 → 视线回避 → 缓慢吸气 → 想点头又停 → 嘴唇小幅说话 → 手势收回。
- 落点：拒绝已经发生，情感仍保留。
- 可复制：人物看着对方时，眼神先出现一丝不忍，随后缓慢移向侧下方。她轻轻吸气，头部像要点下去却停住，双唇以很小幅度开合，像在说出克制的拒绝。伸出的手指轻微动了一下又收回，最后重新看向对方。
- 避免：大幅摇头、冷漠转身、过度安慰。

### F11 假性恢复

- 适用：人物以为自己已经恢复控制，但细节仍泄露。
- 路径：主动整理呼吸与表情 → 恢复原姿态 → 无意识动作继续 → 第二次收束。
- 落点：表面稳定与真实情绪并存。
- 可复制：人物短暂闭眼并缓慢吸气，重新睁眼时主动放松眉心、闭合双唇，把姿态恢复到最初的稳定状态。她的目光看似重新坚定，然而握持道具的手仍有极细微颤抖，眼眶中的湿润也没有消失。她没有再次调整，只让这个破绽停留片刻。
- 避免：恢复后完全没有泄露、重复多次恢复、动作突然重置。

### F12 疲惫强撑

- 适用：长期压力、熬夜、仍需完成任务。
- 路径：上眼睑沉重 → 眨眼变慢 → 目光短暂失焦 → 吸气重新聚焦 → 肩膀仍下沉。
- 落点：精神重新集中，身体疲惫未消。
- 可复制：人物的上眼睑略显沉重，眨眼速度缓慢，目光短暂失去焦点。她轻轻抿唇，缓慢吸气后重新聚焦前方，眉心恢复专注。头部保持稳定，但肩膀仍随呼气轻轻下沉，疲惫没有完全消失。
- 避免：夸张打哈欠、闭眼睡着、连续揉眼。

### F13 挑衅冷笑

- 适用：主动施压、试探底线、危险对峙。
- 路径：视线锁定 → 下眼睑收紧 → 单侧眉尾轻抬 → 单侧嘴角缓慢上扬 → 头部微前倾。
- 落点：笑意短暂，视线不移开。
- 可复制：人物持续锁定对方，下眼睑逐渐收紧，一侧眉尾轻轻抬起。一侧嘴角缓慢上扬，形成极浅、不对称且没有眼部笑意的冷笑。她的下巴略微抬高，头部向前倾斜少许，笑意短暂停留后仍不移开视线。
- 避免：邪恶大笑、夸张舔唇、剧烈前倾。

### F14 心软但仍试图完成决定

- 适用：重大选择、道具参与、内心与行动对抗。
- 路径：稳定执行 → 第一处面部裂缝 → 动作轻微松动 → 假性恢复 → 道具继续泄露 → 最终降低或松开。
- 落点：用道具或手部的缓慢变化表达心软。
- 可复制：人物起初保持稳定而克制的执行姿态。看清眼前的人后，视线停顿一瞬，眉心极浅地收紧又放松，一侧嘴角短促抽动。她的手出现轻微颤抖，道具随之偏移少许。她缓慢吸气，强迫自己恢复原姿态，但手部颤抖仍未消失。最终，她仍看着对方，握力却一点点松开，道具缓慢降低。
- 避免：直接写“她心软了”、突然完全放下、道具自行移动。

### F15 无奈妥协

- 适用：明知不理想却只能接受、争论后让步。
- 路径：坚持凝视 → 眉心短暂收紧 → 视线移开 → 长呼气 → 下颌放松 → 极小点头。
- 落点：行动上接受，情绪上仍有保留。
- 可复制：人物起初仍坚持看着对方，眉心短暂收紧，像还想继续反驳。停顿后，她先移开视线，缓慢呼出一口气，下颌和肩颈逐渐放松。她重新看回对方，只极小幅度地点头一次，嘴角没有笑意，最后停在无奈但明确的接受中。
- 避免：翻白眼、夸张摊手、连续摇头后突然同意。

### F16 释然接受

- 适用：长期纠结结束、终于承认不可改变的结果。
- 路径：残留紧张 → 缓慢闭眼或眨眼 → 长呼气 → 眉心与下颌舒展 → 松开手中物。
- 落点：不一定开心，但停止对抗。
- 可复制：人物起初仍保留轻微紧张，视线在目标上停留片刻，随后缓慢闭眼并呼出一口长气。重新睁眼时，眉心和下颌逐渐舒展，目光恢复清晰而平静。她没有明显微笑，只缓慢松开一直握紧的手指，最后安静接受眼前的结果。
- 避免：突然大笑、彻底无情绪、用一句“她释然了”代替动作。

### F17 无奈苦笑

- 适用：明知结果不理想，却已无力改变。
- 路径：视线移开 → 缓慢眨眼 → 长呼气 → 单侧嘴角短暂抬起 → 笑意消失。
- 落点：笑是接受现实的外壳，疲惫底色仍在。
- 可复制：人物先把视线移到斜下方，缓慢眨眼后呼出一口长气。只有一侧嘴角勉强抬起一点，笑意没有进入眼睛，停留很短便自然消失，最后仍保持疲惫的注视。
- 避免：笑容持续、眼周明显变柔、把苦笑写成释然微笑。

### F18 悲悯同情

- 适用：看见别人受伤、理解对方处境、克制地给出支持。
- 路径：稳定看见对方 → 眉心轻靠 → 嘴唇欲言又停 → 身体小幅靠近 → 手势先停后落下。
- 落点：关注对方，不抢走对方的情绪中心。
- 可复制：人物安静看着对方，眉心轻轻靠拢，双唇张开一丝又无声合上，像在选择更温和的回应。她的身体只靠近少许，伸出的手先停在对方附近，确认没有被拒绝后才轻轻落下。
- 避免：自己先大哭、突然拥抱、过度摇头叹息。

### F19 克制哀求

- 适用：请求对方停下、挽回关系或争取最后一次理解。
- 路径：持续追随对方 → 内眉轻抬 → 话语被呼吸打断 → 身体小幅靠近 → 伸手后停在两人之间。
- 落点：主动争取但不失去尊严。
- 可复制：人物始终看着对方，内眉轻轻抬起，吸气在开口前短暂卡住。她试着说出请求，口型小而断续，身体只向前靠近一点。伸出的手停在两人之间，没有强行触碰，视线仍等待对方回应。
- 避免：立即跪下、抱住对方、大声哭求、反复伸手。

### 选择算法

无法判断具体表情名称时，依次回答：

1. 情绪方向是愉快、不愉快，还是中性认知？
2. 身体唤醒程度是低、逐渐升高，还是突然升高？
3. 人物是释放情绪，还是压制情绪？
4. 人物是靠近、回避、对抗，还是维持社交表面？
5. 最终选择是否已经发生？
