# 踩坑与对策库（全局）

> 用途：任何 AI 片子都会撞上的通用失败模式。**先查这张表，再改提示词。**
> 每条都是"症状 → 真因 → 对策"，按发生频率排序。
> 需要完整方法时，去 **§五 交叉索引**查对应文件与章节。

---

## 第一定律（先记这一条）

> **参考图会连"它当时的状态"一起被抄走。**

设定图是证件照冷脸 → 每个镜头都冷脸；
构图参考是海边 → 画面自己长出水面；
造型参考是湿发 → 头发变湿；
参考穿长裙 → 角色裙子飞起来；
参考里皱着眉 → 每一格都在皱眉。

**对策**：素材职责必须写三样 —— **采用什么 / 不采用什么 / 边界在哪**。
**"不采用"那一项漏掉哪样，模型就抄哪样。**

## 一、单帧阶段的坑

### 1 · 出来像"会动的线稿"

| | |
|---|---|
| **症状** | 视频是铅笔线条在动，或者干脆是一张线稿在轻微推拉 |
| **真因** | 线稿是画面里最强的视觉信号，没有反向指令时模型照抄画风 |
| **对策** | ① 线稿**只提供构图**，画风/笔触/黑白灰/素描感全部作废；② 更好的是**先把线稿转成实拍参考图**，再拿它当首帧 |

### 2 · 头发炸毛 / 画面发雾

| | |
|---|---|
| **症状** | 顶部炸开一大簇细碎飞丝，额前垂几根孤零零的；整张蒙着雾 |
| **真因** | "一根一根看得见"被做成了建模硬管；"空气感"被读成大气雾 |
| **对策** | 改成正向描述：**干爽、蓬松、宽发束、成片**；正向写"画面清爽、不发雾"，不要只写"不要雾" |

### 3 · 头发变湿、变尖（刺猬头）

| | |
|---|---|
| **症状** | 发束细而尖、硬邦邦立着，像刚洗完没吹干 |
| **真因** | 设定图造型本身是"向上立起"，被误解成"湿 + 尖" |
| **对策** | 把两件事拆开写：**"向上"照设定图保留，"湿"禁掉**。<br>配方：`发型形状照角色设定图（包含向上立起的造型），但质感要干爽蓬松柔软、发束宽而成片` |

### 4 · 脸上长雀斑 / 脏点

| | |
|---|---|
| **症状** | 脸上多出斑点、痣、麻点 |
| **真因** | 未排除；"真实皮肤纹理"被扩展到"斑点" |
| **对策** | 写死：**脸上要干净——不要雀斑、不要斑点、不要痣、不要麻点；皮肤纹理指的是毛孔与细纹，不是斑点** |

### 5 · 抓错瞬间（画面里没有动作）

| | |
|---|---|
| **症状** | 该"在找"的镜头，画面里只有"垮掉"；该"刚开始"的只有"已做完" |
| **真因** | 抓到了动作的末尾 |
| **对策** | **一律抓动作开头 / 三分之一**；一格演两段时（先…然后…）**抓前一段** |

### 6 · 参考图里没有的东西，加不出来

| | |
|---|---|
| **症状** | 提示词写了"街上要有路人"，出来一个人也没有；写了"桌上有空杯"，桌上空空的 |
| **真因** | 参考图是强信号，文字是弱信号 |
| **对策** | **补素材，不要反复改文字**：<br>· 找一张有这个元素的图，作为"该元素的来源"挂上去；<br>· 或者在**单帧阶段**就把它画进去（单帧阶段加元素比视频阶段容易得多）；<br>· 重画参考图是最终解 |

### 7 · 参考图场景渗入

| | |
|---|---|
| **症状** | 要的是街道，出来却有水面 / 对岸 / 堤坝 |
| **真因** | 只写了"不采用它的场景"，太抽象 |
| **对策** | **把元素逐词点掉**：`不要水面、江、河、海、湖、堤坝、水岸、对岸的轮廓；街道两侧是建筑，尽头也是建筑` |

### 8 · 服装错（长裙摆飞起来）

| | |
|---|---|
| **症状** | 角色穿短裙，画面里却甩出长裙摆 |
| **真因** | 造型参考穿长裙，被连"裙子形态"一起抄 |
| **对策** | 写死：`她穿的是短款格纹裙，没有长裙摆可甩——飞起来的是她的头发，不是裙子` |

### 9 · 表情治不好（冷脸）

| | |
|---|---|
| **症状** | 写多少"要笑"都没用，每一格都是冷脸 |
| **真因** | 设定图是证件照冷脸，模型把它当"这个人的长相" |
| **对策** | ① 素材职责里**把表情和长相拆开**：`只采用长相、发型、发色、服装，不采用设定图上这个人的表情`；<br>② **另做一张微笑版设定图**（同人同脸同服装，只改表情），这一整段改挂它 |

### 10 · 眉形上扬被当成"皱眉"

| | |
|---|---|
| **症状** | 怎么强调"不要皱眉"都没用，眉头还是挤在一起 |
| **真因** | 角色天生眉形上挑，"上扬"被等同于"皱眉" |
| **对策** | 写**物理级**描述：`眉间那一小块皮肤是平滑的、平的；两只眉头之间要有距离；上扬的眉形不等于皱眉` |

### 11 · 表情用情绪词 → 做成最强烈的那一档

| | |
|---|---|
| **症状** | 写"眼前一亮"，出来是大笑 |
| **真因** | 情绪词会被映射到最强档 |
| **对策** | **改成动作**：头停住再抬起 / 眼睑半垂→睁开（不瞪大）/ 呼吸停一拍 / 嘴唇先微分开、嘴角才上提一点点 / 脖子前伸、脚不动 |

### 12 · 提示词正文混进 Markdown 符号

| | |
|---|---|
| **症状** | 提示词里带着 `**` `#` 之类，模型当噪声 |
| **真因** | 从文档直接复制 |
| **对策** | 代码块内全部清掉加粗符号；交付前跑一次清理 |

## 二、视频阶段的坑

### 13 · 人物完全不动、像动态图片

| | |
|---|---|
| **症状** | 画面只有轻微推拉，人像照片 |
| **真因** | ① 时长太短（<3 秒动作没展开）② 动作只写形容词 ③ 没写到部位 ④ 一段塞三种运镜 |
| **对策** | ≥5 秒；动作写到部位并量化（幅度/速度/力度）；**一段一种运镜**；每拍都有可观察的结束状态 |

### 14 · 角色没被替换、发型服装全错

| | |
|---|---|
| **症状** | 出来的人不是设定图那个人 |
| **真因** | ① 首帧模式与多模态参考**互斥**（混用 = 模型忽略你的图）② 角色图权重被稀释 ③ 用了多视角素材集 |
| **对策** | 走**全能参考**；角色图放前面；用"一张头像 + 一张全身"或单张设定图，不要多视角集合 |

### 15 · 变速没生效（写了升格，出来是常速）

| | |
|---|---|
| **症状** | 要求升格，全片正常速度 |
| **真因** | 只写了"升格"，没写"两种速度"和切换点 |
| **对策** | 两个方向都堵：`不许整条都正常，也不许整条从头到尾都慢`；**切换点绑在一个可观察事件上**（"肩膀擦过椅背那一下"） |

### 16 · 运镜被做错

| | |
|---|---|
| **症状** | 要环绕做成摇；要后拉做成推；要横移做成摇 |
| **真因** | 用了口语描述，没给标准词 |
| **对策** | 按 `camera-movements-46.md` 用**中英双写**的标准词；并且写【禁止】`不要横移、不要原地摇、不要推拉` |

### 17 · 定格变成"整张冻住"

| | |
|---|---|
| **症状** | 最后一格像一张照片被按住 |
| **真因** | "定格"被理解成"画面静止" |
| **对策** | 拆成两层：**镜头停住，不是画面停住**——风还在吹、发丝还在飘，只是机器不晃了 |

### 18 · 视频跑到一半风格漂了

| | |
|---|---|
| **症状** | 后几秒头发变湿、脸变冷、皮肤长雀斑 |
| **真因** | 首帧锁定只有一句，没有逐项兜住 |
| **对策** | 用一段**短锁定句**逐项列：`不要改变色调、质感、画风、发型与头发的质感、表情与视线方向、皮肤`；<br>注意：**锁定 ≠ 重描**，锁定是"别动"，重描是"再画一遍" |

## 四、排查顺序（遇到"不对"时按这个走）

```
1. 先看核心任务对不对（人物是谁、在做什么、事件顺序）
2. 再看硬约束（长相/服装/场景/道具有没有崩）
3. 再看时间连续性（动作有没有断、有没有跳变）
4. 再看镜头与视觉质量（构图/光/质感）
5. 最后对照素材职责——参考对了？还是错误复制了不该参考的维度？
```

**归因五选一（必须选且只选一个主因）**：
`提示词问题` / `参考素材问题` / `运行参数问题` / `模型随机性` / `模型能力问题`

> 单个失败结果**不能**证明"模型能力问题"；
> 多版都失败又找不到原因 → 结论写「**证据不足**」，不要猜。

## 七、三条最容易反复犯的（新文件之间互相咬合的）

| 反复犯的坑 | 三个文件怎么配合 |
|---|---|
| **表情永远冷脸 / 一笑就过火**（9 + 11） | 素材拆开（`character-asset-rules`）→ 弧线按 2 级强度（`performance-arc` §七）→ 具体动作查库（`microexpression-library`） |
| **后几秒整个人变了**（18 + 14） | 身份只取一次（`continuity-bible` §三.1）→ 每镜只写 Delta（§四）→ 修图时写清【保持原样】（`result-repair` §二） |
| **参考图总在偷偷加东西**（6 + 7 + 8） | 定角色（`reference-decode` §三）→ 划不搬清单（§六）→ 多图分工（§七） |

> 这三组是同一个根因的三种表现：**没有把"参考图里有什么"和"我想要的视觉语法"分开。**
