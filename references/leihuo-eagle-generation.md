## 二之三、参考图降噪（送模型前的固定步骤）

**参考图带噪，生成结果就会带噪**——edits 会原样继承参考图的纹理。实测：参考图天空噪点 5.69，先降噪再生成降到 3.80（约 33%）。

**每次把参考图送进 `/images/edits` 之前，先跑一次：**

```bash
python C:/Users/admin/.claude/tools/denoise_ref.py <原参考图> <降噪后的图>
```

等价于：`MedianFilter(3)` + `GaussianBlur(0.6)`，结构保留，细噪点掉一半。

注意：
- 这是**预处理**，不改变构图和内容
- 降噪后的图只用于喂模型，原始参考图不要覆盖
- 提示词里写"不要噪点"**无效**，别指望文字解决

## 二之四、单帧必须带设定图（硬规则）

生成正式单帧时，一律走 `/images/edits`，把第 3 站资产当参考素材传进去，**禁止纯文字生成**。

- 多图参考用 `image[]` 字段（已验证可用）：角色设定图 + 场景四视图 + 道具设定图

- **风格写在第一句**：先写「手绘厚涂三维动画，不是照片 / 写实 CG」，再写内容；末尾的全局质量词权重不够
- **不要写实锚点**：绘画感 3D 不写「35mm 电影机 / 真实毛孔 / 真实光学虚化」，改用「虚拟摄影机 / 等效焦段 / 动画电影式景深」

## 四、Eagle API 操作

1. `GET /api/folder/list?token=...`：查找项目和子文件夹 ID。
2. `GET /api/folder/create?token=...`：创建缺失文件夹，body 为
   `{"folderName": "...", "parent": "父文件夹ID"}`。
3. `POST /api/item/addFromPath?token=...`：导入图片或 Markdown，body 至少包含
   `path`、`folderId`、`name`、`tags`。
4. 导入后用 `GET /api/item/list?token=...` 或文件夹树核对条目数量。

### 网址书签（灰模 / 网页类）

- 用 `POST /api/item/addBookmark`，body 带 `url`、`name`、`folderId`、`tags`、`base64`。
- `base64` 用 `data:image/png;base64,...` 形式的 **1440×900** 网页截图，Eagle 会把它存成书签缩略图。
- **不要用 `/api/item/addFromURL`**：返回 `success` 但不落库。
- **不要用 `addFromPath` 导入 `.url` 文件**：只会得到 82 字节的文件条目，显示通用图标、名字带 `.url`、没有网页预览。
- 名称不带 `.url`；标签带 `链接`；备注留空。
- 本地预览图 1280×720，Eagle 缩略图 1440×900，两者分开保存。

Eagle 未运行时，先请用户手动启动 Eagle；不要假设 API 可用。
